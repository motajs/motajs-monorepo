<objective>
Move the resource layer's leaf modules and its persistence chain out of `@motajs/editor` into
`packages/libs/editor-core/lib/resources/*`, prove the whole relocation architecture end-to-end on the
lowest-risk files, and keep `@motajs/editor` behaving exactly as today through tracked re-export shims.

Purpose: this is the first plan of a pure-refactor phase, and its job is to de-risk the *mechanics*
(package manifest → core directory → root barrel → editor shim → editor consumer → both programs green)
before the heavier injection-seam work lands. It also clears the two structural gates that the moved
test trees would otherwise trip: the core module-state lint block and its verifier's exemption probe.

Output: five leaf resource modules plus `PersistExecutor`/`PersistenceMonitor` living in core, a
`packages/libs/editor-core/package.json` with the four new `dependencies` and two new catalog entries,
seven editor shim files, and `packages/apps/editor/src/appInstances.ts` as the single `new
PersistenceMonitor(` site.

Decisions implemented here — D-05: core consumes only an injected `FsPort` (the `fsPort` binding is
created here and consumed in 04-02). D-06: `PersistenceMonitor` is de-singletonised (class only, no
trailing `new`). D-07: the temporary composition-root-lite module `src/appInstances.ts` is created
here. D-09: `lib/resources/*` is an internal directory whose public surface is aggregated by the root
`.` entry, with no new subpath. D-10: per-file forward-only shims carrying the `// SHIM(phase4)`
marker. D-12: `waitUntil` is re-homed into core by literal move. D-13: the pure in-memory tests move to
core while the `@test/*`/submodule-coupled ones stay in the editor.
</objective>
