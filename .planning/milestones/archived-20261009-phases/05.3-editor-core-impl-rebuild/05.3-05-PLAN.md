<objective>
实现 editor-core 的资源系统：`ResourceSystem`（缓存 + Hook 广播 + 后端读写）与资源句柄 `Resource`（D-17..D-25、D-35..D-37、D-39）。
资源读写只对面板开放（经 `IResourceAccess`）；对外暴露的 `IResourceSystem` 不含读写方法。

Purpose: 提供面板获取/写入/创建/删除资源的统一入口，并把“资源更新”经 Hook 广播给各面板（桥接在面板层）。
Output: `Resource` + `ResourceSystem` 类 + 单元测试 + 桶文件追加导出。
</objective>

    实现资源系统全部成员（类必须完整实现接口，否则 typecheck 不过），本任务先用测试钉住最小闭环：
    （1）`src/resource/resource.ts`：`Resource<T>` 实现 `IResource<T>`。字段 `readonly identifier: IResourceIdentifier`、`private readonly store: IResourceStore`（构造器 `(identifier: IResourceIdentifier, store: IResourceStore)`）。`request()` 调 `this.store.readContent<T>(this.identifier)`；`write(data)` 调 `this.store.writeContent(this.identifier, data)`。**只** import `./types` 与 `./store`，绝不 import `./resourceSystem`（否则成环，触发 no-circular 门禁；D-37）。
    （2）`src/resource/resourceSystem.ts`：`ResourceSystem extends Hookable<IResourceSystemHooks> implements IResourceSystem, IResourceAccess, IResourceStore`。
        - 字段：`private injection!: IResourceInjection`、`private readonly listCache: Map<number, readonly IResourceIdentifier[]> = new Map()`、`private readonly contentCache: Map<number, Map<string, unknown>> = new Map()`。缓存一律用双层 Map，**禁止**字符串拼接键（RESEARCH Don't Hand-Roll）。
        - `protected createController(hook)`：`return new HookController(this, hook);`。
        - `initialize(injection)`：`this.injection = injection;`。
        - `requestResourceList(type)`：命中 listCache 直接返回；否则 `await injection.requestResourceList(type)` 并缓存后返回。
        - `requestResource<T>(id)`：先 `await this.requestResourceList(id.type)`；列表含该 id 时 `return new Resource<T>(id, this)`，否则 `return null`。
        - `readContent<T>(id)`：内容缓存命中返回；否则 `await injection.requestResource<T>(id)` 回填缓存后返回（缓存值可由 `unknown` 单次 `as T` 收窄）。
        - `writeContent<T>(id, data)`：`await injection.writeResource(id, data)`；同步回填内容缓存；**不**触发任何钩子（D-23）。
        - `createResource<T>(id, content)`：`await injection.createResource(id, content)`；回填缓存；`await this.updateResourceList(id.type)`；返回 `new Resource<T>(id, this)`。
        - `deleteResource(id)`：`await injection.deleteResource(id)`；删内容缓存；`await this.updateResourceList(id.type)`。
        - `updateResource(id)`：删内容缓存；`await Promise.all(this.forEachHook((hook) => hook.onUpdateResource?.(id)))`（D-37；forEachHook 可能返回 undefined，Promise.all 接受）。
        - `updateResourceList(type)`：删列表缓存；`await Promise.all(this.forEachHook((hook) => hook.onUpdateResourceList?.(type)))`。
        - `dispose()`：清空两个缓存。
        - 在 `requestResource` / `requestResourceList` / `createResource` / `deleteResource` 上写单行 `//` 注释说明“仅供面板上下文内部使用”（D-35）。
    （3）`src/resource/index.ts` 末尾**追加** `export * from './resource';` 与 `export * from './resourceSystem';`（不追加 `./access`、`./store`）。
    导入一律相对路径、用普通 import（禁类型导入语法）。实现类不重复接口 jsDoc；不写文件头注释。
    新建 `src/resource/__tests__/resourceSystem.test.ts`：写一个内存后端测试替身（实现 `IResourceInjection`，用 Map 存内容与各 type 的列表）。覆盖：
    - `requestResourceList` 首次请求后端一次、二次命中缓存不再请求。
    - `requestResource` 对列表中存在的 id 返回句柄、对不存在返回 null。
    - `resource.request()` 返回后端内容，二次调用走缓存（后端只被请求一次）。
    每个 `it`/`test` 前用单行 `//` 说明覆盖内容；首行必须是 import。

## Trust Boundaries

|----------|-------------|
| 面板上下文 → ResourceSystem | 面板经 IResourceAccess 传入资源标识符与内容 |
| ResourceSystem → IResourceInjection（后端） | 真实读写交给注入的后端；core 不自行 IO |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
