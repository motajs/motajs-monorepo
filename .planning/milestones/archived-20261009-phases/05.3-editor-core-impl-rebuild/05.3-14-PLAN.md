<objective>
在 05.3-13 已加宽的接口上落地实现：把 `injection` 的定值断言换成真正的可空成员——未初始化时经集中日志记一条 `system.notInitialized`（参数为系统名 `Resource`，输出 `Resource system is not initialized`）并返回空值（不中断调用链、不直接控制台输出）；补齐六个私有成员的 jsDoc；把面板切换参数从「可能没有」统一为「总是一个对象」（内部字段与 `currentParam` 必填，`switchTo` / `internalSwitchTo` 的实现参数默认 `{}`，公共接口仍可选）。

Purpose: 消除评审确认的四处实现缺陷（定值断言、私有成员缺 jsDoc、未初始化的处理方式、切换参数可为空），满足 AGENTS §Code style 注释规范、D-09「朴素简洁、绝不炫技」与 D-13「initialize 注入」的语义。本计划**不重做** 05.3-13 已完成的接口加宽与 `EditorPanelHooks.onUpdateResource` 守卫。

Output: 加上空守卫与集中日志的 `resourceSystem.ts`、新增消息的 `messages.ts`、补齐 jsDoc 的 `undoSystem.ts` / `resource.ts`、参数统一后的 `panelSystem.ts`、跟随返回类型加宽的资源测试，以及记录命名的 `05.3-INTERFACE-NAME.md`。

说人话：资源系统还没被初始化时，现在会硬报一个「我给不出数据」。正确做法是——用系统日志记一条英文提示，然后老实返回「空的」（列表给空数组、请求给 null、读内容给 undefined）。另外给六个内部字段补上说明注释，并把面板切换时传的参数从「有时没有」改成「永远是个对象」。
