# Phase 05.3 Plan 14: 资源系统未初始化守卫与面板切换参数统一 Summary

**把资源系统的 `injection!` 定值断言换成真正的可空成员：未初始化时经集中日志记一条 `Resource system is not initialized` 并老实返回空值（列表空数组 / 请求与创建 null / 读内容 undefined / 写入与删除直接返回），同时补齐六个私有成员的 jsDoc、把面板切换参数从「可能没有」统一为「永远是个对象」。**

## Accomplishments

- `resourceSystem.ts`：删除 `private injection!: IResourceInjection;`，改为单行 jsDoc + `private injection: IResourceInjection | null = null;`；相对导入模块级单例 `logger`（`../log`，与 `log/` 无反向依赖、无循环）。
- 六个方法入口各加空守卫，未初始化时先 `logger.error('system.notInitialized', 'Resource')` 再返回 `[]` / `null` / `undefined` / `void` / `null` / `void`；不抛错、不中断调用链、不直接触达控制台。

- 六个私有成员补齐紧贴的单行 jsDoc：`injection` / `listCache` / `contentCache`（resourceSystem）、`undoStack` / `redoStack`（undoSystem）、`store`（resource）。
- `panelSystem.ts`：`IPanelSwitchData.fromParam` / `toParam` 与 `PanelSystem.currentParam` 改必填 `Record<string, unknown>`（`currentParam` 初值 `{}`）；`switchTo` / `internalSwitchTo` 实现参数默认 `{}`；公共 `IPanelSystem.switchTo` 与 `IEditorPanel.onSwitchIn` 仍为 `param?`。
