# Phase 05.1 Plan 03: 拆出 `@motajs/editor-impl` 包 + 依赖门禁

**把 `editor-core` 拆成「底层（接口+管理）」与「默认实现层」两个包：新包 `@motajs/editor-impl` 接收全部默认实现内容，`editor-core` 只剩 kernel + ports，并用机器门禁锁死「底层不依赖实现」「底层不读文件」。**

## Accomplishments

- `@motajs/editor-impl` 物理成形：manifest（7 subpath / 9 peer / `@motajs/editor-core: workspace:*`）、tsconfig、vitest config、根 barrel；`resources`/`edit`/`table`/`code`/`map`/`asset`/`shell`/`react` 八个目录经 `git mv` 整体迁入（历史保留）。
