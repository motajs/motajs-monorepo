<objective>
把 `editor-core` 拆成两个包：**新包 `@motajs/editor-impl`** 接收全部默认实现内容（资源层、编辑层、表格、
能力目录、`react`），**`@motajs/editor-core` 只剩底层**（接口 + 管理）；同时让机器门禁守住「底层不得依赖
实现」「底层不读文件」，并把新包的结构门禁补齐。

Purpose（说人话）：现在这个包把「底层定义」和「具体编辑功能」混在一起，分不清谁依赖谁。这一步把它拆成两个包：
`editor-core` 只留「定义接口 + 管调度」，其它具体功能整包搬到新 `editor-impl`。然后用自动检查把门关死：
谁想在底层里读文件、或者让底层反过来依赖实现，机器立刻报错，不靠人自觉。

Decisions implemented here — D-01 (two packages, one-way dependency), D-02 (the bottom layer only *defines*
file IO and never calls it), D-08 (exported types centralized), D-14 (LF), D-15 (dev.md conventions where
touched).
