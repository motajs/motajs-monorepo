## Sampling Rate

- **After every task commit:** the task's `<automated>` verify (focused vitest file + the relevant package `typecheck`)
- **After every plan wave:** `pnpm test` + `pnpm typecheck` + `pnpm lint` + all `scripts/verify/*.js`
- **Before `/gsd-verify-work`:** full suite + all `scripts/verify/*.js` green
- **Max feedback latency:** 120 seconds

> 到 08 结束时恢复全绿——与 Phase 4 的 `04-04` 同法。每个 wave 的**边界**必须全绿。
