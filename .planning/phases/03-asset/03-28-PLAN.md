<objective>
修复验证缺口 G-03-10：替换一个素材的文件后，卡片缩略图、右侧预览和图片尺寸仍显示旧内容，必须切走再切回才更新。

Purpose: 让「替换」像用户预期的那样立刻可见，不必手动切换选中或重新进入分类。
Output: 每个素材带一个字节版本号；替换 / 原地转码时版本加一；预览与尺寸行看到版本变化就重新读取字节；以及一条证明刷新确实发生的回归测试。

根因：预览效果的依赖只有 MIME，组件的 key 又只用没有变化的素材路径；替换后 React 不会重挂组件，effect 也不会重跑，旧的 `blob:` 地址便一直留在界面上。
</objective>

    在 `IAssetEntry` 上新增可选只读成员 `byteVersion?: number`，jsDoc 说明：素材字节的版本号，同一路径的字节每被覆盖一次加一，加载得到的条目缺省视为 0，预览组件据此重新读取。
    在 `AssetPanel.replaceAsset` 里，覆盖字节成功后构造新条目时补上 `byteVersion: (entry.byteVersion ?? 0) + 1`，其余字段（name / path / config / exists）保持现状。
    在 `AssetPanel.transcodeAssets` 里，每一个成功的转码条目同样补上 `byteVersion: (entry.byteVersion ?? 0) + 1`；即使输出路径变化也要加一，因为素材名可能不变、卡片不会重挂。

    本任务只改数据层与 hook，不改预览组件的调用点（下一任务负责透传）。
