# Phase 3 — UI Design Contract / 素材管理

> 本文件是「素材管理」能力（`@motajs/editor-impl/asset`）的视觉与交互契约。由 gsd-ui-researcher 生成，gsd-ui-checker 校验。
>
> **范围。** 本契约覆盖**一个「素材管理器」面板**（分类切换 + 素材网格 + 详情/预览 + 每素材配置）、**默认素材选择器**、以及**瘦身转码**界面。外壳（菜单行 / 标签行 / 内容区）属 Phase 1，**不在此重复**；本面板渲染在 `editor-core` 外壳的内容区内。Phase 2 已交付的 **JSON Schema 表格/表单引擎**（`editor-impl/table`）被本阶段**直接复用**为「每素材配置表单」，其内部呈现不在本文重复，仅约束其**挂载形态**。
>
> **对齐说明（用户指令）。** 现有 `@motajs/editor` 的素材实现（`ResourcesWorkspace` / `AppendPicPanel` / `PrefabPanel` / `SelectMaterial` / `ImageAssetPickerModal`）是**画面 / 行为参照**，不是照抄模板。用户原话：「旧代码仅做参考，不代表新的代码也要这么写」。凡本文说「与现状一致」，指的是用户可观察到的外观与行为，用本阶段的令牌与组件结构重新表达。
>
> **方向修订提示。** 本阶段按**新版引擎内容模型**重新界定素材范围（CONTEXT §A/§F）：**不再有「合并成一张图、按行拆成多个素材」的细分**。因此**现有实现中的「切分图片 / 逻辑切分 / 图块顺序拖拽」界面不在本契约内**（见 §范围外）。

## Design System

| 项 | 值 |
|----|----|
| Tool | none（无 shadcn —— 这是基于 antd 的库包 `@motajs/editor-impl`） |
| Preset | 不适用 |
| 组件库 | **antd 6.2.1** —— 已是 `@motajs/editor-impl` 的 `peerDependency`（catalog 固定 `antd: 6.2.1`） |
| 图标库 | 无 —— 沿用 Phase 2 F1 结论：使用**内联 SVG** `ReactNode` 或**文案标签**；`@motajs/editor-impl` **未**声明 `lucide-react`（`lucide-react` 仅存在于 `@motajs/editor` 应用侧） |
| 字体 | 继承宿主 `font-family`；面板不自行声明字体 |

**为什么没有 shadcn（已裁定，非待定）。** `@motajs/editor-impl` 是工作区库，其 peer 栈由里程碑约束固定（`antd` + `@motajs/editor-core`）。CONTEXT D-08 把样式锁定为 **antd 组件 + 局部 CSS**，**不引入 PandaCSS、不引入新的运行时渲染依赖**。故 shadcn（Tailwind + Radix + 构建链）**被否决**。设计系统即 antd；样式层为同目录的普通 CSS。

> **门禁说明。** 本项目非 shadcn 工程（无 `components.json`），且前序阶段（Phase 1 / Phase 2）已就「不使用 shadcn」达成并记录结论，故本轮**不再重复询问**该门禁。

## Typography

**恰好 4 个字号 / 2 个字重**。字体族继承宿主（面板不声明）。

| 角色 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 16px | 600 | 1.2 | 面板空态 / 错误态标题；分类区大标题（替换现状 18 / 20px 的层级） |
| Heading | 14px | 600 | 1.3 | 详情标题（素材名）；配置表单 / 分区标题（替换现状 17px） |
| Body | 13px | 400 | 1.5 | 卡片名称；详情正文；操作 / 按钮标签；配置表单正文 |
| Label | 12px | 400 | 1.4 | 文件路径；文件计数；辅助 / 校验文字；缺失 / 逻辑提示 |

字重：正文 / 标签一律 **regular（400）**，标题一律 **semibold（600）**，无其它字重。

> 密度注：外壳（Phase 1）用 Body 14 / Label 13；素材面板与表格（Phase 2）一致地**下沉一号**（Body 13 / Label 12），以贴合现有编辑器的紧凑素材界面。

文本行为：单行文本默认**单行省略号**（`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`），全文经元素 `title` 属性揭示。素材名 / 路径可换行处用 `overflow-wrap: anywhere`（现状详情标题即如此）。

## Color

**浅色为本契约基准。** 面板**复用 Phase 1 外壳的 CSS 变量**（`--editor-*`，定义于 `packages/apps/editor/src/css/editor.css`），因此主题与外壳自动一致；面板以字面量作 fallback 消费这些变量。宿主可覆盖变量（含 `--editor-accent`）。

| 角色 | 值 | 用途 |
|------|----|------|
| Dominant (60%) | `#ffffff`（`--editor-surface`） | 素材网格背景（面板最大面积） |
| Secondary (30%) | `#f5f6f8`（`--editor-bg`）/ `#ffffff`（`--editor-toolbar-bg`） | 工具栏；分类导航表面；详情栏表面 |
| Accent (10%) | `#1677ff`（`--editor-accent`） | **保留 —— 见下方清单** |
| Destructive | `#d00`（`--editor-danger`，沿用现有 `.warnText` 红） | 仅破坏性 / 丢失性呈现 —— 见下方清单 |

**Accent 保留给（穷尽）：**
1. 当前选中的**分类导航项**（文字色 + 浅底色 `--editor-selected`）及其指示条。
2. **选中的素材卡片**边框与底色（`--editor-selected` 浅蓝）。
3. 「新增素材」主按钮（背景 + 标签）与「瘦身转码」主按钮。
4. 每个可交互控件（卡片、分类项、按钮、输入）的 `:focus-visible` 焦点环。
5. 聚焦输入控件的边框。

Accent **绝不**用于：默认文字、默认边框、网格背景、卡片默认底色，或「所有可交互元素」。

**Destructive 保留给（穷尽）：**
1. 「删除」按钮文字 / 图标，及其确认弹窗的确认按钮。
2. 「覆盖旧文件」确认弹窗的确认按钮与警告文案。
3. 会**丢失原文件**的转码二次确认。
4. 缺文件 / 加载失败的提示文字。

支撑中性色（取自 Phase 1 令牌集）：

| 令牌 | 值 | 用途 |
|------|----|------|
| `--editor-fg` | `#202124` | 主文字（素材名、详情正文） |

| `--editor-surface` | `#ffffff` | 卡片与网格表面 |
| `--editor-bg` | `#f5f6f8` | 面板滚动底衬 |

**深色变体（宿主覆盖，与外壳同组）：** `--editor-bg #242424`，`--editor-surface #303035`，`--editor-toolbar-bg #2b2b30`，`--editor-fg #d4d4d4`，`--editor-muted #9da5b4`，`--editor-border #4b4b52`，`--editor-selected #163a5f`。面板不设置主题，只读取变量。

## 素材管理器面板结构与交互契约

> 面板即本阶段交付物，故其结构与交互模型属于契约。`@motajs/editor-impl/asset` 对外导出**面板类型对象**（`assetPanelType`，经顶层注册进 Phase 1 外壳）+ **底层组件** + **默认素材选择器** + **内置 Schema 集**（D-01 / D-11）。能力包**不自行装配到 core**。

### 面板实例模型

- 面板内部持有**当前分类**状态（图片 / 音频 / 动画 / 字体），无全局「当前素材」概念。
- 素材的数据与字节**都经 `editor-core` 资源层**读写（D-04）：每个分类的 **`.list.jsonc` 列表文件 = 一个资源**（内容 = 该分类条目数组）；每个**素材字节文件各自是一个资源**；面板把「列表资源 + 字节资源」二者结合（D-05）。
- 面板在 `onSwitchIn` 时重新请求列表资源与字节资源（沿用 Phase 2 D-15 修订版「切入时刷新」）。
- 面板由 props 驱动；引擎在顶层**注入**分类清单、分类 → 目录 / 列表文件路径（按文件路径寻址资源）、配置表单描述与素材选择器能力（D-11 / D-12），面板**不读 React Context、不读宿主 / 引擎代码**。

### 布局（左 → 右、上 → 下）

```
┌──────────────────────────────────────────────────────────────────────┐
│ 工具栏 32px（--editor-toolbar-bg，下边框）                             │
│   分类标题 …                            [ 瘦身转码 ]   [ 新增素材 ]     │
├────────────┬─────────────────────────────────────┬───────────────────┤
│ 分类导航    │ 素材网格（自适应列，唯一滚动区）       │ 详情 / 预览栏 320px│
│ 184px      │  卡片 116×112                        │  预览（图/音/字/动画）│
│  图片       │  [缩略图 64×56]                      │  名称 + 路径        │
│  音频       │   名称（单行省略）                    │  缺失 / 提示        │
│  动画       │   [登记 / 缺失标记]                   │  [替换][删除][配置] │
│  字体       │  …                                   │                    │
│            │                                      │                    │
└────────────┴─────────────────────────────────────┴───────────────────┘
```

- 面板填满外壳内容区（`width/height: 100%`），列 flex；**素材网格是唯一滚动区**；工具栏与分类导航固定。
- 窄面板（`max-width` 断点，参照现状 980px）：详情栏折叠隐藏（现状即 `display: none`），保留导航 + 网格；分类导航宽度收窄（现状 156px，取整 156px 非 4 倍数 → 收窄为 **152px**）。

### 工具栏

| 控件 | 契约 |
|------|------|
| 分类标题 | 左侧 muted 文字，显示当前分类名；Label 角色，单行省略 + `title`。 |
| 「瘦身转码」`Button` | 打开瘦身转码弹窗（见 §瘦身转码契约）。当前分类为图片 / 音频时可用；动画 / 字体分类该按钮**隐藏或禁用**（不可转码）。 |
| 「新增素材」`Button` | 主按钮（`type="primary"`），最右。打开本地文件选择，上传一个文件（D-16）。 |

### 分类导航

- 一个固定项/已注入分类，**注册顺序**排列；本阶段固定四类：**图片 / 音频 / 动画 / 字体**（另有 `maps` 分类属地图能力，**不计入素材**，D-02）。
- 每项是一个全行按钮：`32px` 高、`sm` 水平内边距、`--editor-selected` 悬停 / 选中底色、accent 文字色（现状：`rgba(22,119,255,0.08)` 底 + `#1677ff` 字，等价映射到 accent 角色）。
- 当前项标记为选中（`aria-current`）；点击切换分类，网格与详情栏随之重取（切入时的资源请求）。

### 素材网格与卡片

- 网格：`display: grid; grid-template-columns: repeat(auto-fill, minmax(116px, 1fr)); gap: 8px`（现状 116px / 10px；间距取整为 8px，见 Spacing exceptions）。
- 卡片（现状 `.resourceCard`）：`112px` 高、`sm` 内边距、居中列布局、`7px` 圆角、默认底色 `rgba(128,128,128,0.055)`（浅灰，映射为中性表面）、`cursor: pointer`。为可聚焦交互元素（`<button type="button">` 或 `role="button" tabIndex={0}`），支持 Enter / Space 选中。
  - 悬停 / 选中：边框 `--editor-accent`、底色 `--editor-selected`。
  - **缺失**态（已登记但文件不存在）：边框暖橙、`--easset-missing-bg` 底、`--easset-missing-fg` 文字（现状保留）。
- 卡片内容：
  - **缩略图区** `64 × 56`：图片 → 位图预览（`image-rendering: pixelated`）；音频 → 音频图标；动画 / 字体 → 对应图标或文字；缺失 → 占位图标。
  - **名称**：Body/Label 角色，单行省略，`title` 揭示全名（现状 12px）。
  - **登记 / 缺失标记**：位于卡片右上角的小标记（见 F5）。本阶段**不保留**现状的「注册复选框」交互（新模型下登记 = 条目存在于 `.list.jsonc`，由配置与增删驱动）。
- 「新增素材」即向当前分类上传文件：写入新字节资源 + 往列表资源追加条目（D-16）。新条目默认值取自 `defaults/*.jsonc`；其中 `@required` 参与字段必需性校验（D-10）。

### 详情 / 预览栏

选中素材后，详情栏（`320px`）自上而下显示：

| 区块 | 内容 |
|------|------|
| 名称 | 素材名，Heading 角色，`overflow-wrap: anywhere`。 |
| 路径 | 资源路径，Label 角色、muted。 |
| 提示 | 缺失 → **「文件已登记，但工程目录中不存在。」**（`--easset-missing-bg`）；逻辑提示（若保留）用 `--easset-logical-fg`。 |
| 预览 | 图片 → 位图（`max-width:100%`、`max-height:372px`、pixelated）；音频 → `<audio controls>`（现状即内联播放器）；字体 → 样例文字（Body×2 放大：见 Typography，用 Display 16/600 或局部放大样式）；动画 → 占位 + 动画预览（现状 `AnimationPreviewEditor` 若保留）。 |
| 操作行 | **「替换」·「删除」·「配置」** 按钮（现状详情 `.resourceDetailActions` 的按钮样式：1px 边框、`5px` 圆角、透明底）。「删除」使用 `--easset-danger-fg`。未选中时显示 **「选择一个素材查看详情」**（现状 `.resourceDetailEmpty` 文案）。 |

- **替换**：打开本地文件选择，覆盖该素材的字节资源（原文件字节改动 → 见 §撤销屏障）。
- **删除**：弹确认 **「确定要删除该素材吗？此操作不可恢复。」**，确认后删除字节资源 + 从列表资源移除条目（字节改动 → 屏障）。
- **配置**：打开**每素材配置表单**（见下）。

### 每素材配置表单（复用 Phase 2 表格引擎，D-07）

- 配置表单**直接复用** `editor-impl/table` 的 JSON Schema 表格/表单引擎（同一网格、控件、校验、撤销提交路径）。其内部呈现规则属 Phase 2 契约，本文不重复；本文只约束**挂载形态**。
- **Schema 解析顺序（D-09）**：优先读取**引擎自带**的分类 Schema（每分类目录下一个**约定固定文件名**，如 `.schema.jsonc`）；读不到则**回退到内置 Schema**。内置两套：**legacy**（现有 `@motajs/editor` 旧素材模型）与**新引擎**（按新内容模型），由装配方按引擎选择注入（D-08）。
- **挂载形态（默认，见 F1）**：从详情栏「配置」进入后，配置表单**占据主区（网格 + 详情栏之间的整幅宽度）**，以让复用表格引擎获得足够宽度；主区显示「返回」/面包屑（**「← 返回素材列表」**）退回浏览态。工具栏与分类导航保持可用。
- 配置改动走 `editor-core` **统一撤销**路径，可撤销 / 可重做（D-13）；写盘经资源层异步持久化（内存优先、最终一致）。

### 撤销屏障（D-14 / D-15）

- **字节改动（新增 / 替换 / 删除）不可撤销** —— 记进历史但作为**屏障**：撤销碰到它即**停住**、返回 `false`。
- `editor-core` 的 **undo / redo 增加布尔返回值**：`false` = 无法执行，`true` = 成功（D-15）。
- 撤销命中屏障时，呈现提示 **「无法撤销」**（经 `antd` `notification` / `message` 或编辑器通知总线）。**不**跳过屏障去撤销更早的配置改动。
- 配置改动正常可撤销，无屏障。

### 状态

| 状态 | 呈现 |
|------|------|
| **加载** | 网格区居中 muted `Spin` + Label **「正在加载素材…」**；工具栏转码 / 新增按钮禁用。 |
| **空** | 无条目 → 居中 Display **「暂无素材」** + Label **「该分类下还没有素材，点击「新增素材」上传一个本地文件。」** |
| **错误** | 资源请求失败 → 居中 Destructive Display **「素材加载失败」** + Label **「请检查该分类的资源是否存在，或稍后重试。」** + **重试**按钮；面板保持打开。 |
| **部分** | 列表有条目但部分字节资源缺失 → 缺失卡片按缺失态渲染并显示缺失提示，其余正常；单个素材失败不拖垮整个网格。 |
| **未选中** | 详情栏显示 **「选择一个素材查看详情」**。 |
| **分类未注入** | 分类清单为空 → 空态 + muted 提示「尚无可用分类」。 |

### 溢出与长文本

- **纵向**：仅素材网格滚动；工具栏与分类导航固定。
- **横向**：网格 `auto-fill` 自适应列，卡片最小 116px，不产生横向滚动条。
- **长名称 / 路径**：单行省略 + `title` 全文；详情标题可换行（`overflow-wrap: anywhere`）。
- **大量素材**：网格纵向滚动；本阶段不契约虚拟化。

### 无障碍与内容安全

- 每个可交互元素都是真实可聚焦元素（`button` / `input` / antd 控件），带可访问名；分类项带 `aria-current`。
- 焦点顺序：工具栏 → 分类导航 → 网格卡片（左到右、上到下）→ 详情栏操作。
- **所有素材名 / 路径 / 提示文本经 React 文本节点渲染**，绝不 `dangerouslySetInnerHTML`（XSS 缓解）。
- 沿用现状 `data-test-id` 供 E2E（如 `data-test-id="resources-workspace"` 等；新面板的 test id 在实现时登记）。

## 素材选择器契约（D-12）

> `@motajs/editor-impl/asset` 提供**默认素材选择器**：自行按分类列素材、缩略图 / 播放预览、返回选中项，作为 asset 能力注入；表格、Blockly 等经接缝调用它（D-12）。它沿用 Phase 2 的**通用多选弹窗骨架**（`MultiSelectModal`：缩略图多选列表 + 固定「取消 / 确定」页脚），并增强素材专属预览。

- **宿主与形态**：复用 Phase 2 通用弹窗壳（`Modal` + `.eimodal-*` 样式族）。列表面板自身滚动，确认 / 取消页脚固定。
- **候选项列表**：每项 = 复选框 + 缩略图（`24px`，`object-fit: contain`）+ 标签（单行省略 + `title`），沿用 `.eimodal-item` / `.eimodal-thumb` / `.eimodal-label`。
- **分类**：选择器按分类列素材；图片取缩略图，音频取内联试听，动画取动画预览（现状 `SelectMaterial` 的「预览 / 折叠」与声效编辑若保留）。
- **状态**：错误态优先于加载态，其次空态（**「暂无可选项」**），最后列表；与 `MultiSelectModal` 的 `renderBody` 顺序一致。
- **多选 / 单选**：图片、动画等支持多选（现状 `multiple`），选中结果以 id 列表返回；`transform` 语义（如扩展名转换）由调用方或注入项决定。
- **搜索**：图片选择器可带搜索框（现状 `ImageAssetPickerModal` 的「搜索图片」）；若保留裁剪，裁剪编辑器沿用现状「拖拽框选 + X/Y/宽/高 数值 + 使用完整图片」。裁剪是否进入本阶段见 §范围外。

## 瘦身转码契约（D-19…D-22）

> 为推广新存储方案，面板提供两个**瘦身**动作：**图片 → WebP（可选 quality）**、**音频 → WebM 容器中的 Opus**（D-19）。音频转码使用 **Mediabunny**（纯浏览器、TypeScript、零依赖、基于 WebCodecs、支持 WebM 输出 + Opus、可 tree-shake，D-20）。需新增工作区依赖并进 catalog。

**入口**：工具栏「瘦身转码」（当前分类为图片 / 音频时可用的批量动作）。

**弹窗内容（`Modal`，宽 720px）：**

| 区块 | 内容 |
|------|------|
| 素材选择 | 当前分类素材列表 + 复选框（**批量**，D-21）；顶部「全选 / 全不选」（现状保留）。 |
| 参数（按分类） | **图片**：**「WebP 质量」** `InputNumber`（quality，0–100）。**音频**：**「码率」**、**「采样率」** `InputNumber`（用户可配置基础项，D-22）。 |
| 覆盖选项 | **「覆盖旧文件」** `Checkbox`，**默认勾选**（D-21）。 |
| 页脚 | **「开始转换」** 主按钮 + **「取消」**。 |

**行为：**

- **不勾「覆盖旧文件」** → 转换后新文件写入，**旧文件改名为 `{file}-origin.{ext}` 保留**（D-21）。
- **勾选「覆盖旧文件」**（默认）→ 点击「开始转换」后**弹出二次确认弹窗**，明确说明 **「原文件将被替换，无法找回。」**（D-21）；此确认弹窗为**破坏性**呈现（Destructive 角色），确认后才就地替换。
- 转换过程显示**进度**（批量逐项）；完成后通知 **「转码完成，共 N 个」**；单项失败不中断整批，失败项以 **「转码失败：{原因}」** 汇总。
- 转码**修改字节 = 不可撤销**，作为撤销屏障（见 §撤销屏障）。
- 转码按钮在当前分类不可转码（动画 / 字体）时**隐藏或禁用**，绝不做成静默失败的空操作。

## Styling Approach（已裁定）

**决定：antd 组件 + 同目录普通 CSS**（CONTEXT D-08）。组件结构与交互控件来自 `antd@6.2.1`（已是 `peerDependency`）；布局、网格、面板作用域装饰来自**随素材模块同目录发布的单个连字符命名样式表**（工作名 `packages/libs/editor-impl/src/asset/asset.css`，由面板 / 组件根引入）。面板仅通过 Phase 1 的 `--editor-*` 变量（含字面量 fallback）与 §Color 中记录的面板作用域 `--easset-*` 变量着色。**不引入 PandaCSS、Tailwind 或新的运行时渲染依赖**。

**本阶段无必需的配套工程改动（与前两阶段不同）：**

1. `packages/libs/editor-impl/package.json` 的 `"sideEffects"` **已为** `["./src/**/*.css"]`，新样式表会被保留，无需修改。
2. `editor-impl` 已有 `src/global.d.ts` 声明 `*.css`，普通 `import './asset.css'` 可通过 `tsc -b`。

**新增运行时依赖（非 UI 库，来自 CONTEXT）：** 音频转码引入 **`mediabunny`**（D-20），需新增 workspace 依赖并进 `pnpm-workspace.yaml` catalog。当运行环境不支持 WebCodecs 时，音频转码入口应**禁用并给出提示**，绝不静默失败。
