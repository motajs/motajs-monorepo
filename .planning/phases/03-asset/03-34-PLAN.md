<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 用户点击 → 列表数据 | 注销会永久丢弃配置，误触即不可恢复 |
| 界面 → 工程文件 | 「删除」删文件、「注销」只改清单，两者入口相邻，必须有强区分 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-34-01 | Tampering | 注销两次确认 | critical | mitigate | 第一次只切弹窗，第二次才回调；两个弹窗都禁用遮罩 / ESC 关闭；回归覆盖两次取消 |
