<objective>
把转码弹窗从「一串裸数字」改成「选档位 + 看说明」，并让单位跟着人话走（kbps / kHz）。

Purpose: 用户面对 128000 / 48000 这样的数字无从判断，也不知道压缩会让像素风素材发糊。预设档位 + 一句取舍说明 + 一句像素风说明能把这件事说清楚；自定义仍然保留，供愿意手填的人使用。
Output: 单位换算与预设解析两个纯函数、弹窗的四档预设界面、三段说明、以及重写后的弹窗回归。

做法：内部契约一个字不改（仍是质量 + bps + Hz），只在界面边界做 kbps / kHz 与档位的换算。
</objective>

    二、`resolveAudioPresetOptions(preset: AssetAudioPreset, custom: IAssetAudioCustomOptions): IAssetAudioTranscodeOptions`：`Custom` 时把 `custom.bitrateKbps` / `custom.sampleRateKHz` 经 `kbpsToBps` / `khzToHz` 换算（码率至少 1，采样率至少 1）；其余档位取预设表对应项再换算；找不到对应项时回落到 `ASSET_DEFAULT_OPUS_BITRATE` / `ASSET_DEFAULT_OPUS_SAMPLE_RATE`。
