<threat_model>
## Trust Boundaries

| Boundary | 描述 |
|----------|------|
| 素材字节 -> 浏览器预览 | 字节来自工程内容，经 `blob:` 地址进入 `<img>` / `<audio>` / `@font-face` |
| 素材路径 / 文件内容 -> CSS 字体族名 | 字体族名与 URL 被拼进 `<style>`；清洗不严会形成样式注入面 |
| 演示数据 -> 开发宿主 | 演示字体 / 图片是仓库内的样例资源，仅用于开发环境 |

## STRIDE Threat Register

| Threat ID | 类别 | 组件 | 严重度 | 处置 | 缓解措施 |
|-----------|------|------|--------|------|----------|
| T-03-61 | Tampering | `AssetFontSample` 的 `@font-face` | high | mitigate | 族名由 FNV-1a 生成 `asset-font-<hex>`，URL 只接受 `URL.createObjectURL` 产生的地址；文字走 React 文本节点，不用 `dangerouslySetInnerHTML` |
| T-03-62 | Information Disclosure | 卡片预览批量读字节 | low | mitigate | 只有图片 / 字体卡片读字节；音频 / 动画不读；`useAssetObjectUrl` 在换源 / 卸载时 `revokeObjectURL`；资源层仍有 LRU 上限 |
| T-03-63 | Denial of Service | 大字体 / 大图片进卡片 | medium | mitigate | 卡片图片限制 `max-width/height: 100%`、`object-fit: contain`，`loading="lazy"`；演示资源为 16×16 PNG 与单份字体 |
| T-03-64 | Elevation of Privilege | 预览实现触碰浏览器全局 | medium | mitigate | 只用 `URL` / `Blob` / React，不使用 `document` / `fetch` / `navigator`；`coreModuleState.js` 与 `coreImportType.js` 作为门禁 |
| T-03-65 | Spoofing | 演示字体来源 | low | accept | 直接复用工作区已存在的 Fira Code 字体文件，不引入第三方下载或新依赖 |
</threat_model>
