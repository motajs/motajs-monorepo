<objective>
让面板认识「文件夹里有、但没登记」的素材，并提供注册 / 注销这两个只改列表的动作。

Purpose: 现实项目的分类目录常与 `.list.jsonc` 不一致。用户需要看见这些文件、能把它们登记进游戏，也能把已登记的素材从清单里摘掉而保留文件。
Output: 扫描模型（纯函数 + 测试）、面板数据层的合并 / 注册 / 注销 / 写回过滤，以及一套数据层回归。

做法：扫描是纯逻辑（只吃 `listDirectory` 的结果与已登记名字），注册 / 注销只是改内存条目并标未保存；真正落盘仍然只有 `AssetPanel.save()` 一条路。
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 分类目录 → 面板 | 目录里的文件名来自工程内容，可能带怪字符、可能是备份或元数据文件 |
| 面板条目 → `.list.jsonc` | 未登记条目一旦泄漏进列表，游戏就会加载一个用户没打算登记的文件 |
| 注销动作 → 工程文件 | 注销与删除共用同一批条目，动作必须只改列表、不碰字节 |
