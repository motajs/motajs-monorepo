# Phase 04.1 Plan 19: 32 基准画布与整场景缩放 Summary

**同一份 13×13 的地图区从此固定是 416×416（150% 时 624×624），跟地图自己声明的格子大小无关；缩放也只是把整张画布等比放大，命中、滚动、标尺都跟着同一个倍率走，右侧素材区拿剩余宽度、只保底 240、不再有上限。**

## Accomplishments

- **画布尺寸与地图声明彻底脱钩**：`resolveMapLayout` 不再接文档，画布 = 视口格数 × `MAP_DISPLAY_CELL_SIZE`（32）× 缩放。13×13 在 50% / 100% / 150% / 200% 下分别是 208 / 416 / 624 / 832；15×9 是 480×288。48×48 与 32×32 的文档得到同一个画布。
- **缩放变成「整场景倍率」**：渲染模型的 `cellWidth` / `cellHeight` 恒为 32，缩放单独作为 `renderScale` 上报；`MapSurface` 在每次绘制前 `scene.scale.set(renderScale)`，`MapCanvas` 用「32 × renderScale」做命中、滚动、内容尺寸与标尺刻度。
- **素材区拿剩余宽度、取消上限**：`paletteWidth = max(240, 可用宽度 − 画布宽)`。可用 1200 → 784，600 → 240（地图区 360，允许横向滚动），3000 → 2584。过渡常量 `MAP_PALETTE_MAX_WIDTH` 与 `Math.min` 夹取一并删除。
- **新增面板宽度测量**：`useMapElementWidth` 只量宽度（`ResizeObserver` + 首次 `getBoundingClientRect`），量不到返回 0，布局据此回退 320；宽度不变不触发重渲染。
- **契约收紧**：`IMapLayout.renderScale` / `IMapLayout.mapPaneWidth` / `IMapRenderModel.renderScale` 改为必填，过渡用的 `?? 1` 全部删除。
