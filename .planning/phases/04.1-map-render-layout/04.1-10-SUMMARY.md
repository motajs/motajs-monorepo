## Accomplishments

- **度量定位收口。** `MapSurface` 不再 import `MAP_CELL_SIZE`（文件里 0 处命中）。坐标换算只有 `toCanvasX` / `toCanvasY` 两处：普通模式是 `(格坐标 − viewport) × 格尺寸`，大地图是 `偏移 + 格坐标 × 缩略比例`；格像素宽高由相邻两个格坐标的换算结果相减得到，因此画布里没有第二份格尺寸来源。通行度、框选、预览、悬停、整条路径全部走这一对函数。
- **G-04-2 收口。** 通行度不再画整圆白底：每个被阻挡方向单独一支箭头，颜色由 `resolvePassArrowColor(MapDirection.X)` 映射到 `MAP_PASS_COLOR_UP/RIGHT/DOWN/LEFT`，每支自带 1px 深色描边，箭头长度 = `min(格宽, 格高) / 2 − 1`，四支同时出现也互不重叠。大地图缩略格小于 16px 时按 Plan 07 的显式例外降级为单色点（`MAP_PASS_COLOR_UP`）。
- **整条路径真的画出来了。** 新增 `drawPreviewCells` 并在 `drawModel` 里调用：普通模式用 `resolvePreviewCellRects(previewCells, model.viewport!, model.cellWidth!, model.cellHeight!)` 取矩形，逐格画 35% 填充 + 1px 描边；大地图模式改用 `thumbnail.scale` 与 `offsetX/offsetY`，不叠加 `model.viewport`。
- **动画只有一个时钟。** `Application.ticker` 用 `UPDATE_PRIORITY.HIGH` 注册回调（早于 Pixi 自己的渲染），把 `ticker.elapsedMS` 累加后交给 `resolveFrameTickAt(elapsed, props.cellFrameSpeed ?? MAP_FRAME_SPEED_DEFAULT)` 换全局帧号，再对每个动画格调用 `resolveCellFrame(defaultFrame, tick, frameCount)`。只有帧号变化的格子改 `sprite.texture`；静态格不重建、不销毁。画布里没有 `Math.floor(elapsed / 300)` 这类自算时间。
- **自动元件四块。** `autotileQuarters` 存在的格子建 4 个精灵，按 `lt → rt → rb → lb` 顺序 `addChild`，各占目标格一个象限（宽高各半）；多帧自动元件把四块的源矩形按 `frameIndex × frameStride` 一起横向平移，因此演示宿主里 2 帧的自动元件会真的动。
- **大地图缩略纹理。** `model.thumbnail !== undefined` 时建一张 `RenderTexture`（尺寸取 `thumbnail.textureWidth/Height`），把 `props.document` 的图层按 `zIndex` 从低到高铺进离屏容器（每格 1 源像素 / 格，高于当前层的层用 `aboveLayerOpacity`），`renderer.render({ container, target })` 后把纹理当**一张 Sprite** 按 `thumbnail.width/height` 摆到 `offsetX/offsetY`；临时容器与临时纹理当场销毁。`props.document` 缺失时只画一块缩略底色，不抛错。
- **帧纹理与缩略纹理全在 ref 里。** 帧纹理按 `格子 key : 帧号` 缓存在 `useRef` 的 Map，缩略纹理与它的重建依据（文档引用 / 当前层 / 上层不透明度 / 纹理版本）也在 `useRef`；模块顶层没有任何缓存，`node scripts/verify/coreModuleState.js` 通过。

## Decisions Made

- **坐标换算只有一处。** 格像素宽高不是另存一份 `model.cellWidth!`，而是 `toCanvasX(model, 1) − toCanvasX(model, 0)`：宽高与定位永远同源，缩放 / 大地图比例变化不会出现「格子画 48、悬停框 32」。
- **大地图缩略重建多一项「纹理就绪版本」。** 图片是异步读到的；只按文档 / 图层 / 不透明度比较，首帧拿不到纹理的缩略图会永远空白（见 Deviations 第 1 条）。
- **大地图的可读图片路径同时来自文档目录。** 大地图的 `cells` 是空的，只按 `cells` 收集路径会让缩略纹理一张图都拿不到（见 Deviations 第 2 条）。
- **缩略纹理按图块编号缓存裁切结果。** 同一编号只裁一张纹理，256×256 逐格铺内容时纹理对象数量只与编号数有关，精灵仍是一格一个（一次性、可回收）。
- **有动画格才启动 ticker。** 没有动画就 `ticker.stop()`，静态地图不再每帧空转渲染；重画后把上一次帧号重置为 -1，让第一帧回调立刻把动画格对齐到当前时钟。
