## Decisions Made

- 放大开关放在共用函数上而非另写缩略路径：保住 D-57「缩略与普通模式共用同一套逐格逻辑」的既有口径。
- 蒙版用纯黑 + 0.7 而非半透明彩色：按用户口径只压暗底图，四色箭头本身负责表达方向。
- 面板根只压自身轮廓，不写全局 `*:focus`：避免键盘用户失去真实控件的焦点提示。
- 箭头头长保留既有「不超过全长一半」的夹取，因此 32×32 下实际为 7.5px（常量上限 8px 只在更长箭头上才生效）。

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] 计划给的箭头头长期望与既有夹取规则冲突**
- **Found during:** Task 2（通行度纯黑蒙版 + 箭头放大 2px）
- **Issue:** 计划要求 `resolvePassArrowHeadLength(15)` 等于 8，但该函数现有不变式是「不超过全长一半」，15 / 2 = 7.5，实际返回 7.5。若强行改成 8 就必须改算法本身，超出本计划「只加大约 2px」的意图。
- **Fix:** 不改函数算法，只把测试改为断言真实值：常量上限用 `resolvePassArrowHeadLength(16) === 8` 证明，32×32 的实际头长断言为 7.5，并保留「三角底 7.5px > 半宽 3.5px」的不重叠证明。
- **Files modified:** `packages/libs/editor-impl/src/map/__tests__/model.passability.test.ts`
- **Verification:** `model.passability.test.ts` 23 tests passed；typecheck exit 0。
- **Committed in:** `c934928`（Task 2 commit）

**2. [Rule 1 - Bug] 普通模式回归断言的换行不符合 Prettier**
- **Found during:** 计划级 `pnpm lint`
- **Issue:** `buildMapRenderModel(...)` 被手写成跨行调用，触发 `prettier/prettier` error（printWidth 120 下应单行）。
