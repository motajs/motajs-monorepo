## Decisions Made

- **编号来源分两条路：** 普通素材（grid / rowAnimate / columnAnimate / scanAnimate / full）只从纹理清单的 `map` 数组取编号；自动元件与 Tileset 才用 `identifier` 与 `tilesetBase` 枚举。`read` 只决定帧怎么排，不改变编号来源。
- **Tileset / 自动元件强制 `Grid`：** `Full` 会让 `resolveFrameInfo` 返回整张图集尺寸，Tileset 的逐格编号会退化成一整块；测试逐组断言 `read === MapTextureReadType.Grid`。
- **大素材 192×64 而非 64×64：** 96×64 在 48×48 格里 contain 后是 48×32、上下各 8px；64×64 会正好填满，留空就永远观察不到。
- **引擎文本落在 `content/map/**`：** 演示宿主需要「项目里真的存在引擎文件」，但 `content/texture/.list.jsonc` 已被素材面板占用；改放 `content/map/texture/.list.jsonc` 与 `content/map/tiles.jsonc`。
- **删除 `recentTilesPath` 注入：** 路径唯一由 `MAP_TILE_PREFS_PATH` 决定；面板回退值（`.editor/map-recent-tiles.json`）与开发宿主原先注入的值相同，行为不变。
