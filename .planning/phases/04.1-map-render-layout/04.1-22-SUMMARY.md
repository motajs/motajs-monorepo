## Accomplishments

- 收藏栏每格不再画图块编号，改画键位角标：第 i 个收藏格显示 `MAP_FAVORITE_SLOT_KEYS[i]`，依次 `2 3 4 5 6 7 8 9 0`；擦除格显示 `1`。这套数字与 `MapCanvas` 键盘映射逐条核对过：`1` → 擦除、`2..9` → 第 1..8 个收藏、`0` → 第 9 个。
- 收藏格加了 `emap-favorite-tile` / `is-favorite` 类：图块 32×32 不变，内描边 `inset 0 0 0 1px rgba(0,0,0,.35)`，左下角键位角标深底白字、`pointer-events: none`，不挡点击与拖拽。
- 删除上移 / 下移两个 `Button` 及其 `reorderDisabled` / `onReorder` 传递；`antd` 的 `Button` 导入一并删掉。拖拽状态机（pointerdown / enter / up）原样保留，`types.ts` 未改。
- 「最近使用 / 最常使用 / 收藏」三页的格子只画缩略图；`title` 与 `aria-label` 改用目录里的图块名（`图块 1`），查不到或名字为空时显示「未知图块」。`data-test-id`、`data-frame-rect`、`aria-pressed`、点击行为全部不变。
- 测试从 33 条涨到 35 条：删掉上下按钮用例，换成「按钮确实不存在」；新增键位断言（`2` / `9` / `0` / 擦除 `1`，且可见文本只有键位字符）与底部格「无文本 + title 是图块名」断言。

## Decisions Made

- **键位常量与键盘映射单点对齐。** `MAP_FAVORITE_SLOT_KEYS = ['2'…'9','0']`，`MapCanvas.handleKeyDown` 的 `0 → MAP_FAVORITE_SLOT_COUNT(9)`、`n → n-1` 正好映射到 `onSelectSlot(9)` / `onSelectSlot(n-1)`，与角标一一对应（T-4.1-22-01 的缓解措施）。
- **描边用 inset 而不是 outline / 外圈。** `.emap-material-cell.is-selected` 的 2px 外圈在文件里位置更后、特异性相同，会自然覆盖描边的 `box-shadow`，选中态仍然清楚。
- **底部格不加 `emap-bottom-tile` 类。** 计划给了「加类就必须有对应 CSS」的选项；不渲染文字后没有任何需要的排版规则，索性不加，避免死类名。
