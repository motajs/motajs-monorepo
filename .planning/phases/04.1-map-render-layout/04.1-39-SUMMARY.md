# Phase 04.1 Plan 39: 工具栏换行与地图区比例控件宽度 Summary

**「地图区比例」容器改为最小 208px、滑块轨道固定 96px 不再收缩，第二行编辑工具加独立换行类：放不下时整行换行、顶栏长高，第一行与缩放行为零改动**

## Accomplishments

- 「地图区比例」控件不再被压扁：容器定住 208px 最小宽度，滑块轨道 `flex: 0 0 96px` 无法再被压缩，标签与百分比也都不参与收缩。
- 第二行编辑工具放不下时整行换行、顶栏跟着长高：新增 `.emap-toolbar-edit-row`，只挂第二行，`flex-wrap: wrap` + `height: auto` + `overflow: visible`。
- 第一行保持单行、顺序不变，`MapZoomSlider.tsx` / `constants.ts` / props / `data-test-id` 全部零改动。
- 新增 8 条断言（4 条规则静态断言 + 1 条规则顺序 + 1 条 DOM 类名 + 1 条行为不回归 + 1 条百分比不收缩），复用已有 `ruleBody`，不引入 `getBoundingClientRect` / `getComputedStyle` / snapshot。

## Decisions Made

- **208px 的取值口径**：标签「地图区比例」约 60px + 两个 4px 间隙 + 轨道 96px + 百分比最小 38px = 202px，取 208px 留余量；写进 CSS 注释，避免以后有人改回固定宽度。
- **换行只挂第二行**：第一行是地图身份，版面已被 U-01 锁定；换行规则写成独立类而不是改基类 `.emap-toolbar-row`，这样第一行仍然单行、超宽照旧裁剪。
- **测试只钉规则与类名**：jsdom 不排版，不用 `getBoundingClientRect` / `getComputedStyle` 伪造像素证据；真实观感交给 04.1-31 的 U-35 人工验收。
