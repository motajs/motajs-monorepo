# Phase 04.1 Plan 27: 素材分类导航（六类同一排）Summary

**Tileset 从一个「特殊开关」变成正经的第六个分类：六类按钮同一排等宽铺满、按钮之间画竖线，同时把多余的 `tilesetOpen` 状态整套删掉，改由「当前分类是不是 Tileset」决定素材区显示什么**

## Accomplishments

- 分类导航现在是一排六个等宽按钮：`MAP_CATEGORY_NAV_ITEMS` 追加 `{ MapTileCategory.Tileset, 'Tileset', 'tileset' }`，末尾那个专属按钮和 `.emap-category-tileset` 样式一起删掉；Tileset 的测试标识变成 `map-category-tileset`，与其余五类同一套规则生成。
- 排布按 U-13 改到位：`.emap-category-nav` 用 `justify-content: space-around`（并删掉 4px 间隙），`.emap-category-item` 用 `flex: 1 1 64px` + `min-width: 64px` 等宽铺满，新增 `.emap-category-item + .emap-category-item { border-left: … }` 画相邻竖线；配色三条（`:hover` / `.is-selected` / `:focus-visible`）一字未动。
- `tilesetOpen` 一族彻底消失：`IMapPanelViewState.tilesetOpen`、`MapPanel.toggleTileset`、`IMapPanelViewProps.onToggleTileset`、`IMapMaterialPanelProps.tilesetOpen` / `.onToggleTileset`、`IMapCategoryNavProps.tilesetOpen` / `.onToggleTileset`、`map-tileset-toggle` 全部删除；素材区只剩 `props.activeCategory === MapTileCategory.Tileset` 一个判据。
- 测试补齐「六类都在 + 旧开关不存在 + 点 Tileset 进、点地形出」三条护栏，并把五条 Tileset 视图用例改成用 `activeCategory` 驱动；CSS 断言换成 `space-around`、`flex: 1 1 64px`、相邻竖线三条。

## Decisions Made

- **局部变量改名 `isTilesetView`**：计划正文写的是保留 `const tilesetOpen = …`，但同一条 `verify` 又要求文件里不出现 `tilesetOpen`；改名后既符合「唯一真源」语义，也能通过反向 grep。
- **`activeCategory` 的 JSDoc 补一句「它同时是当前素材视图的唯一真源」**：把 D-47 的口径写进类型定义源头，后续新增分类时不会再引入第二个开关。
- **三个额外测试夹具一并修掉**：它们是 `IMapPanelViewState` 字面量，字段删除后 typecheck 会直接报错；这属于删字段的连带修改，不是范围扩张。
