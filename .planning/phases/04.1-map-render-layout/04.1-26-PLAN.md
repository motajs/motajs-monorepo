<objective>
把地图区改成「标尺 + 画布、只有一个滚动容器、宽度把标尺算进去」，并把尺寸控制收敛成一条链：滑块（改名「地图区比例」）驱动地图区大小，宽 / 高数字框只在失焦或回车后改可见格数，任何区域都不设最小 / 最大尺寸。

用大白话说：现在地图区套了两层框、两层都能滚，量宽度时又漏掉了左边那条 20 像素的标尺，所以画面会被挤出一条多余的滚动条、右边素材区也算不准。这一步把两层框合并成一层：外框严格等于「标尺 + 画布」、自己不滚；只有画布里面的内容超出可见格数时才在画布内部滚。同时把「缩放」这个词改成「地图区比例」（它其实是在调地图区多大，不是缩放画面），并把宽 / 高两个输入框改成「输完、按回车或点别处才生效」，不再边打字边跳。

Purpose: 修 U-11 / U-14（双层滚动、宽度没算标尺）、U-15（输入即生效），并落实用户确认的布局模型（D-43 / D-44 / D-45 / D-46）。

Output: 一个不再出现第二层滚动条、宽度含标尺的地图区；一个叫「地图区比例」的滑块；两个只在 blur / Enter 提交的数字框；以及同步更新的三层测试。
</objective>
