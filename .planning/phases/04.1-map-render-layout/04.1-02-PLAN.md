<objective>
先用一条最短的完整路径把「每张地图自己的格子尺寸 + 大素材 contain」打通：文档说格子多大 → 渲染模型算出每格画成多大 → 画布照着画。

用大白话说：以前整个编辑器只认 32 像素一格，现在每张地图可以自己定格子大小；格子不是正方形时，大图块要按比例缩进格子里、小图块保持原样、都居中。这一条链路先跑通并被测试盯住，后面加动画、自动拼接、Tileset 才有共同的地基。

Purpose: 这是本阶段的 tracer bullet —— 一条贯穿「文档 → 纯模型 → 视图 → 画布」的垂直切片。它先把最容易错的度量问题证明清楚，后续所有渲染能力都从这条已证明的路径长出来。

Output: `cellMetrics.ts` 纯函数、渲染模型按文档格尺寸产出 contain 目标矩形、画布 / 视图不再用固定 32 推导尺寸、两个测试文件与夹具扩展。
</objective>
