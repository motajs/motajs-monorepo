# Phase 04.1 Plan 40: 地图区比例标签右间距 Summary

**「地图区比例」标签右侧补 6px 外边距，连同容器 4px 间隙共 10px：滑块手柄拖到最左端不再压住最后一个字，轨道宽度与拖动行为一点没动**

## Accomplishments

- 标签不再被压：`.emap-zoom-label` 里加了一条 `margin-right: 6px`，加上容器原有的 `gap: 4px` 共 10px——这个 10px 跟 U-22 修「层不透明度」滑块时用的间距完全一样，是已经验证过够用的值。
- 取值注释同步了：`.emap-zoom` 上方的 208px 加法改成 `60 + 6 + 4 + 96 + 4 + 38 = 208`，并写明这 6px 是给滑块手柄留的、与 U-22 同口径。
- 滑块一点没动：轨道仍 `flex: 0 0 96px` + `width: 96px`，百分比仍 `min-width: 38px`，容器仍 `gap: 4px` + `min-width: 208px`，`MapZoomSlider.tsx` / `MapToolbar.tsx` / `constants.ts` 零改动。
- 新增 4 条断言（标签右间距 / 容器间隙与最小宽度 / 轨道 96px / 标签紧邻轨道之前），复用已有 `ruleBody`，不引入 `getBoundingClientRect` / `getComputedStyle` / snapshot，也没有改写 `04.1-39` 已写的用例。

## Decisions Made

- 间距加在标签右侧而不是滑块左侧：用户明确指定（对 D-58 的补充），且能保持轨道与百分比位置不变。
- 6px 这个数值不是拍的：滑块手柄最左端向轨道盒子左侧溢出约 5px，6px + 4px = 10px 与 U-22 已验收的口径一致。
- 容器宽度与最小宽度不改：新加法正好等于原来的 208px，改反而会破坏 `04.1-39` 的结论。
- 不用省略号 / 缩字号 / 负 margin / 绝对定位「腾地方」：那样只是把字藏起来，不是让它完整可读。
