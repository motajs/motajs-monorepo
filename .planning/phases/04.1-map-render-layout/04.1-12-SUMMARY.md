# Phase 04.1 Plan 12: 右侧素材区取代旧调色板 Summary

**右侧素材区现在有六类入口：五类普通素材按分类竖排、每格一张只显示第一帧，Tileset 单独开关后整图分格、可单点或框选多格；旧的 240px 三段式调色板和它的测试已彻底删除。**

## Accomplishments

- 新增 `MapCategoryNav`：地形 / 敌人 / 人物 / 物品 / 自动元件五类竖排，Tileset 作为最后一个独立开关；选中态用 `is-selected`，测试标识为 `map-category-{slug}` 与 `map-tileset-toggle`。
- 新增 `MapMaterialPanel`：顶部「显示帧数」勾选框（`map-frame-count`），按分类过滤素材组，组名 + 网格（`map-material-grid`）；每格一张（`map-tile-{number}`），第一帧矩形由 `resolveFrameInfo` + `resolveFrameRect(info, 0)` 现算，素材框内联与 CSS 都是直角。
- Autotile 只渲染源图左上角那一格，背景矩形是完整的 `(0, 0, cellWidth, cellHeight)`；不调用 `resolveAutotileQuarters`，不展开 3×4 / 2×3。
- 帧数角标（`map-tile-frames-{number}`）只在勾选「显示帧数」且帧数 > 1 时出现，取消勾选立即消失。
- 新增 `MapTilesetPicker`：整图作背景、按 Tileset 自身 `cellWidth` / `cellHeight` 画 1px 半透明分格线；单击得 1×1 图案，拖动得行主序多格图案，缺格填 0，主图块取左上角；不逐格建 DOM。
- `MapPanelView` 把 `.emap-side` 的内容换成 `MapMaterialPanel`，原样透传 `props.onSelectCategory` / `props.onToggleTileset` / `props.onToggleFrameCount` / `props.onSelectPattern` / `props.onRetryImages`，没有直接调用 `MapPanel`。
- 删除 `MapPalette.tsx` 与 `mapView.palette.test.tsx`，`components/index.ts` 不再导出旧组件；清理只属于旧三段式的 CSS（擦除格 / 最近使用 / 分组折叠 / 旧右栏占位）。
- 宿主端到端测试改用 `map-tile-{number}` 与 `map-material-grid`，并保留「点图块 → 落笔 → 置脏」的断言；没有再引用本波次不存在的 `map-favorite-erase`。

## Decisions Made

- 分类导航内置在 `MapMaterialPanel` 里：`IMapMaterialPanelProps` 已经带了 `activeCategory` / `onSelectCategory` / `onToggleTileset`，侧面只挂一个组件即可，避免导航渲染两次。
- 空目录提示放在素材区主体，因为 `IMapCategoryNavProps` 没有目录字段、无法判空；没有为此新增接口成员。
- 点普通分类时若 Tileset 正展开，导航顺手收起（仍只调用已声明的 `onSelectCategory` / `onToggleTileset`），否则用户会被留在 Tileset 视图里。
- 帧数角标取 `resolveFrameInfo(...).count`；`Grid` 读取方式恒为 1，所以只有 `RowAnimate` / `ColumnAnimate` / `ScanAnimate` / Autotile 会出角标。
- 模块级分类清单改为 `Object.freeze([...])`，既保持只读，也满足 `coreModuleState` 对模块级容器的门禁。
