<objective>
让数字键 `1` / `2`..`9` / `0` 在**整个地图面板内**都生效（不再只在画布聚焦时生效），并把「显示帧数」角标的初始状态改成默认打开。

用大白话说：上一轮已经把「按数字选收藏位」的处理从画布挪到了面板根，但漏了一件事——**键盘事件只会沿着「当前有焦点的那个元素」往上冒泡**。面板根是个普通 div，本身不能接受焦点；点画布、点图块按钮时焦点落在子元素上，事件能冒上来；可点工具栏空白、素材区空白、底部栏空白时，焦点还留在网页最外层，按数字自然没人接。这一步给面板根加上「可以接受焦点」的能力，并在你点面板空白处时把焦点放到面板根上，于是面板内任何位置按数字都有效；同时明确「点输入框、点按钮、点画布、点滑块时不许抢焦点」。顺带把「显示帧数」从默认关闭改成默认打开。

Purpose: 修 U-26 与 U-27。U-26 不是「监听位置不对」，而是「事件根本到不了监听器」；U-27 是「初始视图状态的一个布尔值」。

Output: 面板根可聚焦 + 空白处落焦点 + 焦点归属判断，`MAP_SHOW_FRAME_COUNT_DEFAULT` 常量改成 `true`，以及钉住这两件事的测试。
</objective>
