<objective>
把「切走就自动保存」变成 `editor-core` 的硬契约：外壳在切换 / 关闭 / 替换 / 注销面板之前**按顺序等待**面板的落盘钩子结算完，再让下一个面板切入或释放旧面板；并在类型层写清「`onSwitchOut` 是唯一落盘点、`onBeforeClose` 不再用来问未保存」。

用大白话说：以前的想法是「用户想关的时候弹个框问要不要保存」。现在改成「你只要离开这个面板，编辑器就自己把改动存好了」。但光靠每个面板自己记得保存还不够——外壳现在是「通知一声就走」，保存还没写完，面板可能已经被释放了。这一步把外壳改成「等它存完再走」，并用测试钉死这个顺序。

Purpose: 本轮唯一的**跨包行为契约**。它决定 U-08「所有面板切走即保存」能不能真的成立，也决定表 / 素材 / 地图三个面板的保存时机是否一致。

Output: 串行切换链、关闭 / 替换前的落盘等待、两个钩子的契约文档、以及一组专门验证保存顺序的 core 测试。
</objective>
