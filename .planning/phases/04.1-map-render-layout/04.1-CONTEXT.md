# Phase 4.1: 地图渲染与布局重做 - Context

**Gathered:** 2026-10-22
**Status:** Ready for planning
**Note:** 本阶段是在 Phase 4 之后插入的紧急阶段（`(INSERTED)`），依赖 Phase 4。它把 Phase 4 的地图能力从「能打开、能画、能存」补齐到「能当编辑器用」，并收口 Phase 4 UAT 发现的三个问题。Phase 4 的 `04-UAT.md` 仍有 3 条问题，全部并入本阶段（见 D-23…D-26）。

<domain>
## Phase Boundary

本阶段交付「地图渲染、素材区与布局重做」，作为 `@motajs/editor-impl/map` 的下一版默认实现：

- **渲染**：每张地图可配 `cellWidth / cellHeight`；大素材保持宽高比 contain 到格内、小素材保持原尺寸；图块动画（最多 255 帧）；自动拼接（3×4 与 2×3，含动画）；Tileset 整图分格；大地图整图缩略纹理。
- **素材区**：右侧六类素材（Terrains / Enemy / Npc / Item / Autotile / Tileset），普通类型竖排分类，Tileset 单独开关；逐格拆分、只显示第一帧；可选显示帧数；直角矩形；Tileset 整图带分割线。
- **布局**：左侧地图 + 底部「最近使用 / 最常使用 / 收藏」三页；右侧全部素材；地图视口全局默认 13×13（可配、可长方形）；50%–200% 缩放滑块，同时调整地图缩放与左右栏宽比。
- **交互**：删除工具栏四向按钮与键盘方向键/WASD；线模式显示整条路径；属性抽屉不点外部关闭；收藏栏（1=擦除 + 9 格，拖拽排序，持久化）。
- **修复 Phase 4 UAT**：演示图集整片红、通行度红十字、属性抽屉塌成灰线。

**本阶段不做：**

- 点事件 / 事件叠加 / 事件编辑器（Phase 6）。
- 图块属性编辑（仍属图块 / 素材配置能力）。
- 图层重命名 / 排序 / 删除 / 图层设置。
- 插件加载 / 注册机制。
- 1024×1024 地图（本阶段先按 256×256；稳定后再评估）。

## Implementation Decisions

### A. 数据来源与注入

- **D-01:** **宿主解析引擎文件，生成中立的图块目录**交给地图面板。面板不认识 `texture/.list.jsonc`、`tile.jsonc`，也不读这些文件；换引擎只换宿主适配器。 — **Reversibility:** one-way —— 这是地图能力与宿主的主数据契约，改形状要迁移每个宿主实现。
- **D-02:** 目录给**原始素材 + 规则**，不是切好的帧：图片路径、读取方式（`Full` / `Grid` / `RowAnimate` / `ColumnAnimate` / `ScanAnimate`）、切分尺寸、图块编号列表、帧数、自动拼接类型与连接、Tileset 元数据。**编辑器自己切片、自己展开自动拼接**。 — **Reversibility:** costly —— 切片 / 自动拼接算法与目录形状互相绑定。
- **D-03:** **复用素材数据，不复用素材面板 UI**：宿主从同一份素材数据生成图块目录；右侧素材区由地图能力自己渲染。`map` 不 import `asset` 能力（能力互斥门禁）。 — **Reversibility:** costly —— 数据源与 UI 所有权一旦被两个能力共用，再拆分要迁移调用方。
- **D-04:** **每张地图一份 `cellWidth / cellHeight`**，放在中立地图文档里；不是全局设置。 — **Reversibility:** costly —— 影响地图文档、渲染模型、命中测试、Tileset 切分。
- **D-05:** 图块分类固定为六类：**Terrains / Enemy / Npc / Item / Autotile / Tileset**。`tile.jsonc` 里将要删除的类型不使用；`Animate` 归到 Terrains，不再单独一类。 — **Reversibility:** costly —— 分类决定素材区导航与图块目录分组。
- **D-06:** **自动拼接的连接规则由宿主注入**：宿主给出每个自动元件单方面连接到的图块编号；编辑器实现通用 8 方向连接与 3×4 / 2×3 贴图选择，**不判断“墙壁”**——对编辑器来说不存在墙壁概念。 — **Reversibility:** costly —— 连接语义是自动拼接渲染的输入契约。

### B. 渲染

- **D-07:** **大素材 contain**：保持宽高比缩到完全放进格内，水平、垂直居中（上下或左右留空）；**小素材保持原尺寸**，同样居中。该行为与引擎默认不同，是编辑器为了实用性做的选择。 — **Reversibility:** costly —— 影响所有图块的绘制尺寸与命中范围。
- **D-08:** **动画**：帧数、读取方式来自图块目录；默认 **300ms/帧**，宿主可传数值覆盖；**不提供 UI 配置**；最大 255 帧。 — **Reversibility:** costly —— 动画时钟与渲染循环耦合。
- **D-09:** **自动拼接 3×4（48 帧）与 2×3（24 帧）都要做**，支持动画；编辑器实现通用算法，宿主注入连接。 — **Reversibility:** one-way —— 自动拼接的展开/连接算法一旦被宿主与测试依赖，改语义要迁移全部地图。
- **D-10:** **Tileset**：整图展示、按 `cellWidth / cellHeight` 分格并画分割线；可单格，也可框选多格；框选后画布显示同尺寸矩形预览。 — **Reversibility:** costly —— 选择 / 绘制 / 剪贴板都依赖 Tileset 多格语义。
- **D-11:** **大地图 = 整图缩略纹理**：进入大地图时把整图预渲染成一张缩略图，降采样显示；普通模式只构建可见格。先按 **256×256** 上限；稳定后再考虑 1024×1024。 — **Reversibility:** costly —— 大地图渲染路径与普通路径分离。
- **D-12:** **通行度显示 = 四色箭头，不加图例，不填充格子**。四个方向用不同颜色；具体色值由实现选一组在深浅图块上都可读的颜色。 — **Reversibility:** reversible —— 纯叠加层视觉。
- **D-13:** **删除工具栏四向按钮与键盘 `↑↓←→ / WASD`**；视口改用滚动条 / 滚轮。 — **Reversibility:** reversible。
- **D-14:** **线模式拖动时显示整条路径的所有点**，不是只显示鼠标所在格。 — **Reversibility:** reversible。
- **D-15:** **地图属性抽屉禁用点外部关闭**，保留右上角 ✕ 与 Esc。 — **Reversibility:** reversible。

### C. 布局与素材区

- **D-16:** **地图视口是编辑器全局设置**：默认 **13×13**，可配置、允许长方形。缩放滑块 **50%–200%**，默认 100%，debounce；同时调整地图渲染缩放与左右两栏宽度比例，并保证素材区最小可用宽度。 — **Reversibility:** costly —— 布局与缩放状态被面板、画布、素材区共同消费。
- **D-17:** **左侧 = 工具栏 + 地图 + 底部三页「最近使用 / 最常使用 / 收藏」；右侧 = 全部素材区**。 — **Reversibility:** costly —— 面板结构与测试选择器。
- **D-18:** 素材区：**普通类型竖排分类**（Terrains / Enemy / Npc / Item / Autotile），**Tileset 单独列出一个开关**；除 Tileset 外逐格拆分、只显示第一帧；素材框用**直角矩形**（避免圆角裁掉边角）；可选勾选「显示帧数」，打开后在素材右上角用小字显示帧数。 — **Reversibility:** reversible —— 纯视图与交互布局。
- **D-19:** **收藏栏**：`1 = 擦除`，`2–9`、`0` 共 **9 个收藏**，总计 10 格；**右键普通图块收藏**（Autotile 算普通图块，**只有 Tileset 不允许收藏**）；支持**拖拽排序**（若拖拽实现困难，退化为上下按钮）；**跨会话持久化**。 — **Reversibility:** costly —— 收藏顺序与数字键绑定会被用户形成肌肉记忆。
- **D-20:** **最近 / 最常 / 收藏统一持久化到 `.editor` 文件夹**，建议文件 `.editor/map-tiles.json`，形如 `{ "recent": number[], "frequent": Record<number, number>, "favorites": number[] }`；「最近 / 最常」用切换按钮选择。 — **Reversibility:** costly —— 文件一旦写入项目，改路径/字段要迁移。
- **D-21:** 素材区的 **Autotile 只显示左上角那一格**，不完整展开 3×4 / 2×3；Tileset 仍整图展示。 — **Reversibility:** reversible。
- **D-22:** Tileset 与其它素材**不放在一起**，像最近/最常一样在素材区做单独切换。 — **Reversibility:** reversible。

### D. Phase 4 UAT 修复（全部并入本阶段）

- **D-23:** **演示图集整片红**：`DEMO_TILE_PNG` 实际是半透明红色像素，不是注释所说的透明；改为有区分度的色块图集，使地图与素材区都能看到不同图块。 — **Reversibility:** reversible —— 演示数据。
- **D-24:** **通行度红十字**：按 D-12 改为四色箭头，解决“四方向都不可通行时看起来只有一个十字”的问题。 — **Reversibility:** reversible。
- **D-25:** **属性抽屉塌成灰线**：`.emap-properties` 外层没有高度，`.etable` 绝对定位导致父级 0 高；补齐高度 / flex 布局，保证首次打开即显示字段行。 — **Reversibility:** reversible。
- **D-26:** Phase 4 UAT 的 `G-04-1` / `G-04-2` / `G-04-3` 全部由本阶段收口，不在 Phase 4 另开缺口计划。 — **Reversibility:** reversible。

### E. 流程与门禁

- **D-27:** `coreEngineNeutral` 的扫描范围**只保留 `editor-core/src`**；`editor-impl` 是魔塔编辑器的默认实现，允许使用 `tower` / `floor` / `autotile` 等领域词。仍受 `coreModuleState` / `coreImportType` / `coreBoundaries` 约束。 — **Reversibility:** costly —— 门禁是公开的工程契约，改范围要同步 CI 与文档。
- **D-28:** 自动拼接在 `editor-impl` 中可以直接叫 `autotile`；对外接口命名仍按项目规则先写入 `INTERFACE-NAME.md` 并经用户确认。 — **Reversibility:** reversible。
- **D-29:** 本阶段是 Phase 4 之后插入的紧急阶段，依赖 Phase 4；Phase 4 的 UAT 未完成项不阻塞本阶段启动，但本阶段完成前必须一并收口。 — **Reversibility:** reversible。

- 所有新接口 / 方法 / 类型 / CSS 类 / 测试标识的命名，先写入 `INTERFACE-NAME.md` 并经用户确认。
