<objective>
Express the ten hardcoded mota paths as `ResourceDescriptor`s in a new, dedicated adapter directory
`packages/apps/editor/src/adapter/`, built with the core contract from 05-01 and the file-backed class
from 05-03, using the existing domain handlers.

Purpose: D-02 concentrates all mota engine knowledge in one place so "no engine details in core" becomes
reviewable; D-01 keeps this phase purely additive (the adapter is deliberately dead code until Phase 11's
composition root imports it); D-07 resolves the parameterized floor path entirely adapter-side.

Output: `src/adapter/motaResources.ts` (duplicated literals), `src/adapter/motaEngine.ts` (`motaEngine`
with nine fixed descriptors), and `src/adapter/motaFloor.ts` (`motaFloorDescriptor` factory).

Decisions implemented here — D-01: additive only; `projectData` is a read-only reference. D-02: the
adapter lives in `src/adapter/`. D-05: the handler is built lazily inside `create(deps)`. D-07: the floor
template is decoded adapter-side. D-10: migrations stay adapter-side (PORT-07). PORT-03: the adapter is
the consumer that uses logical ids and `defineEngine`. PORT-05: `Json2xDataHandler` + domain handlers are
adapter-owned (they stay physically in the editor; no code moves into core).

Reversibility (carried from CONTEXT): D-01 is `costly` — switching this phase to wire the adapter into
the editor data path would touch Phase 4's resource contract and change the editor load path; the
additive posture keeps the regression surface minimal.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| adapter → core contract | The adapter supplies IO addresses and logical ids; core must remain ignorant of engine words, paths, and formats. |
| adapter → editor source | The adapter must not reach into the editor's project-data aggregator (which would create a cycle) and must not be pulled into any entry bundle. |
| engine migration → core | Engine-format migrations must stay out of core (PORT-07); a migration migrating into core re-couples core to one engine format. |
