## Trust Boundaries

| Boundary | 描述 |
|----------|------|
| 宿主能力 → 面板 | `openMap` 返回的文档、`saveMapData` 的错误信息都是外部输入 |
| 图块 `imagePath` → 资源层 | 路径由宿主提供，可能指向项目外 |
| 图片字节 → 浏览器解码 | 第三方图片内容交给浏览器解码，面板不自己解析 |
| 用户指针 → 画布 | 指针坐标换算成格子，可能落在负坐标或地图外 |

| Threat ID | 类别 | 组件 | 严重度 | 处置 | 缓解措施 |

| T-04-04-02 | Tampering | 宿主错误字符串 → 面板提示 | high | mitigate | 错误按 React 文本节点显示，不拼进 HTML；不使用富文本注入 |
