<threat_model>
## Trust Boundaries

| Boundary | 描述 |
|----------|------|
| 宿主注入的 Schema → 表单引擎 | Schema 是数据，但决定了控件类型与字段路径 |
| 属性值（用户输入）→ 属性表 | 值可以是任意 JSON 类型，路径来自 Schema / 行树 |
| 属性表 → 宿主保存 | 整表提交，宿主可能校验失败 |
| 抽屉 → 面板内存 | 关闭抽屉不能丢改动，也不能绕开撤销 |

## STRIDE Threat Register

| Threat ID | 类别 | 组件 | 严重度 | 处置 | 缓解措施 |
|-----------|------|------|--------|------|----------|
| T-04-09-01 | Tampering | 属性字段路径 | high | mitigate | 复用 `setByFieldPath`（已拦截 `__proto__` / `constructor` / `prototype`），并补一条属性场景的测试 |
| T-04-09-02 | Tampering | `x-editor` 字段 | medium | mitigate | 交给 `buildTableTree` 前剥掉 `x-editor`，按只读呈现，避免出现「点了没反应」的编辑按钮 |
| T-04-09-03 | Tampering | `TableGrid` 改动波及表格 | high | mitigate | 只改工具栏 / 横幅的构造；表格整包测试作为回归闸门 |
