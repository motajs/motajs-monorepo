## Trust Boundaries

| Boundary | 描述 |
|----------|------|
| 图块目录（宿主）→ 通行度 | `pass` 字段可能缺方向、可能标了 onlyEventLayer |
| 最近使用文件（可被手工编辑）→ 列表 | 文件内容可能是任意 JSON |

| 用户输入的名字 / 尺寸 → 校验 | 名字可能超长 / 含空白 / 重名；尺寸可能为 0 / 负数 / 小数 |
