# Phase 4 — UI Design Contract / 地图编辑

> 本文件是「地图编辑」能力（`@motajs/editor-impl/map`）的视觉与交互契约。由 gsd-ui-researcher 生成，gsd-ui-checker 校验。
>
> **范围。** 本契约覆盖**一个「地图编辑器」面板**（地图打开 / 切换 / 新建、图层切换与新增、图块调色板、画布绘制与框选复制粘贴、只读通行度叠加、地图属性表单、手动保存与未保存提示、视口移动与大地图模式）以及它在开发宿主中的接入形态。外壳（菜单行 / 标签行 / 内容区）属 Phase 1，**不在此重复**；本面板渲染在 `editor-core` 外壳的内容区内。Phase 3 已交付的 **schema 表单引擎**（`editor-impl/shared/schemaForm`）被本阶段**直接复用**为「地图属性表单」，其内部控件呈现不在本文重复，仅约束其**挂载形态**。
>
> **对齐说明（用户指令）。** 现有 `@motajs/editor` 的地图实现（`packages/apps/editor/src/MapEditor/**`）是**画面 / 行为参照**，不是照抄模板。用户原话：「旧代码仅做参考，不代表新的代码也要这么写」。凡本文说「与现状一致」，指的是用户可观察到的外观与行为，用本阶段的令牌与组件结构重新表达。
>
> **范围修订提示（D-13 / D-23）。** 本阶段**不编辑通行性**；新引擎的通行性完全由图块自身属性决定。ROADMAP / MAP-01 中「用户可编辑通行性并看到生效结果」一条**已被用户正式修订**为「只读查看通行度叠加层」。研究与实现不得再按「可编辑通行性」设计。图块属性同样只读（D-14）。
>
> **命名提示（项目规则）。** 本文出现的代码标识（面板类型名、组件名、文件名、CSS 类名、`data-test-id`）均为**工作名 / 提案**，**不是已锁定的契约**。任何重要命名必须先写入 `.planning/phases/04-map/INTERFACE-NAME.md` 并经用户确认，才可落进代码、计划或配置。本文只锁定**角色、布局、视觉令牌、文案与交互结果**。
>
> **引擎中立提示。** `editor-core` 与 `editor-impl/src` 的代码、注释、CSS 类名与测试标识不得出现引擎专有词（`tower` / `floor` / `loc` / `autotile` / `idnum` / `airwall` / `mota` 等）。本文提议的标识一律使用通用词（`map` / `layer` / `tile` / `palette` / `canvas`）。**用户可见文案**使用简体中文的通用词（「地图」「图层」「图块」），这些文案不受代码门禁限制。

| 项 | 值 |
|----|----|
| Tool | none（无 shadcn —— 这是基于 antd 的库包 `@motajs/editor-impl`） |
| Preset | 不适用 |

| 图标库 | 无 —— 沿用 Phase 2 / 3 结论：使用**自包含内联 SVG**（16px）或**文案标签**；`@motajs/editor-impl` **未**声明 `@ant-design/icons` / `lucide-react` |

**为什么没有 shadcn（已裁定，非待定）。** `@motajs/editor-impl` 是工作区库，其 peer 栈由里程碑约束固定（`antd` + `@motajs/editor-core` + `pixi.js`）。Phase 2 的 CONTEXT D-08 把样式锁定为 **antd 组件 + 局部 CSS**，**不引入 PandaCSS、不引入新的运行时渲染依赖**。故 shadcn（Tailwind + Radix + 构建链）**被否决**。设计系统即 antd；样式层为同目录的普通 CSS。

> **门禁说明。** 本项目非 shadcn 工程（无 `components.json`），且前序阶段（Phase 1 / 2 / 3）已就「不使用 shadcn」达成并记录结论，故本轮**不再重复询问**该门禁。

## Typography

**恰好 4 个字号 / 2 个字重**。字体族继承宿主（面板不声明）。

| 角色 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 16px | 600 | 1.2 | 空态 / 错误态标题；弹窗标题；抽屉标题 |
| Heading | 14px | 600 | 1.3 | 调色板分组标题；工具栏分组标签；未保存确认标题 |
| Body | 13px | 400 | 1.5 | 工具栏按钮与标签；图层段；调色板图块名；菜单项；表单正文；状态条主文本 |
| Label | 12px | 400 | 1.4 | 坐标 / 选区尺寸 / 地图尺寸；未保存标记；辅助说明；字段校验文字；`title` 揭示的次要信息 |

字重：正文 / 标签一律 **regular（400）**，标题一律 **semibold（600）**，无其它字重。

文本行为：
- 单行文本默认**单行省略号**（`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`），全文经元素 `title` 属性揭示。
- 地图名、图层名、图块分组名、上下文菜单项均按上述规则处理。
- 状态条中的数字使用 `font-variant-numeric: tabular-nums`，避免坐标跳动。
- 画布本身**不承载文字**（除行列标尺与通行度图形）；坐标、选区尺寸与模式一律放在状态条，避免文字随地图缩放而模糊。

> 密度注：外壳（Phase 1）用 Body 14 / Label 13；地图面板与表格 / 素材一致地**下沉一号**（Body 13 / Label 12），以贴合现有编辑器的紧凑工具界面。

## Color

**浅色为本契约基准。** 面板**复用 Phase 1 外壳的 CSS 变量**（`--editor-*`，定义于 `packages/apps/editor/src/css/editor.css`），因此主题与外壳自动一致；面板以字面量作 fallback 消费这些变量。外壳当前定义了 `bg` / `surface` / `toolbar-bg` / `fg` / `muted` / `border` / `grid` / `selected` 八个令牌；**`accent` 与 `danger` 外壳未定义**，面板分别以 `var(--editor-accent, #1677ff)` 与 `var(--emap-danger-fg, #d00)` 消费，宿主可选择定义它们来换色。

| 角色 | 值 | 用途 |
|------|----|------|
| Dominant (60%) | `#ffffff`（`--editor-surface`） | 面板主体表面：画布外围、调色板网格底、抽屉 / 弹窗正文 |
| Secondary (30%) | `#f5f6f8`（`--editor-bg`）/ `#ffffff`（`--editor-toolbar-bg`） | 工具栏两行；调色板容器；状态条；弹窗 / 抽屉标题栏 |
| Accent (10%) | `#1677ff`（`var(--editor-accent, #1677ff)`） | **保留 —— 见下方清单** |
| Destructive | `#d00`（面板作用域 `--emap-danger-fg`；外壳未定义 danger 令牌，取字面量） | 仅破坏性 / 丢失性呈现 —— 见下方清单 |

**Accent 保留给（穷尽）：**
1. 当前选中的**图层段**（文字 / 底色）与当前选中的**画笔模式段**。
2. 调色板中**选中的图块**（2px 外描边）与**多格框选范围**（描边 + 10% 透明填充）。
3. 画布上的**框选矩形**（1px 虚线描边 + 12% 透明填充）与**绘制预览**（目标格 35% 透明填充 + 1px 描边）。
4. 画布与所有可交互控件的 `:focus-visible` 焦点环。
5. 主按钮：工具栏「保存」、空态「新建地图」、弹窗「创建」。
6. 画布当前悬停格的 1px 轮廓（40% 不透明度的 accent）。

Accent **绝不**用于：默认文字、默认边框、画布背景、调色板默认底色、图块缩略图底色、通行度叠加、或「所有可交互元素」。

**Destructive 保留给（穷尽）：**
1. 工具栏下方的**保存失败**提示（文字 / 图标）与「重试」附近的破坏性强调。
2. 未保存确认弹窗中的**「放弃改动」**按钮。
3. 「清除最近使用的图块」确认弹窗中的**「清除」**按钮。
4. **地图加载失败** / **图块加载失败** / **地图属性加载失败**的标题文字。

## Map Panel Composition & Interaction Contract

> 面板即本阶段交付物，故其结构与交互模型属于契约。`@motajs/editor-impl/map` 对外导出**面板类型对象**（工作名 `mapPanelType`，待确认）与**底层组件 / 类型**；由顶层（开发宿主 / 未来 `@motajs/editor`）调用 `ShellSystem.registerPanelType` 注册。能力包**不自行装配到 core**（Phase 1.1 D-05）。面板类（工作名 `MapPanel`）只做数据与状态接线，视图由同目录组件渲染。

### 面板实例模型与宿主注入（D-01…D-06 / D-08 / D-11 / D-15）

- **一个面板实例 = 一张地图。** 面板内部持有当前地图的中立文档（宽度、命名图层、每层数字格子、图块目录、通行信息），**没有全局「当前地图」**。
- **数据自足（D-02）。** 面板拿到一份中立文档就能绘制、预览、显示通行度，不需要再向多个通道取数。
- **宿主注入（D-01 / D-03 / D-04 / D-05 / D-08 / D-15）：**
  - 地图清单 + 打开回调 + 新建地图回调 + 新增图层回调（宿主执行，面板只发指令并接收更新后的文档）。
  - 图块目录：每一项已由宿主算好「编号 + 图片路径 + 裁切矩形 + 名称 + 通行属性」；面板不懂纹理切分规则。
  - 地图尺寸上限（D-06）：超限时面板拒绝新建 / 改尺寸并提示。
  - 地图属性 JSON Schema：字段由宿主注入，面板不写死引擎字段。
  - 保存接口按域拆分：地图数据、地图属性各一块，**每块传整份数据**；未展示的数据（如点事件）由宿主保留，不得因保存而丢失。
- **面板不读文件、不认识文件路径、不认识引擎文件格式。** 图块图片字节的取得方式由规划阶段决定（经 `editor-core` 资源层按路径读取，或由宿主直接注入字节 / URL）；无论哪种，面板都**不直接触达真实文件系统**。
- **定位：** 面板是「地图数据 + 图块目录」的编辑器；点事件的显示 / 绑定 / 编辑、图块属性编辑、图层重命名 / 排序 / 删除、通行性编辑**均不在本面板**。

| 「新建地图」`Button` | 次要按钮。点击时若有未保存改动，先弹未保存确认；确认后打开新建地图弹窗。 |
| 弹性占位 | 撑开左右两组。 |
| 「未保存」标记 | Label 角色、muted；仅在有未落盘改动时出现。文字 **「未保存」**，不是只有颜色变化的圆点。 |
| 「地图属性」`Button` | 打开右侧抽屉。宿主未注入属性 Schema 时**禁用**并给 tooltip **「当前项目未提供地图属性配置。」**，绝不做静默空操作。 |

| 控件 | 契约 |

| 画笔 `Segmented` | **「线」·「矩形」·「填充」**，`size="small"`；默认「线」；当前模式用 accent 标记。 |
| 「显示通行度」`Switch` | 默认关闭；打开后画布显示只读四方向通行度叠加（见 §只读通行度）。开关标签始终可见，不只用开关颜色表达状态。 |

- 地图加载中：地图切换可用；新建 / 新增图层 / 画笔 / 通行度 / 大地图 / 保存禁用。
- 地图加载失败：仅地图切换与「重试」可用；其余编辑控件禁用。
- 图块目录不可用：画布仍可查看与移动，但线 / 矩形 / 填充的落笔禁用，调色板显示错误态。
- 面板宽度 < 900px：执行「视图」下拉收纳；地图切换 `Select` 可收缩到最小 160px，地图名省略 + `title`。

### 地图打开与空态

**首次打开面板（尚未打开地图）**：工具栏只保留第 1 行（地图 `Select` 禁用 + 「新建地图」），第 2 行编辑工具隐藏；面板主体显示**内联地图清单**，而不是空白画布。

| 状态 | 呈现 |
|------|------|
| 清单加载中 | 居中 `Spin` + Label **「正在读取地图清单…」**。 |
| 清单读取失败 | 居中破坏性 Display **「地图清单读取失败」** + Label **「请稍后重试。」** + 「重试」按钮。 |
| 清单为空 | 居中 Display **「项目中还没有地图」** + Label **「点击「新建地图」创建第一张地图。」** + 主按钮 **「新建地图」**。 |
| 清单有条目 | Display **「尚未打开地图」** + Label **「从下方列表选择一张地图开始编辑，或新建一张地图。」** + 可滚动清单（最大高度 240px）；每行是一个全宽按钮，左对齐显示地图名，单行省略 + `title`；点击即打开该地图。清单下方固定「新建地图」主按钮。 |

**已打开地图后**：地图清单收进工具栏 `Select`；空态不再出现。切换地图时：
1. 若有未保存改动 → 先弹未保存确认（见 §保存与未保存）。
2. 确认后，面板进入「加载中」，旧地图内容**立即从画布移除**（不保留旧图残影），调色板保持可用。
3. 新地图加载成功 → 当前图层取文档的第一个图层；视口回到左上角；框选与内部剪贴板保留（剪贴板是面板级内存，跨地图可用）。
4. 加载失败 → 画布区显示错误态 + 重试；工具栏仍可切换回其它地图。

**切入（`IEditorPanel.onSwitchIn`）刷新：** 面板重新读取宿主的地图清单；**若当前地图有未保存改动，不重新读取当前地图文档**，避免覆盖内存改动。列表变化只影响 `Select` 的候选项；无改动时才按宿主返回刷新当前文档。

### 图层切换与新增图层（D-07 / D-05）

- 图层来源：当前地图文档里的**命名图层**，按宿主给定顺序排列；面板**只切换、只新增**，不重命名、不排序、不删除，也没有图层设置面板。
- 图层 `Segmented` 的每一项显示图层名；名称单行省略 + `title`。当前层用 accent（文字 + 浅底色）标记。切换图层时：
  - **取消**当前正在进行的笔画（不落任何格子、不产生撤销记录）；
  - **清除**画布框选与绘制预览（避免在错误图层上执行复制 / 清空）；
  - **保留**内部剪贴板与调色板选择（跨图层粘贴是允许的）。
- **没有图层**（异常文档）：画布显示空图块棋盘格 + 居中 Label **「该地图没有图层」**；图层段禁用；「新增图层」仍可用。
- **新增图层**（宿主执行，D-05）：
  - 点击「新增图层」打开 `Modal`（宽 360px），字段 **「图层名称」**，默认预填 **「图层 {N}」**（N = 当前图层数 + 1），打开时自动聚焦并全选默认名。
  - 校验：去除首尾空白后非空；不得与现有图层重名。错误行内显示 **「请输入图层名称。」** / **「图层名称已存在。」**。
  - 提交中：按钮禁用 + `Spin` + **「正在创建…」**；弹窗不关闭。
  - 成功：宿主返回更新后的文档；新图层**追加到末尾并成为当前层**；关闭弹窗，提示 **「已新增图层「{名称}」」**。
  - 失败：弹窗保持打开，行内显示宿主返回的原因；按钮恢复可用。
  - 新增图层是**宿主侧操作**，不进入面板的撤销历史；撤销碰到它时按屏障处理（见 §撤销 / 重做）。

### 图块调色板（D-08…D-12）

**调色板是唯一纵向滚动区**，宽 240px，自上而下固定为三段：

1. **擦除格（固定）**：一个 32×32 的 **「空」** 格，棋盘格底 + 对角斜线图形；`title` / tooltip 为 **「擦除：选中后在画布上绘制会清空对应格子」**。它是**单选**，不参与多格框选；选中后画笔的“内容”变为擦除（工具仍是线 / 矩形 / 填充，落笔即清空）。与下方内容用 1px `--editor-border` 分隔。
2. **最近使用（单独分区，D-11）**：标题行 **「最近使用」**（Heading 14 / 600）+ 右侧 **「清除」** 文本按钮（Label 12）。下方是 **6 列 × 32px** 的图块网格，间距 4px，最多显示两行（72px 高），超出时该区自身纵向滚动。按「最近使用」倒序；每条是 1×1 图块（不保存多格区域），点击后选中该图块并把画笔重置为 1×1。空态显示 **「暂无最近使用的图块」**（Label，muted，左对齐）。
3. **分组图块（D-10）**：每个宿主分组一个可折叠标题 + 缩略图网格。
   - 分组标题：全宽按钮，高 32px，左侧 16px 折叠箭头（内联 SVG，展开朝下 / 折叠朝右），中间分组名（Heading 14 / 600，单行省略 + `title`），右侧数量（Label 12，muted）。`aria-expanded` 反映折叠状态。滚动时标题**吸顶**（`position: sticky; top: 0`，底色 `--editor-toolbar-bg`，1px 下边框）。
   - 折叠时该组网格不挂载；展开状态是**面板本地 UI 状态**，不进入撤销、不写盘（默认全部展开）。
   - 网格：`display: grid; grid-template-columns: repeat(auto-fill, 32px); gap: 4px; justify-content: start;`，内边距 8px。
   - 每个图块是一个真实 `<button type="button">`，32×32，`image-rendering: pixelated`，缩略图底 `--editor-bg`，可访问名为 **「图块 {名称}（编号 {编号}）」**，`title` 同文案。图片缺失时渲染棋盘格 + 暖橙角标 **「!」**，`title` 追加 **「该图块的图片不可用」**；仍然可选、可绘制（编号有效），画布预览用占位格。
   - 分组为空：展开后显示 **「该分组暂无图块」**（Label，muted）。
   - 无任何分组 / 目录为空：调色板主体显示 **「暂无可用的图块」**，画布仍可查看但不能落笔。

**选择与多格笔刷（D-09 / D-12）：**
- 单击 = 选中 1×1；**在同组内按住左键拖拽** = 框选一个矩形范围，释放后成为 W×H 笔刷。拖出分组边界时**夹取到该组范围**，不允许跨组选择（不同图片源的裁切规则不同）。
- 框选过程中显示 1px accent 虚线 + 10% 填充的矩形，并在右下角显示 Label **「{W}×{H}」**。
- 选中结果：整体外框 2px accent 描边 + 1px 白色内环（保证在深色像素上也可见）；**不给图块本身叠加半透明色**，以免改变像素观感。悬停态为 1px accent 轮廓。
- 多格笔刷在画布上的预览与落笔尺寸**与选择范围一致**（D-09），不是单格。
- 选择「空」时：笔刷为擦除，尺寸固定 1×1；画布预览为空心矩形。

**最近使用的写入规则（D-11）：**
- 每次**落笔成功**（一次笔画结束）后，把该笔画使用的**主图块**（多格笔刷取左上角那一格）移到最近使用列表首位；同一编号只保留一条。
- 持久化到**项目内约定文件**（跨会话、跨面板实例），**不使用浏览器本地存储**；路径 / 格式 / 条目上限由规划阶段提出并经 `INTERFACE-NAME.md` 确认（本文建议上限 24 条）。
- 「清除」弹确认（见 §Copywriting Contract），确认后清空该项目的最近使用记录；**不可撤销**。

### 画布与鼠标手势（D-16…D-22）

**画布结构：**
- 画布区是一个可聚焦容器（`tabIndex=0`），内含 PixiJS 渲染的 `<canvas>`；上方与左侧各 20px 的行 / 列标尺（Label 12，muted；每 5 格显示一个数字，当前悬停行 / 列用 accent 标记）。
- 画布底部 24px 状态条，从左到右：**「坐标」 (x, y)** · **「选区」 W×H**（无选区时省略）· **「地图」 W×H** · **「图层」 {名称}** · **「模式」 普通 / 大地图**。窄宽度时按此优先级从右向左隐藏次要段。
- 地图按 32px/格渲染；格子边界叠 1px `--emap-grid-line`；空图块（数值 0）显示 8px 棋盘格（`--emap-empty-a` / `--emap-empty-b`），与真实图块区分。
- 画布内容**不缩放像素**：`image-rendering: pixelated`；大地图模式下允许缩小显示（见 §大地图模式），同样不做平滑插值。

**手势契约：**

| 手势 | 触发条件 | 结果 | 撤销 |
|------|----------|------|------|
| 左键单击 / 拖拽 | 已选中图块或「空」，画笔 = 线 | 沿拖拽路径连续落笔；正交插值补齐斜拖经过的格子，不留断点 | 一次笔画 = **一条**撤销记录 |
| 左键拖拽 | 画笔 = 矩形 | 实时显示矩形预览；释放时把矩形（含起止格）按笔刷图案平铺落笔 | 一次矩形 = **一条**撤销记录 |
| 左键单击 | 画笔 = 填充 | 对当前图层做四邻域连通填充：把与点击格**相同图块值**的连通区域替换为笔刷图案（「空」则清空该区域） | 一次填充 = **一条**撤销记录 |
| 左键单击 / 拖拽 | 已选中「空」 | 清空笔刷覆盖的格子（单格 / 多格矩形 / 矩形模式整块） | 一次擦除 = **一条**撤销记录 |
| 右键拖拽 | 任意画笔状态 | 框选一块区域（含起止格）；不修改地图；替换之前的选区 | 无（不产生记录） |
| 右键单击 | 未处于笔画中 | 在指针位置弹出上下文菜单（见 §右键菜单） | 无 |
| 绘制中按右键 | 左键笔画进行中 | **取消当前笔画**：已预览但未提交的格子不落盘，不产生撤销记录 | 无 |
| Ctrl/Cmd + C | 画布聚焦 | 有选区 → 复制选区；无选区 → 复制指针所在的 1×1 格。只复制**当前图层** | 无（复制不是编辑） |
| Ctrl/Cmd + V | 画布聚焦且内部剪贴板非空 | 以指针所在格为**左上角**粘贴到当前图层；超出地图范围的格子**裁剪** | 一次粘贴 = **一条**撤销记录 |
| Escape | 画布聚焦 | 优先级：取消当前笔画 → 关闭右键菜单 → 清除框选。**不清除调色板选择**（避免误丢画笔） | 无 |
| 左键点击视口按钮 | 工具栏 | 视口移动 1 格；Shift + 点击移动 1 屏 | 无（视口不是数据） |

- 笔画期间使用指针捕获：指针移出画布后仍保持笔画，松开时以最后一个有效格提交；移出地图边界的格子裁剪。
- 笔画提交前只显示预览，**不修改文档、不记撤销**；提交时才写入内存并记一条撤销。因此「未保存」标记只在提交后出现。
- 左键在画布上按下时，若当前没有可用图块（调色板目录为空 / 图片缺失但编号有效仍算可用），不进入绘制；不弹错误，只保持浏览。
- 光标：画布可绘制时为 `crosshair`；无可用图块或大地图模式下为 `default`；右键框选仍为 `crosshair`。画布聚焦时显示 2px accent 内描边。

**笔刷几何规则（多格笔刷，D-09）：**
- **锚点：** 指针所在格 = 笔刷的**左上角**，与粘贴定位规则一致。
- **线：** 在路径经过的每个格子上盖一次笔刷；多格笔刷在相邻位置会重叠，重叠部分以最后一次写入为准。
- **矩形：** 把笔刷图案在拖出的矩形内**平铺**（按笔刷宽高取模），不是把单个笔刷拉伸到整块。
- **填充：** 连通区域按笔刷图案**平铺**，锚点为点击格。
- **擦除：** 线 / 矩形 / 填充都按上述覆盖范围清空；「空」格子本身不产生图块图案。
- **越界：** 任何笔刷覆盖到地图外的格子一律裁剪，不报错。

### 右键菜单（D-19 / D-20）

- 定位在指针处（`position: fixed`），最小宽度 160px，`--editor-surface` 底、1px `--editor-border`、4px 圆角、`0 2px 8px rgba(0,0,0,0.15)` 阴影；靠近视口右 / 下边缘时夹取 / 翻转，保证完整可见。
- 真实 `role="menu"`，菜单项为 `role="menuitem"` 的按钮；打开时焦点移到第一项，↑ / ↓ 移动，Enter 执行，Escape / 点击外部关闭。点击菜单外部或滚动地图也会关闭。
- 菜单项与启用条件：

| 菜单项 | 启用条件 | 行为 |
|--------|----------|------|
| **「复制选区」** | 始终可用 | 有选区复制选区；无选区复制指针所在 1×1 格；结果存入面板内部剪贴板 |
| **「粘贴到此处」** | 内部剪贴板非空 | 以指针所在格为左上角粘贴到当前图层；越界裁剪；一条撤销记录 |
| **「清空选区」** | 存在选区 | 清空选区覆盖的格子；一条撤销记录 |
| **「取消选区」** | 存在选区 | 只清除框选，不修改地图 |

- 本阶段菜单**不出现**任何事件相关项（绑定出生点 / 传送 / 机关门 / 复制粘贴事件等），也不出现图层设置项。事件能力留待 Phase 6。
- 内部剪贴板是**面板实例内存**，不写系统剪贴板、不跨面板、不做权限申请；跨地图 / 跨图层粘贴允许。

### 只读通行度叠加（D-13 / D-14 / D-23）

- 工具栏「显示通行度」`Switch` 默认关闭；打开后只**显示**、不修改、不产生撤销记录、不置脏。
- 叠加内容：对每个格子，按图块目录给出的四方向通行属性，只画**不可通行的方向**：
  - 4 个方向各用一枚 10px 红色箭头（`--emap-pass-blocked` `#e60012`），衬 `--emap-pass-chip` 白色半透明底，保证在深色 / 亮色图块上都可读。
  - 可通行的方向**不画箭头**；空图块不画任何通行标记。
  - 一个格子最多 4 枚箭头（上 / 下 / 左 / 右）；箭头方向指向「不能走」的方向。
- 叠加层位于图块之上、框选 / 预览之下，**不拦截鼠标事件**（`pointer-events: none`）。
- 大地图模式下，若屏幕上的单格边长 < 16px，改为每个不可通行格画**一个红色圆点**，避免四箭头糊成一团；放大回普通模式后恢复箭头。
- 开关的 tooltip / 辅助说明：**「红色表示该方向不可通行；这里只查看，不会修改地图。」**
- 图块属性只读（D-14）：面板不提供任何修改通行方向或图块属性的入口；图块目录里没有通行信息时，该格不画标记，也不报错。

### 大地图模式（D-21）

- 点「大地图」或按 `F`（画布聚焦时）进入 / 退出；按钮激活时 accent。状态条「模式」段显示 **「大地图」**。
- 进入后：整张地图按**保持宽高比**缩放到画布视口内（一屏看全图）；不再显示行列标尺；视口移动按钮 / 方向键 / WASD 在此时不改变视图（全图已可见），按钮可保持可见但点击无效果。
- 绘制、擦除、框选、复制 / 粘贴、通行度叠加在缩略视图下**仍然可用**；指针坐标按缩放比例映射回格子。
- 退出后恢复到进入前的视口位置与缩放；不修改地图数据、不置脏。
- 大地图模式是**面板本地视图状态**，不写盘、不进入撤销。

### 地图属性（D-15）

- 入口：工具栏「地图属性」→ 右侧 `Drawer`（480px），标题 **「地图属性」**，右上关闭按钮。
- 表单：**直接复用** `editor-impl/shared/schemaForm` 的 schema 表单（同一套控件、校验、字段路径与呈现规则）；其内部呈现属 Phase 2 / 3 契约，本文不重复。字段由宿主注入的 JSON Schema 描述，面板不写死字段。
- **呈现模式：** 只呈现字段行与值控件；**不显示**表格专属动作（编辑 / 添加 / 删除模式、编辑 Schema、在代码编辑器中打开、关闭栏）。抽屉标题即表单标题。若现有 `TableGrid` 没有这个精简呈现开关，则在 `shared/schemaForm` 增加一个「表单模式」开关（命名 / 形状经 `INTERFACE-NAME.md` 确认），**不得**复制一套表单控件。
- **状态映射：** 属性读取中 → `Loading`；无字段 → `EmptySchema`（「尚未定义任何字段。」）；读取失败 → `Error`；就绪 → `Ready`；`NoTarget` 不使用。
- **字段范围：** 本阶段只保证基础字段（string / number / integer / boolean / enum / array）的行内编辑。代码 / 事件 / 素材类需要外部编辑器的字段依赖后续阶段能力，宿主应避免在地图属性 Schema 中注入；若注入，按缺少外部编辑器能力处理（只读显示，不出现无效的「编辑」按钮）。
- 挂载形态：抽屉正文**唯一滚动区**；标题栏固定；宽度 480px，给复用的表格表单留出「名称 / 注释 / 值 / 操作」列宽。复用的 `TableGrid` 在抽屉内按容器宽度自适应，不触发横向滚动；抽屉正文需为 `position: relative` 且可伸缩，供 `TableGrid` 以 `inset: 0` 填充。
- **只有一个保存入口：** 抽屉内复用 `TableGrid` 时**不传** `onSave`（避免出现第二个保存按钮），只传 `unsaved` 显示未保存状态；保存统一由工具栏「保存」触发。
- 编辑语义：
  - 每提交一个字段值 = 一条可逆撤销记录（复用统一撤销路径）；同时置「未保存」。
  - 抽屉关闭**不丢弃**内存改动；重新打开显示当前内存值。
  - 保存时把**整个属性表**交给宿主（D-04），不是逐字段补丁。
- 状态：
  - 未注入 Schema：入口禁用 + tooltip，不打开空抽屉。
  - Schema 加载中：抽屉内居中 `Spin` + **「正在加载地图属性…」**。
  - 无字段：显示 schemaForm 的空态 **「尚未定义任何字段。」**。
  - 加载失败 / Schema 非法：抽屉内破坏性 **「地图属性加载失败」** + **「请稍后重试。」**；不关闭抽屉、不影响地图绘制。
- 属性表单的改动与地图绘制共用同一个「未保存 / 保存」模型；保存失败时保留改动与脏标记。

### 新建地图（D-05 / D-06）

- 入口：空态主按钮或工具栏「新建地图」。**若有未保存改动，先弹未保存确认**；确认后才打开弹窗。
- `Modal`（宽 420px），标题 **「新建地图」**，字段：

| 字段 | 控件 | 默认 / 校验 |
|------|------|-------------|
| 名称 | `Input` | 空；占位 **「例如：sample0」**；去空白后非空；不得与现有地图重名 |
| 宽度 | `InputNumber` | 默认 32；整数；最小 1；有宿主上限时最大为上限 |
| 高度 | `InputNumber` | 默认 32；整数；最小 1；有宿主上限时最大为上限 |
| 初始图层名称 | `Input` | 默认 **「图层 1」**；去空白后非空 |

- 尺寸提示：**「宽高以格子为单位。」**；宿主注入上限时追加 **「最大 {宽度} × {高度}。」**。超限时拒绝提交并显示行内错误，**不**静默夹取。
- 按钮：**「创建」**（primary）· **「取消」**。
- 提交中：按钮禁用 + `Spin` + **「正在创建…」**；弹窗不关闭。
- 成功：宿主创建文件并返回新地图文档；面板打开新地图（当前层 = 初始图层；视口回左上角），关闭弹窗，提示 **「已创建地图「{名称}」」**。
- 失败：弹窗保持打开，行内显示宿主原因；按钮恢复可用。
- 新建地图是宿主侧操作，不进面板撤销历史；撤销按屏障处理。

### 保存与未保存（D-18 / D-04）

- **手动保存**，与表格 / 素材一致：所有编辑先改内存，点「保存」才写回宿主。
- 脏状态来源：地图格子改动（笔画提交 / 粘贴 / 清空选区）、地图属性字段提交。复制、框选、视口移动、图层切换、通行度开关、大地图、调色板选择**都不置脏**。
- 宿主执行的新建地图 / 新增图层是即时写盘，不置脏，也不进面板撤销。
- 「保存」：
  1. 只提交**有改动的域**；每块传整份数据（地图数据、地图属性）。
  2. 全部成功：清除脏标记、隐藏「未保存」、在工具栏下方提示行显示 **「已保存」**（muted，非阻塞）。
  3. 任一块失败：保留失败域的脏标记与其他域的改动，在工具栏下方显示**破坏性提示条** **「保存失败：{原因}」** + **「重试」**；提示条不自动消失，直到重试成功或用户再次保存。
  4. 保存中：保存按钮禁用并显示 **「正在保存…」**；地图编辑仍可继续（改动会再次置脏），但不要重复触发保存。
- **未保存确认**（`Modal`，宽 420px）：
  - 触发：切换地图（工具栏 `Select` / 空态清单）、点击「新建地图」、关闭面板标签。
  - **不触发**：仅仅切到外壳的其它标签页（面板实例仍存活，改动不会丢）。
  - 标题 **「有未保存的改动」**，正文 **「当前地图还有未保存的改动。要先保存吗？」**；按钮 **「保存并继续」**（primary）· **「放弃改动」**（destructive）· **「取消」**（默认焦点）。
  - 「保存并继续」：调用保存；成功后继续原操作；失败则**弹窗保持打开**并显示 **「保存失败：{原因}」**，不继续原操作。
  - 「放弃改动」：丢弃内存中的地图数据与属性改动，恢复为最近一次保存 / 宿主返回的状态，然后继续原操作。
  - 「取消」：关闭弹窗，保持当前地图与改动不变。
- 关闭面板时若正在保存：阻止重复关闭动作，等待保存完成或失败提示；不得在保存中被销毁而导致写回一半。

### 撤销 / 重做（D-17）

- 粒度：**一次笔画 = 一条撤销记录**；线、矩形、填充、擦除、粘贴、清空选区各算一次。属性表单每提交一个字段 = 一条。
- 复制、框选、视口移动、图层切换、通行度开关、大地图、调色板选择**不产生撤销记录**。
- 宿主侧的新建地图 / 新增图层不进入面板撤销历史，作为**屏障**：撤销碰到它即停住，返回「无法执行」；命中时提示 **「无法撤销」**，**不**跳过屏障去撤销更早的笔画。
- 快捷键由 Phase 1 外壳统一绑定（Phase 2.19）：`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 与 `Ctrl/Cmd+Y` 重做。**地图面板不自行绑定撤销快捷键**；只在画布聚焦时绑定 `Ctrl/Cmd+C` / `Ctrl/Cmd+V`。
- 撤销 / 重做后：画布与调色板选择保持不变；脏状态按「内存与最近保存快照是否一致」重新计算；需要重新点「保存」才写回。

### 溢出与长文本

- **纵向：** 调色板是唯一纵向滚动区；画布按视口裁剪；工具栏、状态条、提示行固定。
- **横向：** 图层段横向滚动；调色板网格 `auto-fill` 不产生横向滚动；工具栏在 < 900px 时用「视图」下拉收纳，不换行。
- **地图名 / 图层名 / 分组名 / 菜单项：** 单行省略 + `title`；抽屉里的字段标签按 schemaForm 规则换行 / 省略。
- **地图清单 / 最近使用 / 分组网格：** 超出各自容器时自身滚动；外层面板不整体滚动。
- **右键菜单：** 靠近视口边缘时夹取 / 翻转；菜单内不滚动（本阶段最多 4 项）。
- **弹窗 / 抽屉：** 正文自身滚动，底部按钮 / 标题栏固定；窄屏下不撑破视口。
- **大地图：** 整图缩放，不产生滚动条。

### 无障碍与内容安全

- 画布是可聚焦区域：`tabIndex=0`，`aria-label` 说明「地图画布：左键绘制，右键框选，Ctrl+C / Ctrl+V 复制粘贴」；另用 `aria-describedby` 指向一段视觉隐藏的快捷键说明。聚焦时显示 2px accent 内描边。
- 画布内的图形（图块、通行度箭头、框选）不是可聚焦控件；所有**操作入口**都在 DOM 里（工具栏、调色板、菜单、弹窗、抽屉），保证键盘与屏幕阅读器可用。
- 调色板图块是真实按钮，带可访问名与 `title`；分组标题带 `aria-expanded`；选中的图块带 `aria-pressed`。
- 图层 `Segmented`、画笔 `Segmented` 使用 antd 自带的键盘语义；当前项可被读出。
- 右键菜单使用 `role="menu"` / `role="menuitem"`，打开即聚焦第一项，方向键 / Enter / Escape 可用。
- 状态不只靠颜色：未保存有文字标记；通行度有开关标签 + 箭头形状；选区有虚线框 + 状态条尺寸。
- 焦点顺序：工具栏第 1 行 → 第 2 行 → 调色板擦除格 → 最近使用 → 分组标题 / 图块 → 画布 → 状态条（状态条不可聚焦）→ 提示行「重试」。弹窗 / 抽屉由 antd 管理焦点陷阱。
- **所有地图名 / 图层名 / 图块名 / 错误原因都经 React 文本节点渲染**，绝不 `dangerouslySetInnerHTML`（XSS 缓解）。宿主返回的错误字符串按纯文本显示。
- 画布渲染使用 `OffscreenCanvas` / `createImageBitmap` 或 PixiJS 的 canvas；**不得**用 `document.createElement('canvas')` 造渲染画布（`coreModuleState` 门禁）。

- **工具栏 · empty**：工具栏恒渲染固定控件，没有「零元素」态。

2. `editor-impl` 已有 `src/global.d.ts` 声明 `*.css`，普通 `import './map.css'` 可通过 `tsc -b`。
3. `pixi.js` 已在 `peerDependencies` 与 `devDependencies` 中；本阶段不新增任何依赖。
4. `./map` 子路径已在 `package.json` 的 `exports` 中预留；本阶段只是填充实现。

**平台门禁：** 画布渲染不得使用 `document.createElement('canvas')`；使用 PixiJS 的 canvas 或 `OffscreenCanvas` / `createImageBitmap`。`editor-impl/src` 仍受 `coreModuleState` / `coreEngineNeutral` 门禁约束。

## 开发宿主接入（阶段收尾，ROADMAP 横切约束）

本阶段完成后，地图能力**必须**接入 `packages/apps/editor-dev`，使其可在浏览器里被打开与手动验收。接入只改开发宿主，不进产品产物：

- **顶层注册：** 开发宿主 import 地图面板类型对象并调用 `ShellSystem.registerPanelType`；能力包不自行装配。
- **注入：** 通过内存后端注入地图清单、打开 / 新建地图 / 新增图层 / 保存回调、图块目录、地图尺寸上限、地图属性 Schema。
- **演示数据最低要求：**
  - 至少 2 张地图：一张小于视口（能看全边界）、一张大于视口（能验收视口移动 / 大地图）。
  - 图块目录至少 2 个分组、若干 32×32 图块，并包含**一个图片缺失的图块**（验收缺失占位）。
  - 地图属性 Schema 至少包含 2 个字段（一个字符串、一个数字），用于验收抽屉表单与撤销。
  - 最近使用偏好文件可被读到 / 写入，验收跨面板重开仍保留。
- **手动验收清单：** 打开地图 → 线 / 矩形 / 填充绘制 → 擦除 → 切换图层 → 新增图层 → 多格框选笔刷 → 右键框选 → 复制 / 粘贴（含越界裁剪）→ 显示通行度 → 编辑地图属性 → 保存 → 关闭重开确认写回；另验收「无地图空态」「地图加载失败」「图块目录失败」「未保存确认」四个状态。
- **不引入**新的开发宿主专用 UI 契约；地图面板在开发宿主里与未来产品宿主使用同一套布局与文案。
