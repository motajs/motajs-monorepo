## Trust Boundaries

| Boundary | 描述 |
|----------|------|
| 图块图片路径 + 字节（宿主）→ blob URL | 路径可能越界、字节可能不是图片、可能很大 |
| 视图 props → 面板 Store | 选中要写进面板状态，图片 URL 不许写进去 |
| 面板重试计数 → 视图 hook | 计数变化触发重新取字节，必须 revoke 旧 URL |
