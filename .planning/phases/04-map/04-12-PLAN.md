## Trust Boundaries

| Boundary | 描述 |
|----------|------|
| 指针 / 键盘输入 → 编辑动作 | 输入可能越界、快速连点、在拖动中按右键 |
| 剪贴板 → 粘贴 | 剪贴板与当前地图尺寸无关 |
| 画布 → 文档 | 画布是唯一高频写入口 |
| 渲染模型 → WebGL | 图元数量随地图尺寸增长 |
