## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → root devDependency | A freshly published release of a build-time tool executes inside CI and every developer's install. |
| Boundary rules → the module graph | A rule whose subject never resolves passes silently; a green gate over a dead rule is worse than no gate. |
| Verifier → the tool's real output | Asserting configuration text instead of the tool's emitted result reproduces the exact class of bug the gate exists to prevent. |
| CI step → the four-job contract | Adding or renaming a job silently un-gates merges by invalidating the required-status-check configuration. |
| Editor-owned generated tree → core source | Core depends on the consumer's generated `styled-system`; a missing generation silently reds core's typecheck. |
