## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `catalog:default` reference → workspace catalog | A catalog reference resolves only if the catalog defines the package; declaring one for an undefined name fails at install, and declaring a literal version silently forks the version set. |
| Workspace symlink graph → Node resolution | Node, not the lockfile, decides which copy of React/antd/immer a module gets; two realpaths means two instances at runtime. |
| `exports` map → tracked source tree | A subpath target that does not exist on disk is a latent failure: it resolves only when someone imports it. |
| CI step → the four-job contract | Adding or renaming a job silently voids the repository's required-status-check configuration. |
