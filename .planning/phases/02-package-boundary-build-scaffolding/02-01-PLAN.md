## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| New workspace package → editor build graph | Core source becomes part of the editor's TypeScript program and Vite module graph; a wrong resolution here is invisible to a passing build. |
| `package.json` `exports` → the repository's tracked tree | An `exports` target that points at a gitignored or generated path resolves for the author and breaks for everyone else. |

| pnpm workspace graph → every consumer | A peer that the library installs for itself would fork the instance at runtime. |
