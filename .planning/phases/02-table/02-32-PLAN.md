<objective>
修掉「切表 / 刷新后卡一下（P26）」：现在每次刷新都会先把整张表卸掉（切成「正在加载」空态）再整棵树重建，约 100 行 DOM 反复重新挂载；本计划让刷新改为**原地更新**——内容没变就直接复用现有节点，并给表格加记忆化，使内容未变的刷新**完全跳过重渲染**。

Purpose: 剖析显示瓶颈主要是**元素挂载开销**，而非 schema / 行树分析。原因不是数据算得慢，而是每次刷新都把界面拆了重建。只要不再拆，React 就能按稳定的 key 复用已有节点；再加上「内容没变就返回同一批元素」的记忆化，切换与刷新的开销会显著下降，view 也不再闪一下空态。

2. `components/TableGrid.tsx`——`React.memo` 包裹表格 + 行元素列表记忆化。
