## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 活动面板切换 → 面板钩子 | 外壳调用 `onSwitchIn` / `onSwitchOut`；一次切入可能重复拉取资源 |
| schema 按钮 → 打开器能力 | 打开器由受信组合根注入；面板只传目标串 |
| 代码编辑器返回 → 资源写回 | 返回文本来自外部编辑器，写回前须解析校验 |
| schema / 单元格文本 → DOM | 文本为可被影响的输入，只作文本渲染 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-20 | Denial of Service | `onSwitchIn` 反复拉取资源 | medium | mitigate | 仅在活动面板真正变化时触发（02-05）、请求幂等，且切入后才重算，不在钩子里写回，无回环。 |
| T-02-21 | Spoofing | 打开器能力身份 | low | accept | 由受信组合根装配；面板无法伪造。 |
| T-02-22 | Tampering | schema / 单元格文本渲染为标记 | medium | mitigate | 一律 React 文本节点。 |
| T-02-23 | Tampering | 代码编辑器返回的整份内容写回 | high | mitigate | 写回前解析为 JSON；解析失败即拒绝写回、资源不变；写回经统一撤销路径的可逆操作，不绕过提交层。 |
| T-02-SC | Tampering | package installs | high | mitigate | 本计划不新增依赖。 |
