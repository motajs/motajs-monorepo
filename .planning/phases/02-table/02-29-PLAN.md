<objective>
修复同面板内的同步滞后（G-02-UAT2 的 P18 / P20）：在同一表格面板里改 schema 后，面板内引用同一 schema 的其它栏（其它 schema 栏与主数据表）**立即刷新**，不再需要额外触发 focus。

Purpose: 现在改完 schema，同面板的另一栏 schema 表和主数据表要「点一下 / 切走再切回」才更新，对照编辑时非常别扭。根因是写盘只更新了触发那一栏。修复后同一面板内任何一栏的写盘都会把「引用同一资源的其它栏」一起刷新；仍不做跨面板实时刷新（符合 D-15 / D-31）。

Output:
1. `tablePanel.ts`——写盘后刷新同面板内引用该资源的其它栏。
2. `panelSync.uat.test.tsx`（新）——同面板改 schema 立即同步的用例。

**新增命名提案（逐条待用户按「重要命名先确认」门禁确认后才可落实现）：**
- `TablePanel.refreshDependents(columnIndex: number, changedId: IResourceIdentifier): void`（**新增**私有方法，`tablePanel.ts`）：按被写资源 id，刷新本面板内引用它的其它栏。

</objective>
