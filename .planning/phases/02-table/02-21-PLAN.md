<objective>
修复 UAT 的层级视觉与对齐（G-02-LAYOUT 的 P3 / P4 / P8 / P11）：层级缩进只作用于「条目」列，其余三列保持与顶层对齐；条目列加树形缩进引导竖线、外边框加粗；嵌套展开行按层级逐级加深背景并把缩进缩到约 3/4；单元格内容由靠上改为垂直居中。

Purpose: UAT 里子层级整行被收窄并右移，四列纵向对不齐；层级关系不直观（无缩进引导线、外框过细）；嵌套展开行与子行底色无差别、缩进偏宽；单元格内容贴着上沿。修复后嵌套结构与旧编辑器观感一致，四列严格对齐。

Output:
1. `TableGrid.tsx`——渲染递归逐层传递 `level`。
2. `TableRow.tsx` / `GapRow.tsx`——接收 `level`，据层级缩进与着色。
3. `table.css`——缩进只在条目列、树形引导线、外框加粗、逐级底色、缩进 3/4、垂直居中。
4. `indent.uat.test.tsx`（新）——覆盖上述行为。

**新增 / 改动命名提案（逐条待用户按「重要命名先确认」门禁确认后才可落实现）：**
- `ITableRowProps.level: number`（**新增**只读成员，`components/TableRow.tsx`）：叶子行在行树中的深度（0 基），用于「条目」列缩进。
- `IGapRowProps.level: number`（**新增**只读成员，`components/GapRow.tsx`）：分组行的深度（0 基），用于层级着色与缩进。
- `renderRows(rows, context, level)` / `renderRowNode(row, context, level)`（**既有非导出函数签名扩展**，`TableGrid.tsx`）：递归传递当前层级。
- CSS 钩子（非对外命名，登记备查）：`.etable-tree-guide`（条目列左侧引导竖线）、`data-level`（层级属性）、`--etable-indent`（缩进步长变量，约 9px）。

</objective>
