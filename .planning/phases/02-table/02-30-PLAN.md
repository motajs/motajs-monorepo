<objective>
优化切换 / 编辑表格时的卡顿（G-02-UAT2 的 P23）：把「每次校验都新建 ajv 并编译」改为共享实例 + 按 schema 引用的编译缓存；把行树构建按输入引用缓存，输入未变时直接复用。

Purpose: 开 3 个面板切换时约需 0.5s，主要来自两处重复劳动：校验时反复 `new Ajv2020` 并编译 schema；以及每次切入 / 写盘后重建整棵行树。去掉这两处重复后，切换与编辑明显更跟手，且不改变任何对外行为。

Output:
1. `model/validation.ts`——共享 ajv + 编译缓存。
2. `model/traversal.ts` / `model/schemaPresentation.ts`——行树结果缓存。
3. `performance.uat.test.tsx`（新）——缓存命中的用例。

**新增命名提案（逐条待用户按「重要命名先确认」门禁确认后才可落实现）：**
- `sharedAjv`（**新增**模块级变量，非导出，`validation.ts`）：懒创建的共享 `Ajv2020` 实例。
- `validatorCache`（**新增**模块级常量，非导出，`validation.ts`）：`WeakMap<object, ValidateFunction>`，按 schema 引用缓存已编译校验器。
- `getValidator(schema)`（**新增**非导出函数，`validation.ts`）：取（必要时编译并缓存）某 schema 的校验器。
- `tableTreeCache`（**新增**模块级常量，非导出，`traversal.ts`）：按 (schema, data) 引用缓存 `buildTableTree` 结果。
- `schemaTreeCache`（**新增**模块级常量，非导出，`schemaPresentation.ts`）：按 schema 引用缓存 `buildSchemaTree` 结果。

</objective>
