<objective>
修复 UAT 的 B5：全局撤销 / 重做快捷键没有接线，Ctrl+Z 只触发浏览器原生撤销。把 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 接到 `editor-core` 外壳里的 `UndoSystem`，并 `preventDefault`。

Purpose: 表格编辑已走统一撤销（D-09），但没有键盘入口，用户按 Ctrl+Z 得到的是浏览器原生撤销，与旧编辑器体验不符。接线后撤销 / 重做对所有宿主统一可用。

Output:
1. `editor-core/src/shell/shellSystem.ts`——外壳根组件挂载全局 keydown 监听；把 undo/redo 执行器经 props 传入；一个内部纯函数把按键组合解析为「撤销 / 重做 / 无关」。
2. `editor-core/src/shell/__tests__/shellUndoShortcut.test.ts`（新）——三种组合、preventDefault、空栈安全。

**层选择结论：editor-core 外壳（`ShellSystem`）。** 理由见 `<objective>` 上方注释与下段；**不**放在各宿主的组合根。

**为什么不是组合根：** 撤销 / 重做由 editor-core 的 `UndoSystem` 拥有，`ShellSystem` 构造时即持有它并负责渲染编辑器 UI 根；把它交给组合根意味着 editor-dev、`@motajs/editor`、第三方各自重复接线（且容易漏），正是本次缺口的成因。外壳是「所有宿主共有」的那一层，绑在这里即「一次实现、处处生效」，且不违反 editor-core 的引擎无关 / 不读文件约束。

**新增命名提案（逐条待用户按「重要命名先确认」门禁确认后才可落实现）：**
- `UndoRedoShortcut`（数值 `const enum`，`shellSystem.ts`，**非导出**）：快捷键语义——成员 `Undo` / `Redo` / `None`。备选名 `ShortcutKind` / `KeyboardIntent`。
- `resolveUndoRedoShortcut(event: KeyboardEvent): UndoRedoShortcut`（函数，**非导出**）：把键盘事件解析为撤销 / 重做 / 无关（纯函数）。
- `IShellRootProps.onUndo` / `IShellRootProps.onRedo`（成员）：外壳根组件触发撤销 / 重做（由构造函数绑定到 `undoSystem`）。

</objective>
