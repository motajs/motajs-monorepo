## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-23 | Tampering | values returned from external editors | high | mitigate | Returned values re-enter through the same validated commit path (`checkRange` before write), so an editor cannot bypass validation. |
| T-02-24 | Tampering | modal item labels/thumbnails | medium | mitigate | Rendered as React text nodes / `<img src>` with the provided string only; no raw-HTML and no inline script. |
| T-02-25 | Elevation | clipboard via global | high | mitigate | Copy goes through an injected capability; the source contains no `navigator`/`document` reference (gate-enforced). |
| T-02-26 | Denial of Service | modal with a very large item list | low | accept | The list scrolls; no virtualization is contracted this phase. |
| T-02-SC | Tampering | package installs | high | mitigate | No dependency added. |
</threat_model>
