<objective>
Define the two new `editor-core` contract seams that Phase 2 needs, as **types only** (no behaviour):

1. **D-15 seam** — a way for a panel that has just written a resource to broadcast "this resource changed" so every other panel watching it re-renders immediately.
2. **D-06 mechanism** — how "编辑 Schema" opens a *new* table panel already aimed at `table#schema.<name>`. The DEFAULT is an injected opener (plan 02-03) plus the panel's `ITablePanel.setTable` (plan 02-02) — no editor-core change. Generalizing the shell's 「打开参数」 is an explicit checkpoint opt-in, because `02-CONTEXT` `<deferred>` defers that generalization.

Purpose: The research established that neither seam exists today (`Resource.write` never broadcasts; `IEditorPanelFactoryParam` carries no open parameter). They must be pinned down before any implementation plan, and they are public contracts, so the shapes are decided with the user at the checkpoint task.

Output: An extended `panel/types.ts` (D-15 member) in `editor-core`; a touched `shell/types.ts` only if the checkpoint opts into generalizing the shell open parameter. No behaviour, no tests added, existing suite unchanged.
</objective>
