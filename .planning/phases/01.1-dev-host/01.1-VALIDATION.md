# Phase 1.1 — Validation Strategy

> Per-phase validation contract. This phase is a **dev-only integration**; its acceptance is largely **manual** ("open it in a browser and see/reach the shell"). The automated surface is the dev package's typecheck (and, optionally, one smoke test).

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | TypeScript (`tsc -b`) required; vitest optional (a minimal smoke test) |
| **Config file** | `packages/apps/<dev-pkg>/tsconfig.json` (package name to be confirmed in `INTERFACE-NAME.md`) |
| **Quick run command** | `pnpm --filter @motajs/editor-dev typecheck` |
| **Full suite command** | `pnpm --filter @motajs/editor-dev typecheck` (+ the smoke test if added) |
| **Estimated runtime** | ~15 seconds |

> The dev package name is a proposal; commands substitute the confirmed name.

---

## Sampling Rate

- **After every task commit:** `pnpm --filter @motajs/editor-dev typecheck` + 根 `pnpm lint`
- **After every plan wave:** typecheck + **manually open the dev host in a browser** and confirm the shell renders
- **Before `/gsd-verify-work`:** the dev host typechecks; the shell is reachable in the browser; a panel can be opened/closed
- **Max feedback latency:** 60 seconds (automated) / minutes (manual)
