## Sampling Rate

- **After every task commit:** 受影响单文件 `vitest run <file>` + 该包 `typecheck`。
- **After every plan wave:** 三个包全量 `test` + 三个 `typecheck` + 四条门禁。
- **Before `/gsd-verify-work`:** 三包全绿 + 四条门禁全绿 + `pnpm lint`（0 error）+ `pnpm format:check` + 手动验收表完成。
- **Max feedback latency:** 单文件 < 60s；`coreBoundaries` 单独放宽到 ~3 min。
