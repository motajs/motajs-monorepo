# Phase 04.2: 面板内容解耦与文件资源管理器 - Context

**Gathered:** 2026-10-27
**Status:** Ready for planning

<domain>
## Phase Boundary

把「面板」和「组件」的职责分开：面板是唯一知道文件路径的角色，负责读文件、把内容分配给一个或多个组件、把组件交回的内容写回文件；组件不接触路径，只接收内容，内部编辑，需要保存时发出保存请求，并通过 ref 暴露读取内容、替换内容、脏状态和已保存标记。

新增文件资源管理器面板：浏览项目文件，按面板自己对完整路径的判断选择可用面板（不只看后缀），多个候选时由用户选择。表格面板保持三栏，每栏的表格组件改用上述组件契约。

04.2 内分波次把表格、地图、素材三个面板都按「功能区组件」拆开，并补上文件变化同步与关闭前提示。
</domain>

<decisions>
## Implementation Decisions

### 分层与组件契约
- **D-01:** 面板是唯一知道路径的角色；组件不接收路径、不主动读文件。
- **D-02:** 组件接收面板传入的内容，并在挂载期间持有编辑状态。
- **D-03:** 组件通过 ref 暴露四项能力：读取当前内容、替换内容、判断是否有未保存改动、标记已保存。
- **D-04:** 组件在内部请求保存时发出保存请求，携带当前内容的快照；该请求返回一个 Promise 结果，组件据此显示保存中 / 成功 / 失败。
- **D-05:** 面板在切走时调用「读取当前内容 + 判断脏状态」并保存；保存成功后调用「标记已保存」；普通切走的保存不可取消。
- **D-06:** 组件只在挂载期间持有状态；面板负责在切走 / 关闭时把内容取回并保存，重新切入时把最新内容传给组件。
- **D-07:** 只有可编辑组件实现保存契约；预览、工具栏、导航等只读组件只接收内容 / 回调，不实现保存。
- **D-39:** 面板是文件数据与组件内容之间的适配器：面板按自己要的数据类型从文件读取并转换，组件收到的内容结构**不要求**与文件原始结构同构。这次重构正是为了允许后续内容依赖这种「面板结构 ≠ 文件结构」的能力。
- **D-40:** 草稿归属采用分层契约：表格组件持有草稿；地图 / 素材由面板持有权威文档，组件只接收内容 + 回调，不自己保留一份草稿。所有可编辑组件仍然都接收内容并发出保存请求，但「谁持有权威内容」由面板决定，以保住 04.1 的保存 / 撤销模型。

### 关闭流程
- **D-08:** 关闭前询问返回三态：保存并关闭 / 不保存关闭 / 取消。
- **D-09:** 「保存并关闭」由面板保存；保存成功后外壳跳过普通切走的落盘，直接关闭；保存失败保持打开。
- **D-10:** 「不保存关闭」外壳跳过普通切走的落盘，直接释放；「取消」保持标签。
- **D-11:** 普通切走仍然是「必须落盘、不可取消」，不参与关闭决策。

### 文件变化同步
- **D-12:** 宿主提供文件变化流；core 只监听这一条通道。
- **D-13:** 本期先假定宿主一定会传入文件变化流；具体宿主实现（Node 侧监听、浏览器宿主是否提供）后续再定。
- **D-14:** 资源层不在自己 write 后额外通知，避免两个来源重复触发。
- **D-15:** 宿主事件到达时照常通知，不因为资源层缓存里已经是新内容就吞掉；去重放在面板 / 组件层。
- **D-16:** 面板只处理自己打开的路径；收到通知后比较内容，真的变了才替换组件内容。
- **D-17:** 冲突规则：面板没有未保存改动时自动刷新；有未保存改动时不覆盖，提示用户选择「放弃我的改动并刷新」或「保留我的改动，下次保存覆盖」。
- **D-18:** 宿主提供的变化流需要覆盖编辑器自己的写入；旧开发宿主不在本期适配范围，新版宿主后续接入。

### 改造范围与组件边界
- **D-19:** 04.2 内分波次全拆：通用契约 → 表格三栏 → 文件资源管理器 → 地图区 / 素材区；每波单独验收。
- **D-20:** 按现有功能区划组件；地图区、素材区、表格每栏、素材分类 / 列表 / 详情 / 预览等都可以独立复用。
- **D-21:** 表格面板保持三栏；每栏一个表格组件；本期不做「外部一次给三份内容」的模式，由面板按栏分配。
- **D-22:** 素材 / 地图的逐组件清单在接口计划中列出，沿用现有功能块，不重画界面。

### 文件资源管理器
- **D-23:** 只做浏览 + 打开；新建 / 重命名 / 删除 / 移动后续再加。
- **D-24:** 复用同一个文件浏览器组件；单目录列表 + 面包屑；组件只渲染，面板提供「读目录」「过滤」「打开」三项输入。
- **D-25:** 表格空栏复用该浏览器；过滤规则与表格的「能否打开」判断一致（`.json` + `.jsonc`，包含 schema）。
- **D-26:** 面板类型提供两项可选能力：判断完整路径能否打开、把路径转成自己的打开参数；资源管理器询问所有已注册面板类型。
- **D-27:** 多个候选时每次弹窗让用户选；没有候选时提示；只有一个时直接打开。
- **D-28:** 资源管理器总是新开标签；同步做好后，重复打开同一个文件是安全的。
- **D-29:** 宿主在创建资源管理器面板类型时注入「列面板类型 / 打开面板」回调；`editor-core` 不因此扩大面板上下文。
- **D-30:** 预览组件本期不加。

### 面板类型与打开参数
- **D-31:** 后缀列表不够，判断依据是完整路径。示例：表格接受所有 `.jsonc`，代码编辑器接受所有 `.jsonc`，地图只接受 `maps/*.jsonc`。
- **D-32:** 面板类型自己把路径转成打开参数；资源管理器不解释参数形状。
- **D-33:** 面板类型的两项能力都是可选的；没有声明的面板不会被资源管理器列为候选。

### 接口与命名
- **D-34:** 第一波只定义接口与命名；命名在 `INTERFACE-NAME.md` 中逐项确认后才写实现。
- **D-35:** `editor-core` 需要新增 / 修改的接口：关闭三态、文件变化流、面板类型的「能否打开 / 打开参数」；具体形状在接口计划中定。
- **D-36:** 文件变化的去重与自写回声抑制放在面板 / 组件层，不在资源层。

### 面板生命周期
- **D-37:** 非活动面板不渲染；外部更新只更新面板保存的内容，等重新切入时再传给组件。
- **D-38:** 关闭前外壳先激活目标标签（现有行为），面板自己弹三态确认框。

</decisions>

## Existing Code Insights

### Reusable Assets
- `TableGrid` / `TableRow` / schema form 组件：已经按「数据 + 回调」驱动，最适合改成组件契约。
- `TablePicker`：现有单目录列表 + 面包屑的雏形，可抽成通用文件浏览器。
- `MapSurface` / `MapCanvas` / `MapMaterialPanel` / `MapBottomTabs` / `MapFavoriteBar` / `MapPropertiesDrawer`：地图功能块，可直接作为组件边界。
- `AssetGrid` / `AssetDetail` / `AssetPreview` / `AssetConfigView` / `CategoryNav` / `AssetToolbar` / `TranscodeModal`：素材功能块。
- `IEditorPanelContext`：面板已有请求资源、创建、删除、移动、列目录、添加撤销上下文。
- `ShellSystem.openPanelInTab` / `openBlankTab` / `listPanelTypes`：宿主可通过注入回调转给资源管理器。

### Established Patterns
- 面板类型通过 `IEditorPanelType` 注册；宿主负责装配，能力通过参数或 React context 注入（地图、素材、表格已有先例）。
- 资源层以纯路径为唯一标识，内容缓存 + 文件索引；写文件不自动通知其他面板。
- 关闭标签前外壳先激活目标标签，再调用关闭前询问；随后释放标签时会走普通切走的落盘。
- 非活动面板不渲染，组件只存在于活动标签中。

### Integration Points
- `editor-core`：关闭三态、文件变化流、面板类型的「能否打开 / 打开参数」、更新通知语义。
- `editor-impl`：表格三栏、地图 / 素材组件拆分、文件浏览器组件、资源管理器面板。
- `editor-dev`：新版宿主注入文件变化流、注册资源管理器面板、提供「列面板类型 / 打开面板」回调。
- 测试：`editor-core` / `editor-impl` / `editor-dev` 的现有测试与端到端需要迁移。

</code_context>

<specifics>
## Specific Ideas

- 表格：三栏，每栏一个表格组件；从资源管理器打开文件时默认第 0 栏。
- 地图：地图区、素材区各自是组件；地图只接受 `maps/*.jsonc`。
- 表格接受所有 `.jsonc`；代码编辑器接受所有 `.jsonc`；素材列表按自己的路径约定判断。
- 文件浏览器：单目录列表 + 面包屑，窄栏也能用。
- 关闭提示：保存并关闭 / 不保存关闭 / 取消。
- 同步冲突：不脏自动刷新；脏则提示「放弃并刷新」/「保留并下次覆盖」。
- 命名在 `INTERFACE-NAME.md` 中确认；本期不锁死最终名字。

</specifics>
