## 六项人工验收

| ID | 验收项 | 怎么操作 | 应该看到什么 | 判定标准 |
|----|--------|----------|--------------|----------|
| U-01 | 资源管理器窄栏的面包屑 | 打开「文件资源管理器」面板，把窗口缩到约 360px 宽；逐级进入深层目录（如 `content/map` → 更深一层），再逐段点面包屑往回跳，最后点根段 `/` | 面包屑只有一行、不换行、不挤压工具栏；每段都能点；跳转后**当前目录那一段**在可见范围内（不被右侧截掉） | 不换行 + 每段可点 + 当前段可见，三条同时成立才算通过 |
| U-02 | 同一路径被两个面板认领时的候选弹窗 | ① 在 `content/map/` 里点一张地图文件（表格与地图都会认领同一路径）→ 弹「选择打开方式」→ 先点「地图」；再点同一张图 → 这次点「表格」。② 再点 `tables/demo.json`（只有表格认领） | ① 弹窗列出两个类型，每项一个全宽按钮，页脚只有「取消」；选「地图」开到地图面板、选「表格」开到表格面板，两次都开在**新标签**里。② 不弹窗，直接开到表格面板 | 两次选择各开到正确面板 + 单候选不弹窗。**注意：** 没有面板认领的文件（如 `.txt`）会被列表直接过滤、界面上根本不出现，所以「没有可以打开该文件的面板」这一分支不在本清单里验收——它由 `explorerPanel.test.tsx` 在面板 API 层覆盖 |
| U-03 | 关闭三态弹窗（保存 / 不保存 / 取消） | ① 在表格里改一格 → 点标签上的 ✕ → 三个按钮各验一次：先「取消」，再「不保存关闭」，最后重开改一格后点「保存并关闭」。② 把窗口拉宽到铺出 3 栏，两栏各改一格后再点 ✕。③ 地图面板与素材面板各做一次「改一处 → ✕」 | ①「取消」：标签还在、改动还在；「不保存关闭」：标签关闭，磁盘上仍是**旧值**；「保存并关闭」：标签关闭，磁盘上是**新值**，保存期间主按钮变「正在保存…」、另两个按钮禁用。② 只弹**一个**确认框（不是每栏一个）。③ 地图与素材同样只弹一个、三条分支行为一致 | 三条分支各验一次且结果如上；3 栏时只弹一个框；三个面板都覆盖 |
| U-04 | 外部修改后的自动刷新与冲突提示 | ① 开两个标签编辑**同一个文件**；在 A 里改一格并保存 → 看 B。② 让 B 有未保存改动，再在 A 里保存一次 → 看 B。③ B 弹冲突后，两个选项各验一次：「放弃我的改动并刷新」与「保留我的改动，下次保存覆盖」 | ① B 自动刷新成新内容，**不弹任何框**。② B 弹「文件已被外部修改」，两个选项文案如上；期间 B 的改动没被静默覆盖。③ 选「放弃」→ B 显示 A 的新内容；选「保留」→ B 保留自己的改动，再保存时覆盖外部内容 | 不脏自动刷新且不弹框；脏则弹冲突且不丢改动；两个选项各自的结果正确 |
| U-05 | 图片替换后的预览刷新与「重试」真的重读 | ① 替换一张图块图（或一个素材的字节），不重开面板。② 在地图区制造一次「图块加载失败」，点它的「重试」按钮 | ① 图块区与素材预览**无需重开面板**即显示新图。② 点「重试」后图片真的被重新读取（画面变化），不是毫无反应 | 两处都不重开面板即更新；重试按钮有实际效果 |
| U-06 | 改一格保存的补充确认 + 切标签的保存时序（B1） | ① 在表格里改一格再保存，看有没有异常。② 改一格后**直接切到另一个标签**、再切回来；用文件修改时间或宿主日志确认写盘次数 | ① 保存后没有「草稿被重置」或「ref 为 null」的报错，改动正常落盘。② 切走时磁盘已是新值（保存发生在卸载之前）；切回来内容仍是刚改的值；**同一次切换只写一次盘**，不出现「保存后又存一次」 | ① 无草稿重置 / ref 为空。② 卸载前已落盘 + 切回内容仍在 + 只写一次，三条同时成立 |

**关于 U-06 的边界：** 这一项**不是** React Compiler 的验证——开发宿主 `editor-dev` 未启用 `babel-plugin-react-compiler`，无法用它判定编译期行为。编译期行为由 `editableContract.test.tsx`（`pnpm --filter @motajs/editor-impl test`）自动化覆盖，判定以那条自动化结果为准；开发宿主里只做「运行期没有草稿被重置 / ref 为 null」的补充确认。
