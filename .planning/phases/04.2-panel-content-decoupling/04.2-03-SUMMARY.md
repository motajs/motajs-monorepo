## Decisions Made

- 组件契约采用 React 19 的 `ref` 普通 prop（`readonly ref?: Ref<IEditableContentHandle<T>>`），不写 `forwardRef`；`setData` 的 JSDoc 明写「替换后视为已保存基线」。
- `ITableEdit` 用单接口而非对象联合（项目代码风格）：`kind` / `key`（字段路径，`Add` 时是锚点）/ `value?` / `anchorKey?` / `name?` / `config?`。
- `ITableEditableProps.onOpenSchema` / `onOpenInCodeEditor` 带上开口器参数（`ITablePanelOpener` / `ICodeEditorOpener`，从 `react/capabilities` 普通 import）：不带参数就无法把打开器透传给 `TableGrid`，「编辑 Schema」会失效；类型名全部复用既有。
- `IFileBrowserProps` / `IFileExplorerCapabilities` / `IFileExplorerViewProps` 的函数成员用 `readonly xxx: (...) => ...` 属性形态：既满足「九个成员全部 readonly」，又不引入未经用户确认的新 type 别名。
- 两张图块地址表键空间分离并在 JSDoc 写死：`IMapImageSources` 用图片路径、`IMapTileGroupUrls` 用 `group.id`，禁止互相查表。
- `IMapImageSourceStore.version` 是 `readonly` 普通成员，不写 `get version()`；`refresh` / `getSources` / `getGroupUrls` / `dispose` 四条齐全。
- 接口级 JSDoc 按 AGENTS.md 代码风格省略；原先要写在接口上的口径（「Plan 10 只把它挂到视图状态上」「键是图片路径」「只浏览 + 打开」）分别落到**文件级注释**与**成员 JSDoc**，信息未丢失。
