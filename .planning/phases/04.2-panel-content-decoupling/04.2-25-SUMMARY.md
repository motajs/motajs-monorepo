## Decisions Made
- 说明注释写在组合规则的声明块内部，而不是规则上方：计划自带的 CSS 源断言用 `/([^{}]+)\{([^{}]*)\}/g` 取选择器文本，规则上方的 `/* */` 会被并入选择器，使 `.efb-crumb` 的精确匹配失败（详见 Deviations）

**1. [Rule 3 - Blocking] 组合规则的说明注释移到声明块内部**
- **Found during:** Task 1（首轮跑 `fileBrowser.test.tsx`）
- **Issue:** 计划要求「规则上方写一句中文 `/* */` 注释」，但计划自带的 CSS 源断言与该注释冲突：断言用 `/([^{}]+)\{([^{}]*)\}/g` 取选择器并把 `/* … */` 一并算进选择器文本，导致 `.efb-crumb` 无法精确匹配，新用例与断言命令都会失败（首轮实测：`expected undefined to be '24px'`）
