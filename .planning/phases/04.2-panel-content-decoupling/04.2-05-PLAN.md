<objective>
把宿主文件变化流接进 core：`ResourceSystem` 在初始化时订阅、释放时退订，事件到达时更新文件索引与内容缓存并把「路径 + 种类」转给面板；`ShellPanelHooks` 优先走新的不预读通道，旧面板继续走原来的预读通道。

Output: `ResourceSystem` 的订阅 / 校验 / 索引缓存同步、`ShellPanelHooks` 的两条转发分支、带显式开关的测试替身，以及一组把七条语义钉死的测试。
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 宿主 `watch` 回调 → core | 事件路径是不可信输入，可能含 `..`、绝对路径或改名残留 |
| core 钩子 → 面板 | 面板会按路径读文件，路径必须已被规范化 |
