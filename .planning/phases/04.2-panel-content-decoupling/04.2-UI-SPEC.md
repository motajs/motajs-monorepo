# Phase 04.2 — UI Design Contract / 面板内容解耦与文件资源管理器

> 本文件是「面板内容解耦与文件资源管理器」的视觉与交互契约。由 gsd-ui-researcher 生成，gsd-ui-checker 校验。
>
> **范围。** 本契约覆盖本阶段**新出现的四个界面表面**：
> ① 可复用**文件浏览器组件**（单目录列表 + 面包屑，表格空栏与资源管理器共用）；
> ② 新增**文件资源管理器面板**（头部标题 + 浏览器 + 候选面板弹窗）；
> ③ **关闭三态弹窗**（保存并关闭 / 不保存关闭 / 取消）；
> ④ **外部变化冲突弹窗**（放弃我的改动并刷新 / 保留我的改动，下次保存覆盖）。
> 以及表格面板空栏**接入共用浏览器**后的可见差异。**不重画**表格三栏网格、地图面板、素材面板的任何布局（D-19 / D-21 / D-22）。
>
> **不重复的部分。** 外壳（菜单行 / 标签行 / 内容区）属 Phase 1；表格网格、schema 表单、地图布局、素材三栏分别属 Phase 2 / 04 / 03 契约。本文只约束本阶段新增表面的**布局、令牌、状态、文案、焦点与测试标识**，以及它们**挂载**到既有面板的形态。
>
> **命名提示（项目规则）。** 本文出现的代码标识（组件名、文件名、CSS 类名、props 名、`data-test-id`）均为**工作名 / 提案**，**不是已锁定契约**。任何重要命名必须先写入 `.planning/phases/04.2-panel-content-decoupling/INTERFACE-NAME.md` 并经用户确认，才可落进代码、计划或配置。本文锁定的是**角色、布局、视觉令牌、文案与交互结果**。方法引用一律写 `类名.方法名`，自由函数写裸名。
>
> **无新依赖。** 本阶段不新增任何 UI 库 / 图标库 / 样式方案：组件库仍是 `antd@6.2.1`（`editor-impl` 的 peerDependency），样式仍是同目录普通 CSS + `--editor-*` 变量，图标仍是**自包含内联 SVG（16px，`currentColor`）**。

## Typography

**恰好 4 个字号 / 2 个字重**。字体族继承宿主（面板与弹窗不声明）。

| 角色 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 16px | 600 | 1.2 | 三个弹窗的标题（antd `Modal` 标题，默认即 16/600） |
| Heading | 14px | 600 | 1.3 | 资源管理器面板头部的面板标题 |
| Body | 13px | 400 | 1.5 | 列表行文字；面包屑；按钮文字；弹窗正文；候选面板名称 |
| Label | 12px | 400 | 1.4 | 候选弹窗顶部「文件：{路径}」；浏览器空 / 错误提示；辅助说明；表格空栏既有提示 |

字重：正文 / 标签一律 **regular（400）**，标题一律 **semibold（600）**，无其它字重。

文本行为（穷尽）：

- **列表行名称**：单行省略号（`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`），元素 `title` 为**完整路径**。
- **目录行**：`font-weight: 600`；**文件行**：`font-weight: 400`。行内不放图标。
- **面包屑**：单行**不换行**；每段 `max-width: 160px` + 省略号，`title` 为该段对应路径；当前目录段（最后一段）为**非交互文本**，不加省略号以外的交互态。
- **弹窗正文**：允许换行（`white-space: normal`），错误原因过长时换行显示，不撑破弹窗（`overflow-wrap: anywhere`）。
- **候选弹窗名称**：单行省略 + `title` 为面板类型名称。
- 数字不涉及本阶段；不需要 `tabular-nums`。

> 密度注：外壳（Phase 1）用 Body 14 / Label 13；本阶段新增表面与表格 / 地图 / 素材一致地**下沉一号**（Body 13 / Label 12），以贴合现有编辑器的紧凑工具界面。

## Color

**浅色为本契约基准。** 新表面**复用 Phase 1 外壳的 CSS 变量**（`--editor-*`），以字面量作 fallback 消费，因此主题与外壳自动一致。

| 角色 | 值 | 用途 |
|------|----|------|
| Dominant (60%) | `#ffffff`（`var(--editor-surface, #ffffff)`） | 浏览器列表底色；面板主体；弹窗正文 |
| Secondary (30%) | `#f5f6f8`（`var(--editor-bg)`）+ `#ffffff`（`var(--editor-toolbar-bg)`） | 面板头部与浏览器工具栏底色；行悬停底（`rgba(0,0,0,0.04)`） |
| Accent (10%) | `#1677ff`（`var(--editor-accent, #1677ff)`） | **保留 —— 见下方清单** |
| Destructive | `#cf1322`（文字）+ antd `danger` 令牌（按钮） | **保留 —— 见下方清单** |

**Accent 保留给（穷尽）：**

1. 面包屑**当前目录段**的文字色（表示「你在这里」，与外壳活动标签同一语义）。
2. 所有可交互元素的 `:focus-visible` **2px 内描边**（面包屑、列表行、重载按钮、候选行、弹窗按钮）。
3. 关闭三态弹窗的**「保存并关闭」**主按钮（`type="primary"`）——本阶段唯一的主按钮。
4. 候选面板行的**悬停底色** `var(--editor-selected, #dbeafe)`（accent 的浅色家族，与外壳悬停一致）。

Accent **绝不**用于：默认文字、列表分隔线、列表底色、普通按钮、错误提示、目录 / 文件的字重区分。

**Destructive 保留给（穷尽）：**

1. 浏览器**错误行**的文字（`#cf1322`）。
2. 关闭三态弹窗的**「不保存关闭」**按钮（antd `danger`）。
3. 冲突弹窗的**「放弃我的改动并刷新」**按钮（antd `danger`）。
4. 关闭三态弹窗内的**「保存失败：{原因}」**错误行（`#cf1322`）。
5. 表格空栏删除态的行内**删除入口**文字（`#cf1322`，沿用现状 `.etable-list-delete`）。

Destructive **绝不**用于：普通行、面包屑、主按钮、重载按钮、候选面板名称。

**支撑中性色（取自 Phase 1 令牌集）：**

| 令牌 | 值 | 用途 |
|------|----|------|
| `--editor-fg` | `#202124` | 列表行名称、弹窗正文、面板标题 |
| `--editor-muted` | `#656d76` | 面包屑非当前段、分隔符、空态 / 加载提示、候选弹窗「文件：」标签 |
| `--editor-border` | `#d0d7de` | 头部 / 工具栏下边框、浏览器外框、弹窗内分隔 |
| `--editor-selected` | `#dbeafe` | 候选行悬停底 |
| `--editor-surface` | `#ffffff` | 列表底、弹窗正文底 |
| `--editor-bg` | `#f5f6f8` | 面板底衬（列表之外） |

**深色变体（宿主覆盖，与外壳同组，面板只读变量）：** `--editor-bg #242424`、`--editor-surface #303035`、`--editor-toolbar-bg #2b2b30`、`--editor-fg #d4d4d4`、`--editor-muted #9da5b4`、`--editor-border #4b4b52`、`--editor-selected #163a5f`。新表面**不设置主题**，只读取变量；行悬停的 `rgba(0,0,0,0.04)` 在深色下改为 `rgba(255,255,255,0.06)`（同一变量的两档取值，由宿主主题切换时一并覆盖）。

**60 / 30 / 10 的边界。** 本阶段没有图像内容参与配色：60% 是列表与弹窗正文表面，30% 是头部 / 工具栏 / 悬停行，10% 是 accent 的四项用途。

## Copywriting Contract

全部文案为**简体中文**，与现有编辑器一致。

| 元素 | 文案 |
|------|------|
| Primary CTA | **「保存并关闭」** —— 关闭三态弹窗的 `type="primary"` 按钮，本阶段唯一主按钮。资源管理器与浏览器**没有 CTA 按钮**：文件行本身就是动作入口（点行即打开），不额外加「打开」按钮。 |

| Error state（浏览器，缺省） | **「目录读取失败，请稍后重试。」** + **「重试」** 按钮；面板传入 `errorText` 时显示该文案，但**「重试」按钮始终存在** |
| Destructive confirmation（关闭三态） | **标题：**「有未保存的改动」**正文：**「当前面板还有未保存的改动。关闭前要保存吗？」**按钮：**「取消」·「不保存关闭」·「保存并关闭」 |
| Destructive confirmation（外部变化冲突） | **标题：**「文件已被外部修改」**正文：**「这个文件在编辑器之外被修改了，你还有未保存的改动。」/「刷新会丢弃你的改动；保留则下次保存会覆盖外部内容。」**按钮：**「放弃我的改动并刷新」·「保留我的改动，下次保存覆盖」 |

| 打开失败提示 | `message.error` **「打开失败，请稍后重试」** |
| 读取外部改动失败 | `message.warning` **「读取外部改动失败，已保留你的改动」** |

## FileBrowser 组件契约（共用浏览器）

> 工作名 `FileBrowser`，位于 `packages/libs/editor-impl/src/shared/fileBrowser/`，样式表 `file-browser.css`（CSS 文件名连字符命名），类名前缀 **`efb-`**。**表格空栏与资源管理器共用同一个组件**（D-24 / D-25）。

### Props（形状提案，名字待 `INTERFACE-NAME.md` 确认）

| 成员 | 说明 |
|------|------|
| `directory: string` | 起始目录；根目录为空串 |
| `loadChildren(path): Promise<readonly IFileEntry[]>` | 读某目录的直接子条目；组件**不碰文件系统**，只调用面板给的回调 |
| `filter?(path): boolean` | 文件是否显示；**目录永不受过滤** |
| `onOpen(path): void` | 点击文件行 |
| `testIdPrefix?: string` | `data-test-id` 前缀；缺省 `file-browser`，表格传 `table-list`，资源管理器传 `explorer` |
| `emptyText?: string` | 空目录文案；缺省「该目录下没有文件」 |
| `errorText?: string` | 读取失败文案；缺省「目录读取失败，请稍后重试。」 |
| `renderRowAction?(entry): ReactNode` | 文件行右侧附加内容（表格删除态用）；缺省不渲染 |
| `reloadToken?: number` | 外部刷新令牌；变化时重读当前目录 |

- 组件根 `.efb`：`display:flex; flex-direction:column; flex:1 1 auto; min-width:0; min-height:0; height:100%; overflow:hidden; border:1px solid var(--editor-border); background:var(--editor-surface); font-size:13px; line-height:1.5;`

### 面包屑规则

- 段由当前目录按 `/` 切分：`''` → 只有根段；`'content/map/texture'` → 根 + 3 段。
- 根段与每个中间段是可点的 antd `Button type="text" size="small" autoInsertSpace={false}`，类名 `efb-crumb`，`data-test-id` 为 `{prefix}-crumb-root` / `{prefix}-crumb-{path}`；点击 = 导航到该段路径。
- **最后一段是当前目录**：渲染为非交互 `<span class="efb-crumb-current" aria-current="location">`，文字为目录名（根目录时为 `/`），颜色 `var(--editor-accent)`，`data-test-id` 为 `{prefix}-current`。
- 段之间是 muted 的 `/` 分隔符（`<span aria-hidden="true">`）。
- **溢出**：不换行；容器横向滚动；**导航后自动滚到最右端**（`scrollLeft = scrollWidth`），保证当前目录始终可见。
- 窄栏（约 360px，表格三分之一宽）同样成立：早期段被滚出视口，当前段与重载按钮始终可见。

### 列表规则

- 当前目录非根时，首行是 `..` 行（`{prefix}-up`），点击进入父目录。
- 目录行：`font-weight:600`；文件行：`font-weight:400`；两者 `data-test-id` 都是 `{prefix}-entry-{path}`（沿用既有表格约定：目录与文件同前缀）。
- 文件行是否显示由 `filter(path)` 决定；**目录行永不受 `filter` 影响**。
- 每行 `title` = 完整路径（`path`），供长名称 / 歧义场景揭示。
- `renderRowAction` 存在时，动作槽包在 `<span class="efb-row-action-slot" data-test-id="{prefix}-row-action-{path}">` 内；表格的删除按钮保留自己的 `data-test-id`（`table-list-delete-{path}`，既有断言依赖）。
- **不做**：方向键遍历、多选、树形展开、拖拽、右键菜单、搜索框。键盘可达性由 Tab 顺序 + Enter/Space 承担（行是原生 `button`）。

### 状态（穷尽）

| 状态 | 呈现 |
|------|------|
| **首次载入 / 目录切换** | 列表区居中 `Spin size="small"` + Label **「正在读取目录…」**（`min-height:96px`），`data-test-id="{prefix}-loading"`；工具栏与面包屑**始终可用**（用户可立刻离开该目录）。 |
| **已有内容时刷新**（手动重载 / `reloadToken`） | **保留旧行可见**，新结果到达后整体替换；**不闪空态、不闪加载态**（与 `TablePanel.refresh` 的「原地更新」同口径）。 |
| **空目录** | 列表区 Label **「该目录下没有文件」**（或 `emptyText`），`data-test-id="{prefix}-empty"`，`min-height:96px`，不替换面包屑。 |
| **读取失败** | 列表区 Destructive Label（`#cf1322`）显示 `errorText`（缺省「目录读取失败，请稍后重试。」）+ **「重试」** 按钮（`data-test-id="{prefix}-retry"`），`data-test-id="{prefix}-error"`；面包屑保留，可导航离开。 |
| **请求竞态** | 每次 `loadChildren` 递增请求序号，晚到的旧结果被丢弃；界面永不显示上一个目录的条目。 |
| **过滤后无文件但有目录** | 不是空态：仍显示目录行（目录不受 `filter` 影响）。 |
| **过滤后完全为空（含无子目录）** | 显示空态文案。 |

### 焦点与无障碍

- 根 `.efb` 不进入 Tab 顺序（无 `tabIndex`）；Tab 顺序：面包屑各段 → 重载按钮 → `..` → 目录行 / 文件行（自上而下）。
- 重载按钮是 `<button>`，`aria-label="重新加载"`，`title="重新加载"`；加载中保持可点（重复点击只触发一次有效读取，靠请求序号丢弃旧结果），并设 `aria-busy="true"` 在列表容器上。
- 列表容器 `role="list"` 不强制；行是原生按钮即可。行可访问名 = 文件名（不覆盖为路径，避免与可见文字不一致）。

### 打开流程（可见结果）

| 候选数 | 结果 |
|--------|------|
| 0 | `message.warning` **「没有可以打开该文件的面板」**；不弹窗、不新开标签。（正常路径下过滤已排除此类文件，此为防御） |
| 1 | **直接新开标签**并打开该面板（D-27 / D-28），无确认、无提示；当前面板保持原样（不切走、不关闭）。 |
| ≥2 | 弹**候选面板弹窗**（见下）；用户选中后才新开标签打开。 |
| 打开失败 | `message.error` **「打开失败，请稍后重试」**；若宿主为「先开空白标签再填内容」的实现，失败时**必须关掉那个空白标签**，不留可见残留。 |

- **总是新开标签**（D-28），即使该文件已在别的标签打开；本阶段不给「已在别处打开」的提示（已知行为，见 UAT 记录）。
- 点击文件行后、弹窗出现前**不进入 loading**（`canOpen` 是同步纯函数，无需异步态）。

### 目录与过滤

- 起始目录恒为**项目根**（`''`）；本阶段不支持「从打开参数定位到某目录」。
- 过滤谓词 = 「存在至少一个已注册面板类型同时声明了 `canOpen` 与 `createOpenParam`，且 `canOpen(path) === true`」。
- **隐藏以 `.` 开头的路径段**（含 `.editor`）：过滤分两级——**目录行**在渲染前按「任一段以 `.` 开头」隐藏（用户无法进入点开头目录），**文件行**再叠加面板谓词。索引照常收录这些文件（**不得**改 `ignore`，否则地图偏好读不到）。
- 目录不受面板谓词影响：任何非点开头的目录都可进入。

### 外部变化

- 收到文件变化通知时：`reloadToken++`，浏览器重读当前目录（索引同步，重列代价低）；**保留旧行直到新结果到达**。
- 非当前目录的变化也允许触发重列（简单口径），但**不得**打断用户正在进行的点击（不重置面包屑、不清空滚动位置以外的东西）。

## 无障碍与焦点

- 所有可交互元素都是真实可聚焦元素（`button` / antd 控件），带可访问名；**不**用 `div` + `onClick`。
- 焦点可见性：统一 `outline: 2px solid var(--editor-accent); outline-offset: -2px`（与外壳一致）。
- 弹窗：antd `Modal` 自带 `role="dialog"` / `aria-modal` / 焦点陷阱与关闭后焦点归还；候选弹窗额外把初始焦点放到第一个候选。
- Esc 语义（明示）：候选弹窗 = 取消；关闭三态弹窗 = 取消；冲突弹窗 = **无**（必须点选）。
- 目录切换后，焦点保持在面包屑中被点击的那一段（若该段因导航被替换为「当前段」非交互文本，则焦点落到列表容器首行）。实现上不强制，但**不得**把焦点丢到 `<body>`。
- 所有文本经 React 文本节点渲染；路径不拼进 `innerHTML`。

## 范围外（本契约明确不含）

以下内容**不在本阶段**，如要实现须另立契约与决策：

- **资源管理器的新建 / 重命名 / 删除 / 移动**（D-23）：浏览器只有「浏览 + 打开」，没有任何写操作入口。
- **文件预览区 / 内容预览**（D-30）：点文件只打开面板，不显示文件内容。
- **搜索框 / 过滤器输入框**：D-24 的「过滤」是**面板提供的谓词**（哪些文件显示），不是用户可输入的搜索框。
- **树形目录展开、多选、拖拽、右键菜单、方向键遍历**：单目录列表 + 面包屑是本阶段唯一导航形态。
- **虚拟滚动 / 大量文件性能优化**：本阶段不契约虚拟化。
- **表格网格、地图布局、素材三栏的任何视觉重画**（D-19 / D-22）：只改组件边界与路径归属，不改观感。
- **暗色主题的新增令牌**：只消费既有 `--editor-*`，不新增主题层。
- **「已在其他标签打开」提示 / 重复打开去重**（D-28）：总是新开标签，不加提示。
- **代码编辑器 / 事件编辑器的文件打开**：后续阶段。
