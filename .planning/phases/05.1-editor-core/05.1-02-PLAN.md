<objective>
只定义包内默认实现层要用的接口与类型落点：`lib/edit/types.ts`（`IPatchableResource<T>`）、
`lib/resources/types.ts`（追加 `IResourceView<T>`/`ILoadableResource<T>`）、`lib/table/types.ts`
（`ActionType`/`Action`）。**一行实现都不写。**

Purpose（说人话）：这一层是包里的「编辑功能」——表格、地图、代码编辑这类，它们自己管自己的内容。
这个计划只先把它们彼此之间、以及它们与底层之间**要对齐的接口**写清楚，特别是「什么东西算一张
可编辑的表格数据」「资源的只读视图长什么样」，好让后面的搬家和实现有依据。

This plan is interface-only (D-16) and is the default-implementation-layer counterpart to 05.1-01.

Decisions implemented here — D-01 (default impls depend on the bottom layer), D-03/D-06 (each default
implementation holds its own content; no unified content abstraction), D-07 (`I` prefix on implemented
interfaces), D-08 (exported types live in `types.ts`), D-11 (no `import type`), D-18 (old names kept as
aliases when the rename lands in 05.1-06).

Spec-less probe: `phase_req_ids` is null for this inserted phase — the probe visibly skips; acceptance is
grounded in `05.1-CONTEXT.md` D-01..D-19.

with its purpose, and the user confirms it at the per-plan briefing **before** this plan executes.
