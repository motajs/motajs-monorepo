`OperationMeta`、`AppliedOperation<T>`、`IEditorOperation<T>`、`IUndoManager`、`OperationHistoryEntry`、

Purpose（说人话）：撤销功能要重做，重做的第一步是先把「以后底层到底认什么」讲清楚——底层只认两件事，
一个操作长什么样（能自己撤销自己），一个管理器长什么样（只记先后、不存快照）。接口先定下来、
经用户确认，后面的实现才有依据，不会写完再推翻。

This plan is interface-only (D-16): it creates new declaration files and nothing else. It is the phase's
tracer for the bottom layer — the "end-to-end slice" is *the interface plus its compile proof*, i.e. the
new contract typechecking against the whole package without disturbing the existing public surface.

Decisions implemented here — D-01 (bottom layer = interfaces + management), D-04 (manager only, each
operation carries its own inverse), D-05 (no snapshots: no `capture`/`restore`/`targets` in the new
contract), D-07 (`I` prefix on implemented interfaces), D-08 (exported types live in `types.ts`),
D-11 (no `import type`), D-18 (old names kept as aliases).

map, so the probe visibly skips. Acceptance is grounded in `05.1-CONTEXT.md` D-01..D-19 and the
Validation Architecture mapping instead.
