<objective>
按 D-07 给「会被 `implements` 的接口」加 `I` 前缀并保留旧名为别名（分散在两个包）：
底层 `IFsPort`/`IHostPort`/`IEngineAdapter`/`IPreviewAdapter`；默认实现层
`IResourceView`/`ILoadableResource`/`IRecoverableResource`。

Purpose（说人话）：统一命名规范——凡是「有类去实现它」的接口，名字都以 `I` 开头，一眼能看出它是接口。
同时把旧名字留成别名，这样上层编辑器不用改一行也能继续编译。

Decisions implemented here — D-07 (`I` prefix on implemented interfaces), D-08 (types live with their
layer's type file), D-11 (no `import type`), D-18 (old names kept as aliases so `@motajs/editor` is untouched).

Output: renamed port interfaces in `editor-core/lib/ports/**` and resource-view interfaces in
`editor-impl/lib/resources/**`, with each package's root barrel exporting new names plus old-name aliases.
