<objective>
把 core 撤销改造带来的**不可避免**的编辑器侧机械跟随做掉：删掉视口快照注册、删掉操作里的 `targets`
与 `operationPathTarget` 用法、清掉转发 barrel 里已消失的名字，并把那条钉住旧行为的测试改成记录 D-19
的新行为。

Purpose（说人话）：core 不再存快照了，编辑器里那两个「把视口存起来 / 贴回去」的调用就没地方放了；
操作里那个「记一下我要改哪」的字段也没人看了。这个计划只做这些删删改改——**不加功能、不改界面**——
顺带把「撤销数据改动会顺带恢复地图视口」这条旧测试改成记录「以后不会了」（这是用户明确确认的行为变化）。

**已定的范围（D-18 更新后，用户选 A）：** core 彻底删掉旧快照机制，`@motajs/editor` 只做**最少量机械
跟随**——删掉对已删除符号（`registerUndoSystem` / `OperationTarget` / `operationPathTarget`）的调用、
删掉不再需要的 `targets` 字段、按 D-19 改写一条测试——并**集中在本计划**。除此之外编辑器不改。

**执行顺序（硬约束）：** 本计划与 05.1-04（撤销重构）**同处 wave 3**，但必须排在 05.1-04 **之后**
执行：05.1-04 先删掉 core 的旧快照符号与 `registerUndoSystem`，本计划随即删除编辑器对这些符号的调用、
`targets` 字段并改写那条测试。两计划在同一波完成，**波末全仓保持可编译/测试绿**；本计划自身的验证
限定在编辑器范围内（`--filter @motajs/editor`），不要求中途的全仓绿。（frontmatter 里不写
