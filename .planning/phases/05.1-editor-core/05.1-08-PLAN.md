<objective>
把 core 撤销改造带来的**不可避免**的编辑器侧机械跟随做掉：删掉视口快照注册、删掉操作里的 `targets`
与 `operationPathTarget` 用法、清掉转发 barrel 里已消失的名字，并把那条钉住旧行为的测试改成记录 D-19
的新行为。

Purpose（说人话）：core 不再存快照了，编辑器里那两个「把视口存起来 / 贴回去」的调用就没地方放了；
操作里那个「记一下我要改哪」的字段也没人看了。这个计划只做这些删删改改——**不加功能、不改界面**——
顺带把「撤销数据改动会顺带恢复地图视口」这条旧测试改成记录「以后不会了」（这是用户明确确认的行为变化）。

**⚠️ 范围提示：** 编排器给本阶段的总 scope 写的是「`@motajs/editor` 必须不编辑」，但同一段约束又明确
要求删除 `undoSystem.ts`、`OperationTarget`、`operationPathTarget` 与 D-19 的行为变化；这几项一起生效时
编辑器侧必然无法编译。研究（读了实际代码）结论一致：编辑器机械跟随不可避免。本计划即为此设，且是
**唯一**触碰到编辑器的计划。用户可在本计划简报上二选一：(A) 批准本计划（推荐，改动面最小且集中）；
(B) 要求编辑器一行不改，则 Plan 04 改为保留三个显式弃用兼容导出，本计划只保留 Task 3。

(aliases keep every other editor file compiling), D-19 (the confirmed viewport behaviour change is recorded).

grounded in `05.1-CONTEXT.md` D-01..D-19.

Output: a minimal, mechanical editor adaptation plus the re-recorded D-19 test.
