## Areas Discussed

用户先自行阐述大致目标，随后 agent 逐条提问，共两组。

### 1. 外壳形态（问 1–4、6–8）
- 面板类型展示：**名称 + 图标**（分类后续再加）。
- 工厂入参：`context + 实例 id`（实例 id 由 core 生成，唯一）。
- 关闭标签：**销毁实例（dispose）并移除**，随后**自动切到相邻标签**；若无其它标签则回到空白新标签页。
- 顶部菜单注册粒度：**菜单项（标题 + 点击回调）**。
- 空白新标签页：**可有多个**。
- 打开参数：**本阶段只到实例 id 为止**。
- 顶部布局：**菜单行 + 标签行（两行）**。

### 2. 通用 fs 接口（问 5、9）
- 方法范围：**读 / 写 / 列目录 / 建目录 / 移动 / 删除**。
- 落点：**仅是 editor-core 导出的一个接口类型**，无默认/占位实现；core/impl 不实现不引用。

## User's Opening Explanation (verbatim intent)

- 外壳 = core 在「无任何面板/功能」和「加了面板但忽略面板本身」时都应长什么样。
- 像浏览器一样列举面板：**动态注册/删除面板**，同类型可开多个（两个表格面板编辑不同内容、互不冲突）。
- 现接口「面板注册是一次性的」，**考虑改为注册面板构造器（工厂）而非对象**。
- 页面管理像浏览器：一排标签（各带 ×），最右 + 打开新标签页；加载完毕默认开一个空白新标签页；空白页列出已注册面板，点击即替换该页。
- 最上一排加基础功能（文件/编辑…），**允许外部注册**。
- 编辑器**外部装配**，加载完成后基本系统应已注册。
- fs 接口只为**统一外部实现**，core/impl 不实现不引用，存在与否不影响项目。
