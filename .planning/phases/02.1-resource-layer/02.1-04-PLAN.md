## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 注入的文件系统 → 索引 | 目录枚举结果不可信（可能含平台分隔符 / 大小写差异）；索引按 `/` 精确比对 |
| 磁盘内容 → 缓存 → 面板 | 缓存按路径键；字节 / 文本分离 |
| 忽略模式 → 索引 | 外部注入的模式列表可能过宽 / 过窄 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02.1-09 | Tampering | 索引 / 缓存路径键碰撞（分隔符 / 大小写） | medium | mitigate | 键为 `/` 规范化相对路径字符串精确比对；契约由 `IEditorFileSystem` 注释保证（Pitfall 3）。 |
| T-02.1-10 | Tampering | 索引一致性（增删移未同步父目录） | medium | mitigate | 变更收敛到 `insert` / `remove` / `move` 三个入口，同事务式维护父目录与子节点（Pitfall 4）；fileIndex 测试覆盖。 |
| T-02.1-11 | Denial of Service | 递归扫进被忽略目录（如 `node_modules`）导致耗时异常 | medium | mitigate | 忽略模式在递归前按名匹配跳过（D-05）；fileIndex 测试覆盖。 |
| T-02.1-12 | Tampering | 超大内容撑爆内存 | medium | mitigate | 缓存池字节上限 + LRU 淘汰（D-09）；contentCache 测试覆盖。 |
| T-02.1-SC | Tampering | 依赖安装 | high | accept | 本计划零依赖安装。 |
</threat_model>
