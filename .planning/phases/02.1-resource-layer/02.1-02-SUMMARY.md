## Decisions Made

- `ITablePanelTarget` 取**单一 `dataPath`**（而非保留 `data` + `schema` 两成员）：贴合 D-14「目标只给数据文件路径」，且 schema 视图也复用同一字段（其值本身是 schema 文件路径）。
- `ITablePreset` **只声明一次**，落在 `react/types.ts`（接缝层）；`table/types.ts` 引入后 `export type` 再导出——保证只有一个声明模块，同时维持 `table → react` 单向依赖（`react` 不得反向 import `table`）。
- 预设表清单走**能力接缝**（`ITableEditorCapabilities.tablePresets?`）而非列表面板打开参数：一次注入、静态清单更自然（D-11）。
- `table/types.ts` 中原本只为旧 `{ data, schema }` 服务的 `IResourceIdentifier` 引入随之删除。
