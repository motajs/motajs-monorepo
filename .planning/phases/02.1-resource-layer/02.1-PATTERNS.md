### `packages/libs/editor-core/src/resource/types.ts`（改：接口契约）

### `packages/libs/editor-core/src/resource/resourceSystem.ts`（改：core 系统）

**Analog:** 自身

**核心缓存与钩子派发**（`resourceSystem.ts:59-140`，本阶段把 key 从 `(type,id)` 换成 `path`，并接 fs）：
```ts
async readContent<T>(id: IResourceIdentifier): Promise<T | undefined> {
  if (!this.injection) {
    logger.error('system.notInitialized', 'Resource');
    return undefined;
  }

  const byId = this.contentCache.get(id.type);

  if (byId) {
    if (byId.has(id.id)) return byId.get(id.id) as T;
  }

  const content = await this.injection.requestResource<T>(id);
  const target = this.contentCache.getOrInsertComputed(id.type, () => new Map());

  target.set(id.id, content);
  return content;
}
```

**钩子批量派发 + 错误隔离**（`resourceSystem.ts:116-140`，保留形状）：
```ts
async updateResource(id: IResourceIdentifier): Promise<void> {

  await Promise.all(
    this.forEachHook((hook) =>
      Promise.resolve()
        .then(() => hook.onUpdateResource?.(id))
        .catch((error: unknown) => {
          logger.error('resource.hookFailed', String(error));
        }),
    ),
  );
}
```

**类骨架**（`resourceSystem.ts:12-28`，照抄）：

### `packages/libs/editor-core/src/resource/resource.ts`（改：资源句柄）

**Analog:** 自身（`resource.ts:1-21`，全文）

```ts
import { IResource, IResourceIdentifier, IResourceStore } from './types';

export class Resource<T> implements IResource<T> {
  readonly identifier: IResourceIdentifier;

  /** 资源内容读写的窄接缝，由资源系统提供 */
  private readonly store: IResourceStore;

  constructor(identifier: IResourceIdentifier, store: IResourceStore) {
    this.identifier = identifier;
    this.store = store;
  }

  request(): Promise<T | undefined> {
    return this.store.readContent<T>(this.identifier);
  }

  write(data: T): Promise<void> {
    return this.store.writeContent(this.identifier, data);
  }
}
```

**要点（D-08）**：`request()` / `write()` 的泛型 T 收敛为 `string | Uint8Array`；`readContent` / `writeContent` 签名同步跟进。类照旧**先有 `interface`（`IResource<T>`）再 `implements`**、窄接缝（构造器收 `IResourceStore`）。

## Shared Patterns

### 接口先于实现（interface → implements）
**Source:** `packages/libs/editor-core/src/fs/types.ts:1`、`resource/types.ts:12-26`、`resource/resource.ts:3`、`hook/hook.ts:3-6`
**Apply to:** 所有新建的 core 类（索引、缓存、FileSystem 实现）
```ts
// 先定义 interface（放同层 types.ts），再让 class implements
export abstract class Hookable<H extends IHookBase = IHookBase, C extends IHookController<H> = IHookController<H>>
  implements IHookable<H, C> {
```
**规则**：`AGENTS.md` §Code style —— 所有类必须先有 `interface` 再由类 `implements`；需要向外暴露的接口类型放到该层的 `types.ts`。

### jsDoc 与注释规范
**Source:** `fs/types.ts:2-7`、`resourceSystem.ts:13-14`、`tablePanel.ts:176-183`
**Apply to:** 全部新文件（含注释）
```ts
/**
 * 判断一个值是否为可读写的普通对象
 * @param value 待判断的值
 * @returns 是普通对象时为 true
 */
function isRecord(value: unknown): value is Record<string, unknown> { /* ... */ }
```
**规则**：方法/成员**必有 jsDoc**；`type` 别名写 jsDoc、类/接口不写；**文件级说明写在 import 之后**（参照 `shellSystem.ts:11-12`、`capabilities.ts:11-12`），**顶部不写文件头注释**；单行 `//` 仅限「文件级说明 / 函数内解释下一行 / `// TODO:` / `//#region`」三类。

### 钩子（Hookable）批量派发 + 错误隔离
**Source:** `resourceSystem.ts:116-140`、`shell/shellSystem.ts:818-843`、`hook/hook.ts:54-60`
**Apply to:** resource 系统对外通知（onUpdateResource 等）
```ts
await Promise.all(
  this.forEachHook((hook) =>
    Promise.resolve()
      .then(() => hook.onUpdateResource?.(id))
      .catch((error: unknown) => {
        logger.error('resource.hookFailed', String(error));
      }),
  ),
);
```

### 注入式能力接缝 + 缺省优雅降级
**Source:** `react/capabilities.ts:11-79`、`react/capabilitiesContext.ts:1-15`、`CapabilityProvider.tsx:56-63`
**Apply to:** 表格的打开列表 / 新建 / 删除（若走能力接缝），以及任何需触达外部编辑器的入口
```ts
const capabilities: ITableEditorCapabilities = {
  codeEditor: provided?.codeEditor,
  multiSelect: provided?.multiSelect ?? openMultiSelect,
  tablePanel: provided?.tablePanel,
  copy: provided?.copy,
};
```
**规则**：外部能力一律经**注入接缝**（`IXxxOpener`），core / impl **不导入宿主或引擎代码**；缺省时优雅降级、不抛。

### 面板切入刷新 + 在途结果丢弃
**Source:** `tablePanel.ts:438-442`（`onSwitchIn`）、`tablePanel.ts:704-723`（`nextToken` / `createColumn`）、`shellSystem.ts:770-815`（`syncActiveInstance` / `invokeSwitchIn`）
**Apply to:** 表格打开列表、目录树数据的刷新
```ts

  const count = this.columns.length;

  for (let index = 0; index < count; index += 1) await this.refresh(index);
```

### 通知 / 日志约定
**Source:** `resourceSystem.ts:32,47,61`（`logger.error('system.notInitialized', 'Resource')`）
**Apply to:** 所有 core 新文件（未初始化 / 失败分支）
**规则**：core 用 `logger`（`../log`）；`editor-impl` 面板把失败隔离成**面板级错误提示**（`publishError`，`tablePanel.ts:766-774`）；**不新增无谓 `try/catch`**，仅保留行为关键路径（持久化失败隔离、诊断订阅隔离等）。

### 两极性门禁脚本骨架
**Source:** `coreFsSurface.js:124-195,221-254`、`coreImportType.js:139-213`、`coreEngineNeutral.js:229-306`、`coreModuleState.js:302-377`
**Apply to:** `coreFsSurface.js` / `coreBoundaries.js` 的改造
```js
function check(condition, message) {
  if (!condition) failures.push(message);
```

**规则**：**必须仍「可失败」**——保留「真实树断言 + 合成 fixture 必须被拦 + 非空转下界 + fixture 已删断言」四要素；断言恒真的门禁与没有门禁不可区分。
