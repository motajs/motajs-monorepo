## 资源标识形状

| Option | Description | Selected |
|--------|-------------|----------|
| A: 只剩路径 | 标识仅一个文件路径；列资源 = 列目录 | ✓（最终） |
| B: 路径 + 类型号 | 路径当主键，类型号保留用于「按类列资源」 | ✓（先选，后撤回） |

**User's choice:** 先选 B「路径 + 类型号」，随后判断「没有类型号似乎更好，不要类型号了，否则复杂度会提高」→ 最终采用 **A：纯路径**。
**Notes:** 随后进一步提出「资源系统应该拓展，先对项目本身进行索引，用 readdir 索引，列出资源列表应该不再需要，类似于一个简易的文件资源管理器」——列表接口被「项目索引」取代。
