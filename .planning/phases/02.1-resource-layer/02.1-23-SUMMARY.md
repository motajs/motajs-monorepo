## Accomplishments

- **工具栏两个低频动作收进「更多」下拉**：`TableToolbar` 用 antd `Dropdown`（`trigger={['click']}`）替换两个常驻按钮；触发按钮 `data-test-id="table-more"`、文案「更多」（`.etable-toolbar-more`，`size="small"`）。菜单项「编辑 Schema」仅在 `props.showSchemaButton` 为真时出现、按 `!props.schemaButtonEnabled` 禁用；「在代码编辑器中打开」按 `!props.codeButtonEnabled` 禁用；两项的 `data-test-id`（`table-edit-schema` / `table-open-code`）落在 label 节点上，菜单级 `onClick` 按 key 分发到 `props.onOpenSchema` / `props.onOpenInCodeEditor`。`ITableToolbarProps` 既有成员未变，✕ 关闭按钮与「保存」按钮保持在外。

## Decisions Made

- **key 分发 + label 上的 data-test-id**：菜单项 `data-test-id` 放在 label（`span`）上以便 `getByTestId`；动作经菜单级 `onClick` 按 key 分发，禁用交给菜单项自身 `disabled`（渲染为 `aria-disabled`），不把动作放到 label 的 onClick（否则禁用态下仍会触发）。
- **「不显示」断言必须先展开下拉**：下拉关闭时菜单项本不在 DOM，直接 `queryByTestId(...).toBeNull()` 会永真；故先 `openToolbarMenu()`，并以常驻的 `table-open-code` 存在性确认菜单确已展开，再断言 `table-edit-schema` 不存在——保持断言可失败。
- **位置语义逐字保留**：`layout`/`closeColumn` 只把参照节点由「已收进下拉的菜单项」换成「常驻的下拉触发按钮」，位置关系（表名 → 分隔线 → 动作按钮；✕ 在动作按钮右侧）不变。
