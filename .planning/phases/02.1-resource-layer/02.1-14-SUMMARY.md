# Phase 02.1 Plan 14: 两个可复用表格组件（浏览器 / 新建表单）Summary

**把 Plan 13 声明的两个可复用组件落成实现——一个「表格浏览器」（注入预设表即打开态、不注入即删除态，两态唯一差异就是有没有预设表）与一个「新建表格表单」（点按钮内联输入名称、回车确认）；两组件纯由 props 驱动、不碰文件系统，登记进桶文件供 Plan 15 组装进表格面板空栏。**

- **Completed:** 2026-10-16
- **Tasks:** 2
- **Files modified:** 3（新建 2 / 改 1）

## Accomplishments

- `TablePicker`（`TablePicker.tsx`）：实现 Plan 13 的 `ITablePickerProps`。上半区为**可选**预设表——`presets` 缺省或为空数组时不渲染，有预设时渲染标题「预设表」与逐项按钮（点击回调 `onSelect(preset.path)`）；下半区为项目目录树——根目录显示 `/`、非根目录先渲染 `..` 行（回调 `onNavigate(父目录)`），目录行进入 / 文件行打开；文件行**仅**当 `isTableDataPath(entry.path)` 为真时渲染（排除 schema 与非 json/jsonc）；`deletable` 为真且 `onRequestDelete` 存在时每数据文件行额外渲染「删除」入口（回调 `onRequestDelete`）。`error` 非空时渲染错误提示。组件无自身状态，纯由 props 驱动。
- `TableCreateForm`（`TableCreateForm.tsx`）：实现 Plan 13 的 `ITableCreateFormProps`。渲染「新建表格」antd `Button`，点击后内联渲染 antd `Input`（`autoFocus`，回车确认 / Escape、失焦取消）；确认时名称 `trim()` 非空才回调 `onCreate(directory, name.trim())`；`error` 非空时显示提示。不使用浏览器原生对话框。
- 两组件复用 Plan 09 既有的 `.etable-list*` 类名与 `table-list-*` 的 `data-test-id` 前缀（预设项 `table-list-preset-<name>`、文件 / 目录行 `table-list-entry-<path>`、删除 `table-list-delete-<path>`、`..` 行 `table-list-up`、空目录 `table-list-empty`、错误 `table-list-error`、新建按钮 / 输入 `table-list-create` / `table-list-create-input`），把 Plan 17 的样式与断言迁移面压到最小。
- `components/index.ts` 追加 `export * from './TablePicker';` 与 `export * from './TableCreateForm';`；既有全部导出（含 `TableListPanelView`）保留。

## Decisions Made

- **TablePicker 无自身状态**：打开态与删除态共用同一组件，差异仅体现为是否传入 `presets`（对应用户「这些组件应该是可以复用的，差距只是有没有预设表」）；因此组件内不持有任何选择 / 目录状态，全部经 props 进出。
- **删除入口双开关**：每行的「删除」入口需 `deletable` 为真**且** `onRequestDelete` 已传入才渲染，避免删除态缺回调时误渲染无效按钮。
- **文件行过滤沿用 `isTableDataPath`**：schema 约定文件与非 json/jsonc 不会出现在目录树里，schema 文件不会被当数据表打开（T-02.1-14-01）。
- **名称收敛在组件边界**：`TableCreateForm` 只把 `name.trim()` 回调给面板，不自行拼路径、不做合法性判定——`validateId` 与路径拼接留给 Plan 15 的面板侧（T-02.1-14-02）。
- **沿用 Plan 09 的类名与断言前缀**：`.etable-list*` 与 `table-list-*`，减少 Plan 15/17 的样式与测试迁移面。
