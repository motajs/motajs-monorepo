## Decisions Made

- **负向断言用字符串字面量**：`table-list` 面板类型 id 与「打开表格」菜单标题在删符号后已无来源，正 / 负向断言分别用 `tablePanelType.id` / `DEMO_PANEL_TYPE.id` 与 `'table-list'` / `'打开表格'` 字面量表达（符合「字符串本身」例外）。
- **新建前先导航进 tables**：空栏 Create 态用的 `directory` 来自该栏目录态，故 e2e 先经目录树点 `table-list-entry-tables` 进 `tables`、再点「返回」回三按钮（目录状态保留在 `tables`），才能在该目录写出一对文件。
- **删除前先 ✕ 关栏让目录归根**：`TablePanel.closeColumn` 复位 `directory=''`，故删除前先 ✕ 关栏，再进 Delete 态从根导航进 `tables`，与「打开态 / 删除态唯一差异是是否注入预设」的不变量一致（删除态断言预设区不出现）。
- **「开进本栏」以「标签数不变」落地**：dev 宿主测试不捕获 `TablePanel` 实例，故以开面板标签后记的 `tabsBefore` 与操作后 `listTabs().length` 相等断言「不新开标签」，并辅以「本栏不再出现空栏三按钮 / 出现 `data-table`」。
