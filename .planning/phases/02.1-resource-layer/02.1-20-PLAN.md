<objective>
把表格面板从「每次编辑立即写盘」改成**手动保存**：行内改值 / 新增 / 删除 / 代码编辑器写回 / 撤销重做都先只改内存并在该栏标「未保存」；点「保存」才落盘；并在**切出面板 / 关闭面板 / 关栏 / 换目标表**时自动保存已修改的栏（避免逐次编辑调文件系统、对硬盘不友好）。
