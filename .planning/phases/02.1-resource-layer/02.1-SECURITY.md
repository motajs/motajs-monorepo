## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| 不可信路径（`../`）→ 注入的文件系统 | core 只拼接路径、不校验；越界拦截由注入的 `IEditorFileSystem` / 宿主负责（D-02） | 文件路径字符串 |
| 二进制字节 ↔ 文本 | 以 `ResourceContent`（`string | Uint8Array`）区分；core 不把字节当文本解析（D-08） | 文件原文 / 原始字节 |
| 磁盘文本 → 表格解析（`.jsonc`/`.json`） | 磁盘内容不可信；解析只产出数据对象，失败落错误态 | 项目文件文本 |
| 字段名 / 值 | 行内编辑经 `validateId` / `validateValue`；写入拒绝 `__proto__` / `constructor` / `prototype` | 用户输入 |
| 面板 / 宿主 DOM | 表格 UI 全部走 React + antd，无 `dangerouslySetInnerHTML` | 渲染节点 |
| 开发宿主（dev-only） | `packages/apps/editor-dev`，`private: true`，不进产品产物 | 演示数据 |
