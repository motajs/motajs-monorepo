<objective>
把 `@motajs/editor-impl/table` 从「类型号 + 标识串（`table.<name>` / `table#schema.<name>`）」迁到「**纯文件路径 + 文件名约定**」：新增路径约定纯函数与按项目约定的文本解析 / 序列化（`.jsonc` 系统前缀约定 + 注释剥离回退），面板目标收敛为单一数据路径，读写改为经资源层拿原文再自行解析；并给面板补上「打开前检测非合规文件、弹面板内确认框」的行为。（既有 21 个表格测试的装配迁移已拆到 **Plan 07 / Plan 08**，本计划专做实质实现迁移。）

Purpose: D-14 / D-15 / D-08 的落点；也是「打开 / 新建 / 删除表格」（Plan 09）与开发宿主接入（Plan 10）的前置。

Output: 路径约定与文本编解码模块、路径化并带系统前缀往返 / 注释剥离确认的 `TablePanel` / `tablePanelType`。

**`.jsonc` 项目级约定（用户已定，本计划落地）：**
1. `.jsonc`（以及 `.schema.jsonc`、`.json`）可带一段**系统前缀注释块**，由精确这一行终止：`// --- SYSTEM PREFIX END --- //`。该行及其之前的全部文本 = 系统前缀；其后的文本 = 严格 JSON 正文。
2. **完全没有注释即合规**——标记行**不是必需**的。
3. 打开时检测：先整段严格 `JSON.parse`（成功 ⇒ 合规、无前缀）；否则在标记行处拆分、正文严格解析（成功 ⇒ 合规并**记住前缀**）；否则用 `json5` 宽松解析（成功 ⇒ **非合规**，弹面板内确认框；确认 ⇒ 以宽松结果 + 空前缀打开，取消 ⇒ 不打开）；三者皆失败 ⇒ 无效、落既有错误态（承接 D-29）。
4. 确认框**不是注入能力**——直接在表格面板的 React 视图里用既有 antd `Modal` 渲染；**不新增** `IConfirmOpener` / `IConfirmRequest` 等接缝，**不动** `src/react/types.ts` / `src/react/capabilities.ts`。

**依赖决策（命名须用户确认，见 `INTERFACE-NAME.md` `## Plan 06`）：** `json5` 为**必需依赖**——只用于「非合规文件、打开前剥离注释」的回退路径的宽松解析；把 `json5` 加入 workspace catalog 并作为 `editor-impl` 依赖。它**已在本仓 lockfile 内**（`file2x` 直接依赖），非新引入到仓库。系统前缀往返路径本身不依赖 json5。
