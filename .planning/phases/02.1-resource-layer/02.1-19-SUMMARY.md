## Accomplishments

- `ITablePanel` 新增可选方法 `save?(columnIndex?: number): Promise<void>`——「保存」成为表格面板对外显式动作，供工具栏按钮与切出 / 关栏自动保存路径统一调用。
- `ITablePanelViewState` 新增 `unsaved?: boolean`；`ITablePanelViewProps` / `ITableColumnProps` 各新增 `onSave?: (columnIndex: number) => void`——视图可据「未保存」位显示标记并启用保存。
- `ITableGridProps` / `ITableToolbarProps` 各新增 `unsaved?: boolean` / `onSave?: () => void`——表格透传给工具栏，工具栏据此渲染保存按钮与未保存标记。
- `ITableCreateFormProps` 新增 `entries?: readonly IFileEntry[]` / `onNavigate?(path: string): void`（`IFileEntry` 自 `@motajs/editor-core` 导入）——新建表单可在当前目录的子目录间浏览并选定新建位置。
