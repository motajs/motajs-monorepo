# Phase 02.1 Plan 09: 表格「打开列表 / 新建 / 删除」Summary

**把表格能力补上三个用户入口：一个读 core 索引铺目录树的「打开表格」列表面板（上半注入预设表、下半只列 json/jsonc 并排除 schema 文件），新建在当前目录一次写出 `name.json` + `name.schema.json` 一对文件，删除经 antd 二次确认后删掉这一对且不可撤销。**

## Decisions Made

- **列表做成独立面板类型、预设经能力接缝注入**：`tableListPanelType`（`id='table-list'`）沿用 Phase 1 外壳注册；预设表清单走 `ITableEditorCapabilities.tablePresets`（D-11），非经打开参数。
- **目录树 = 单层可导航浏览器**：面板只持有「当前目录 + 其直接子条目」，目录行点击进入 / 选中，另设「..」父目录行以便返回；文件行按 `isTableDataPath` 过滤——贴合计划对 `TableListPanel.selectDirectory` 「设置当前选中目录 + 触发重取」的描述，也匹配 `listDirectory(path)` 返回直接子条目的语义。
- **删除确认落在视图内的受控 antd `Modal`**：与 Plan 06 的注释剥离确认同法（`renderCommentStripModal`），两个 `data-test-id` 按钮（`table-list-delete-confirm` / `table-list-delete-cancel`）；既不使用 `window.confirm`，也不使用命令式 `Modal.confirm`——后者在 jsdom 里难以稳定断言且与既有面板内确认写法不一致。
- **新建名称校验在面板侧**：`TableListPanel.createTable` 先 `listDirectory` 该目录、以 `tableBaseName` 把条目折成表格基名后经 `validateId` 查重，非法时不落任何文件并把错误发布进视图状态；视图内联 antd `Input`（Enter 确认 / Escape、失焦取消）只负责收集名称。
- **视图状态类型落在视图文件**：`ITableListPanelViewState` 与 `ITableListPanelViewProps` 同处 `TableListPanelView.tsx`，面板从视图文件引入状态类型——`tableListPanel` 引入 `TableListPanelView`（值）而视图仅引入资源类型，二者不互相 import，避免 panel ↔ view 循环引用（契合「无循环引用」）。
