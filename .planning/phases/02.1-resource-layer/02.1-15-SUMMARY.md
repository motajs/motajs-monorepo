# Phase 02.1 Plan 15: 表格面板空栏内联承载 + 移除独立列表面板 Summary

**把「打开表格 / 新建表格 / 删除表格」做实到表格面板的每一个空栏里——未设目标的那一栏直接显示三个按钮，点开后在同一栏内内联展示可复用的浏览器 / 新建表单 / 删除确认（不再弹出盖住外壳的独立面板），并删掉 Plan 09 的独立列表面板形态、让表格面板标签名支持多表。**

## Decisions Made

- **删除态 `onSelect` 传空操作**：`IgnoreSelect` 是模块级裸函数（无参，赋给 `(dataPath: string) => void` 合法），保持 `ITablePickerProps.onSelect` required、不因调用态降为可选（承接 Plan 13 结论）。
- **`publish` 条件发布空栏字段**：`@tanstack/store` 的 `setState` 是**整体替换**（已核实 store.js），因此在 `target === null` 时用对象展开同时带上 `emptyMode` / `pickerDirectory` / `pickerEntries` / `pickerError`；有目标栏省略即清空这四项。
- **`closeColumn` vs `deleteFromColumn` 的复位差异**：关栏复位 `emptyMode` 为 `Buttons`；删除后保持 `Delete`（连续删除）。两者区别在实现里显式分开。
- **迁移测试以保 typecheck 归零**：`tsc -b` 的 `include: ["${configDir}/src"]` 覆盖测试树，删除产品导出后 `tableList.test.tsx` / `openNewDelete.uat.test.tsx` 必然 TS2724；为满足计划 `<verify>`（无残留引用）与成功判据（typecheck 0），移除这两处残留（详见 Deviations）。
- **常量与辅助迁址**：`INITIAL_TABLE_DATA_TEXT` / `INITIAL_TABLE_SCHEMA_TEXT` / `joinPath` / `tableBaseName` 从 `tableListPanel.ts` 迁到 `tablePanel.ts`，名字与 `export` 均不变。
