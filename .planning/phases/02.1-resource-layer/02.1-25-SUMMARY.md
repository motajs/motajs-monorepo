## Decisions Made
- **类型面零新增**：props 复用既有 `ITableCapabilitiesProviderProps`，打开器实现既有 `ICodeEditorOpener`；只新增对外符号 `DevCodeEditorProvider`（命名已在 INTERFACE-NAME 登记并本轮改为已确认）。
- **组件用 JSX 而非 `createElement`**：`data-test-id` 需落在 antd `Modal` 根上，而 `createElement(Modal, { 'data-test-id': ... })` 会因 `ModalProps` 无 `data-*` 索引签名而报 TS2769（已用一次性探针验证）；JSX 对连字符属性放行，故全文用 JSX。计划 action 已明示「JSX 可用」，非偏差。
- **文本编辑不做解析 / 校验 / 拼路径**：写回合法性完全由 `TablePanel.openCurrentViewInCodeEditor` 内的 `parseTableText`（仅 `Conforming` 且 `isRecord`）把关，本组件只做文本态。
