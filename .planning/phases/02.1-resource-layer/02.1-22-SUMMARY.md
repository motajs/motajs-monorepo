# Phase 02.1 Plan 22: 空栏按钮与新建选目录 Summary

**空栏三个按钮改为更大且竖排，并让「新建表格」能在目录树里选定目标目录后再创建——一次性收口 UAT 缺口 G-02.1-3 的 ②③ 两项。**

## Performance

- **Duration:** ~20 min
- **Started:** 2026-10-16T21:15:00Z (approx)
- **Completed:** 2026-10-16T21:36:00Z
- **Tasks:** 3
- **Files modified:** 7

## Accomplishments

- **新建表单可浏览选位置**：`TableCreateForm` 在名称输入之上渲染「新建位置」区——当前目录路径 + 非根目录时的一行「..」上行 + 各子目录行；子目录行由 `props.entries` 过滤 `EditorEntryKind.Directory` 得到，点击经 `props.onNavigate(entry.path)` 切换、「..」经 `props.onNavigate(parentDirectory(props.directory))` 上行。`entries` / `onNavigate` 缺省时不渲染目录区（向后兼容）。
- **空栏透传选目录**：`TableEmptyColumn` 的 `Create` 态把 `entries` / `onNavigate` 透传给 `TableCreateForm`。
- **面板进入新建态即取目录**：`TablePanel.setEmptyMode` 把进入 `Create` 态也纳入 `TablePanel.refreshPicker`（原来只对 `Open` / `Delete`），使新建表单能列出当前目录子条目。
- **空栏三按钮更大且竖排**：`renderButtons`（模块级自由函数）三个按钮由 `size="small"` 改为 `size="middle"`；`table.css` 的 `.etable-empty-actions` 改为竖列（`flex-direction: column`、`align-items: stretch`、`width: 100%`、`max-width: 200px`、`margin: 0 auto`）且按钮 `width: 100%`。
- **可失败断言**：`layout.uat.test.tsx` 新增 CSS 规则原文断言（`.etable-empty-actions` 含 `flex-direction: column` 与 `width: 100%`）与渲染后 DOM 断言（空栏第 1 栏三个 `.ant-btn` 均不带 `ant-btn-sm`）。
- **测试迁移到选目录**：`tableEmptyColumn.test.tsx` 新建用例先进入子目录 `sub` 再新建，断言一对文件写在 `sub`（而非根目录）；`openNewDelete.uat.test.tsx` 新建 / 删除用例进入 `tables` 目录后再建 / 删，断言读写均在选定目录。目录名读取辅助由 `rootNames` 泛化为 `directoryNames(path)`。

## Decisions Made

- **目录区向后兼容**：`renderCurrentDirectory` 在 `entries` 或 `onNavigate` 缺省时返回 `null`，既有仅传 `directory` 的调用点行为不变（typecheck 与既有用例零改动即过）。
- **自由函数命名**：`renderDirectoryRow` / `renderCurrentDirectory` 按 INTERFACE-NAME `## Plan 22` 登记落地，为模块级自由函数（裸名引用）；`renderButtons` 沿用裸名，未写 `TableEmptyColumn.renderButtons`。
- **断言双轨**：`size` 与 CSS 都不能由 typecheck 观测，故落成「CSS 规则原文正则 + 渲染后类名」两条可失败断言；用「不带 `ant-btn-sm`」代理「已由 `small` 改回 `middle`」。
