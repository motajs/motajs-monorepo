## Sampling Rate

- **After every task commit:** `pnpm --filter <touched-pkg> test` + `pnpm --filter <touched-pkg> exec tsc -b` (migration period is high-churn; catch contract breaks early)
- **After every plan wave:** `pnpm -r run test` + `pnpm -r run typecheck` + the five gates (`coreFsSurface` / `coreBoundaries` / `coreImportType` / `coreModuleState` / `coreEngineNeutral`)
- **Before `/gsd-verify-work`:** Full suite green + all-package typecheck green + all gates green
- **Max feedback latency:** 120 seconds
