# Phase 05.3 Plan 05: 资源系统 Summary

**Status:** Complete
**Executed:** 2026-10-04

## 结果

把 `@motajs/editor-core` 的资源系统落地：面板通过资源句柄 `Resource` 读取 / 写入资源，后台的 `ResourceSystem` 负责缓存资源列表与内容、把「资源更新」经 Hook 广播出去，并把真实读写转交给注入的后端。一句话：**这是编辑器里「读写一份资源」的统一入口——它自己不做任何文件操作，只负责记住列表和内容、并在别人改动时通知所有关心的人。**

## 实际改动

- 新增 `packages/libs/editor-core/src/resource/resource.ts`：`export class Resource<T> implements IResource<T>`。
  - 字段 `readonly identifier: IResourceIdentifier`、`private readonly store: IResourceStore`；构造器 `(identifier, store)`。
  - `request()` → `this.store.readContent<T>(this.identifier)`；`write(data)` → `this.store.writeContent(this.identifier, data)`。
  - 只 import `./types` 与 `./store`，刻意不 import `./resourceSystem`，因此不产生 resource ↔ resourceSystem 环。
- 新增 `packages/libs/editor-core/src/resource/resourceSystem.ts`：`export class ResourceSystem extends Hookable<IResourceSystemHooks> implements IResourceSystem, IResourceAccess, IResourceStore`。
  - 字段 `private injection!: IResourceInjection`；`private readonly listCache: Map<number, readonly IResourceIdentifier[]> = new Map()`；`private readonly contentCache: Map<number, Map<string, unknown>> = new Map()`（双层 Map，无拼接键）。
  - `protected createController(hook)` → `new HookController(this, hook)`。
  - `initialize(injection)`：保存注入。
  - `requestResourceList(type)`：列表缓存命中直接返回；否则请求后端、缓存后返回。
  - `requestResource<T>(id)`：先确保列表已取；列表含该 id 返回 `new Resource<T>(id, this)`，否则 `null`。
  - `readContent<T>(id)`：内容缓存命中返回；否则请求后端、回填缓存后返回。
  - `writeContent<T>(id, data)`：写后端、回填内容缓存、不触发任何钩子。
  - `createResource<T>(id, content)`：调后端创建、回填缓存、`updateResourceList(id.type)`、返回新句柄。
  - `deleteResource(id)`：调后端删除、删内容缓存、`updateResourceList(id.type)`。
  - `updateResource(id)`：删内容缓存，`await Promise.all(this.forEachHook((hook) => hook.onUpdateResource?.(id)))`。
  - `updateResourceList(type)`：删列表缓存，`await Promise.all(this.forEachHook((hook) => hook.onUpdateResourceList?.(type)))`。
  - `dispose()`：清空两个缓存。
  - `requestResource` / `requestResourceList` / `createResource` / `deleteResource` 上方各写一行 `// 仅供面板上下文内部使用`（D-35）。
  - 导入全部相对路径、普通 import（无 `import type`、无 `@/` 别名）；实现类不重复接口 jsDoc；无文件头注释、无构造器注释。
- `packages/libs/editor-core/src/resource/index.ts`：末尾**追加** `export * from './resource';` 与 `export * from './resourceSystem';`（原有 `export * from './types';` 未动；未追加 `./access` / `./store`）。
- 新增 `packages/libs/editor-core/src/resource/__tests__/resourceSystem.test.ts`：
  - 内存后端测试替身 `FakeResourceInjection implements IResourceInjection`，用两层 Map 存内容、`Map<number, IResourceIdentifier[]>` 存列表，并记录各方法的调用次数；`seed(id, value)` 预置内容与列表项。
  - 最小闭环 3 例：列表首次请求一次、二次命中缓存；`requestResource` 命中返回句柄、未命中返回 `null`；句柄 `request()` 读后端并缓存、二次不再访问后端。
  - 写入与更新 6 例：`write` 写后端 + 同步缓存 + 不触发钩子 + 随后取值不走后端；`updateResource` 以 id 广播且重取到最新内容；`updateResourceList` 以 type 广播并作废列表；`createResource` 创建 + 广播 + 返回可用句柄；`deleteResource` 删除 + 广播；`dispose` 清缓存后重新请求后端。
  - 首行 import；每个 test 前单行 `//` 说明覆盖内容；无文件头大段注释；模块级常量 `ID` 用 `Object.freeze` 声明以契合 coreModuleState 模块级可变容器门禁。
