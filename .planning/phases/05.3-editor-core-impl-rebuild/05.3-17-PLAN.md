<objective>
修复评审确认的四方面板系统缺陷：`dispose()` 不复位 `initialized` / `currentParam` 造成释放后半可用（WR-05）；重复 id 注册时已创建的面板被丢弃且不释放（WR-07）；`switchTo` 不校验面板是否已注册（WR-08）；`onFocus` / `onBlur` 的 Promise 拒绝被 `void` 丢弃（WR-06）。

Purpose: 让面板系统在释放 / 重入、重复注册、非法切换与窗口焦点回调失败等边界下行为一致、无泄漏、可排查（D-26 / D-28 / D-30）。

说人话：① 面板系统被「关掉」后没有把内部状态复位，导致再注册时以为自己还开着、但窗口焦点又收不到；正确做法是关掉时把所有状态清干净。② 重复 id 注册时，已经建好的那个面板被直接丢掉、从不释放；正确做法是丢掉前先释放它。③ 切换面板时不检查这个面板是不是系统注册过的；正确做法是没注册就拒绝切换。④ 窗口进 / 出时调面板回调，回调报错会被无声吞掉；正确做法是捕获并记日志。

Output: 状态复位 + 幂等重入的 `panelSystem.ts`、重复注册释放面板的同一文件、`switchTo` 校验与焦点回调兜底的同一文件、新增两条消息的 `messages.ts`、覆盖四场景的 `panelSystem.test.ts` 与命名记录。

⚠️ 只动本计划列出的文件；不改公共接口 `panel/types.ts`；不重做 05.3-13 / 05.3-14 已完成的工作。新日志 id `'panel.callbackFailed'` / `'panel.notRegistered'` 为**提案，需用户确认**后才可写入代码。不改 `hook/` 的接口与实现（WR-01 / WR-02 / IN-01 用户已判定不是问题）。若发现必须改行为或扩大公共接口才能修好，先停下汇报（D-34）。
</objective>
