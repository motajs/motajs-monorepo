# Phase 05.3 Plan 09: 接口修正 Summary

**把资源读写接口收拢进 resource/types.ts 并新增 IResourceSystemAccess，统一三系统 dispose 为 Promise<void>，并落地 ILogger/LogMessages 接口与 log 桶导出**

## Accomplishments
- `IResourceAccess` / `IResourceStore` 从独立文件移入 `resource/types.ts` 并经既有 `export * from './types'` 自动桶导出；`access.ts` / `store.ts` 删除。
- 新增 `IResourceSystemAccess extends IResourceSystem, IResourceAccess, IResourceStore`，`ResourceSystem` 改为只 `implements` 它，删除了 `panelSystem.ts` 中唯一的 `as ResourceSystem` 断言；`PanelSystem` / `EditorCore` 内部字段类型同步改为 `IResourceSystemAccess`，对外 `IEditorCore.resourceSystem` 仍为 `IResourceSystem`。
- `IUndoSystem.dispose` / `IResourceSystem.dispose` 返回类型统一为 `Promise<void>`，`UndoSystem` / `ResourceSystem` 实现改 `async`，`EditorCore.dispose` 与相关测试补 `await`。
- `IPanelSystem.registerPanel` 返回类型放宽为 `Promise<IEditorPanel | null>`；`EditorPanelCreator` 补 jsDoc。
- 新增 `log/types.ts`（`ILogger` + `LogMessages`）与 `log/index.ts` 桶，`src/index.ts` 追加 `export * from './log'`。

## Decisions Made
- 接口类型一律落在各层 `types.ts` 并经桶导出；不导出深路径（`access.ts` / `store.ts` 删除而非保留）。

- `dispose` 统一为 `Promise<void>`（D-39）；`registerPanel` 返回类型放宽，重复 id 记日志/返回 null 的行为留 05.3-10。
- `ILogger` 用字符串 id + 参数式替换（`$1`/`$2` 占位），`LogMessages` 为只读记录；消息表与 Logger 实现留 05.3-10。
