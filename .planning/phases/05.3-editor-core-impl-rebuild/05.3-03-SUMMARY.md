# 05.3-03 Summary — 构建/测试前提对齐

**Status:** Complete
**Executed:** 2026-10-04

## 结果

把 `@motajs/editor-core` 的构建与测试前提对齐：react 依赖改用工作区 `catalog:default`（解析到 19.3.0），补齐渲染测试所需的 devDependencies（`react-dom` / `@types/react-dom` / `@testing-library/react`），并加了一个持久的最小渲染冒烟测试。typecheck 退码 0，测试 1 个用例通过。本计划未改任何 editor-core 源码接口或实现。

关键点：安装后 `react-dom` 起初仍解析到 19.2.3，与 `react` 的 19.3.0 不一致，冒烟测试报 `Incompatible React versions` 而失败。按用户 2026-10-04 决定（保持 react 最新、不降级、不动编辑器 19.2.3 精确锁），把 editor-core 的 `react-dom` 与 `@types/react-dom` 固定为精确 `19.3.0`，两者随即严格同版本，测试通过。

## 实际改动

- `packages/libs/editor-core/package.json`
  - `dependencies`：`react`、`@types/react` 由 `^19.3.0` 改为 `catalog:default`（D-41）；`@tanstack/store` 保持 `catalog:default`。
  - `devDependencies` 新增：`react-dom: 19.3.0`、`@types/react-dom: 19.3.0`、`@testing-library/react: 16.3.2`（D-44）；保留 `@motajs/config`、`jsdom`、`vitest`。
- `pnpm-lock.yaml`：随 `pnpm install` 更新，仅 editor-core importer 及其解析相关条目。editor、service-worker、react-hooks、react-store 等现有包的 react/react-dom 运行时解析仍为 19.2.3，未改动；附带的新增条目为 `react-dom@19.3.0`、`@types/react-dom@19.3.0`、`scheduler@0.28.0` 及若干可选 peer 变体（纯类型键，无运行时影响）。
- 新增 `packages/libs/editor-core/src/__tests__/infrastructure.test.ts`：用 `createElement` 渲染一个文本节点并断言 `screen.getByText` 能找到它（无 JSX），证明 jsdom + react-dom + @testing-library/react 测试栈端到端可用。这是持久基础设施测试。

**版本修改与理由（用户 2026-10-04 决定）**：不迁就编辑器的精确 `19.2.3`，`react` 保持 catalog 最新（19.3.0）；为保证 react/react-dom 严格同版本，editor-core 单独把 `react-dom` / `@types/react-dom` 固定到精确 `19.3.0`（两包在 npm 上均存在，已用 `npm view` 核对）。未采用「提升工作区 catalog」方案，因为那会连带影响所有 `catalog:default` 消费者，且可能让 service-worker 等包出现 react 19.3.0 与 react-dom 19.2.3 的新错配。
