<objective>
实现 editor-core 的组合根 `EditorCore` 与包根公开面（D-12..D-16、D-39）。
EditorCore 是唯一入口：构造三大系统、统一下发注入、逆序释放；渲染根由 `panelSystem.render()` 提供。

Purpose: 让编辑器顶层 `new EditorCore()` 即可获得完整内核。
Output: `EditorCore` 类 + `EDITOR_CORE_VERSION` + 包根导出 + 单元测试。

⚠️ 执行前简报需确认：`EDITOR_CORE_VERSION` 的取值为提案 `'0.1.0'`（旧 `EDITOR_CORE_API_VERSION` 已随旧实现作废）。
</objective>

  <action>
    新建 `src/core.ts`：
    - `export const EDITOR_CORE_VERSION = '0.1.0';`（模块常量；提案值待用户确认）。
    - `export class EditorCore implements IEditorCore`：
      - 字段 `readonly version: string = EDITOR_CORE_VERSION;`、`readonly undoSystem: IUndoSystem;`、`readonly resourceSystem: IResourceSystem;`、`readonly panelSystem: IPanelSystem;`。**接口引用即可**（D-39 已把 dispose 加到接口上，无需保留具体类引用）。
      - 构造器：`this.undoSystem = new UndoSystem(); this.resourceSystem = new ResourceSystem(); this.panelSystem = new PanelSystem(this.undoSystem, this.resourceSystem);`（D-16）。
      - `initialize(injection: IEditorCoreInjection)`：先把同一个 injection 下发给 `undoSystem.initialize(injection)` 与 `resourceSystem.initialize(injection)`（`await Promise.all([...])`），**再** `await this.panelSystem.initialize(injection)`（面板初始化可能要用到已就绪的资源系统，D-14/D-30）。
      - `dispose()`：`await this.panelSystem.dispose(); this.resourceSystem.dispose(); this.undoSystem.dispose();`（逆序，D-39）。
    - 相对导入：从 `./undo`、`./resource`、`./panel`、`./types` 取类与接口；用普通 import。
    - 不写文件头注释；实现类不重复接口 jsDoc；无 render()（D-12）。
    新建 `src/__tests__/core.test.ts`：构造 EditorCore，断言 `version === EDITOR_CORE_VERSION`、三个系统字段存在；用一个假 `IEditorCoreInjection`（`maxUndoStep` + 资源后端方法，面板注入为空对象）调 `initialize` 不抛错，且随后可经 `core.resourceSystem`/`core.panelSystem` 正常使用。
    每个 `it`/`test` 前用单行 `//` 说明覆盖内容；首行必须是 import。
