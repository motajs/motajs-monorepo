    实现三个类（类必须完整实现各自接口，否则 typecheck 不过）：
    （1）`src/panel/panelContext.ts`：`PanelContext implements IEditorPanelContext`，构造器持有 `IResourceAccess` 与 `IUndoSystem`。`requestResource` / `requestResourceList` / `createResource` / `deleteResource` 直接转调 `IResourceAccess`；`addUndoContext(panel, context)` 直接转调 `IUndoSystem.addUndoContext`（D-31）。从 `../resource/access`（非桶）导入 `IResourceAccess`。
    （2）`src/panel/editorPanelHooks.ts`：`EditorPanelHooks implements IResourceSystemHooks`（D-45：构造签名属实现细节，采用 `(panel: IEditorPanel, context: IEditorPanelContext)`）。`onUpdateResource(id)`：`const resource = await this.context.requestResource(id); if (resource) { await this.panel.onUpdateResource(id, await resource.request()); }`；`onUpdateResourceList(type)`：`await this.panel.onUpdateResourceList(type, await this.context.requestResourceList(type));`。
    （3）`src/panel/panelSystem.ts`：`PanelSystem implements IPanelSystem`。
        - 字段：`private readonly undoSystem: IUndoSystem`、`private readonly resourceSystem: IResourceSystem`、`private readonly panels: Map<string, IEditorPanel> = new Map()`、`private readonly hooks: Map<IEditorPanel, IHookController<IResourceSystemHooks>> = new Map()`、`private readonly pendingPanels: IEditorPanel[] = []`、`private initialized = false`、`private currentParam?: Record<string, unknown>`、`currentPanel: IEditorPanel | null = null`、`private readonly panelStore = new Store<number>(0)`（版本号，仅用于通知订阅者）、`private readonly subscribe = (listener: () => void): (() => void) => this.panelStore.subscribe(listener)`、`private readonly getSnapshot = (): IEditorPanel | null => this.currentPanel`。
        - `private readonly RootComponent: FC = () => { const current = useSyncExternalStore(this.subscribe, this.getSnapshot); return current ? createElement(current.render()) : null; };`（组件只在构造器创建一次，避免每次 render() 返回新组件导致反复重挂，RESEARCH Pitfall 3）。用 `createElement`（该文件保持 .ts，不写 JSX）。
        - `render(): FC` 返回 `this.RootComponent`。
        - `registerPanel(creator: EditorPanelCreator)`：`const context = new PanelContext(this.resourceSystem, this.undoSystem); const panel = await creator(context);`；若 `this.panels.has(panel.id)` 抛错（id 强制唯一，D-28）；否则 `this.panels.set(panel.id, panel)`；`this.hooks.set(panel, this.resourceSystem.addHook(new EditorPanelHooks(panel, context)))`；已 initialize 则 `await panel.initialize()`，否则 push 到 `pendingPanels`（D-30）。返回 panel。
        - `initialize()`：省略空占位参数 `IPanelInjection`（无未使用形参），置 `initialized = true`；`window.addEventListener('focus', this.handleFocus)` 与 `('blur', this.handleBlur)`（D-38）；取出并清空 pendingPanels，逐个 `await panel.initialize()`。
        - `getPanel(id)`：`return this.panels.get(id) ?? null;`
        - `switchTo(panel, param?)`：同当前面板直接返回；否则 `this.undoSystem.addUndoContext(this, { type: PanelUndoType.Switch, data: { from: this.currentPanel, fromParam: this.currentParam, to: panel, toParam: param } })`，再 `await this.internalSwitchTo(panel, param)`。
        - `private async internalSwitchTo(panel: IEditorPanel | null, param?)`：`const previous = this.currentPanel; if (previous) await previous.onSwitchOut();`；`this.currentPanel = panel; this.currentParam = param; this.panelStore.setState((version) => version + 1);`；`if (panel) await panel.onSwitchIn(param);`。**不记录撤回**。
        - `undo(context: IUndoContext<unknown>)` / `redo(context: IUndoContext<unknown>)`：单次 `as` 收窄为模块内接口 `IPanelSwitchData`，只调 `internalSwitchTo`（D-32，避免自证循环，RESEARCH Pitfall 5）。`IPanelSwitchData` 用 `from: IEditorPanel | null`、`to: IEditorPanel` 与各自 param。
        - `disposePanel(panel)`：先 `this.hooks.get(panel)?.unload()` 再 `await panel.dispose()`，删两张表；若是当前面板则置 `currentPanel = null` 并 notify。
        - `dispose()`：移除 window 监听；按注册逆序（`[...this.panels.values()].reverse()`）逐个 unload 钩子并 `await panel.dispose()`；清空 pendingPanels 与两表；`currentPanel = null`。
        - `handleFocus` / `handleBlur` 作为实例箭头字段：`void this.currentPanel?.onFocus()` / `?.onBlur()`。
        - `PanelUndoType` 从 `./types` 导入（它定义在 `panel/types.ts`，经桶自然导出）。
    （4）`src/panel/index.ts` 末尾**追加**：`export * from './panelSystem';`、`export * from './panelContext';`、`export * from './editorPanelHooks';`。`PanelUndoType` 由 `panel/index.ts` 既有的 `export * from './types'` 自然导出（它已定义在 `panel/types.ts`，见 05.3-02），无需额外导出行。
    相对导入、普通 import（禁类型导入语法）；实现类不重复接口 jsDoc；不写文件头注释。
    新建 `src/panel/__tests__/panelSystem.test.ts`：
    - 写 `FakePanel implements IEditorPanel`（记录 initialize/dispose/onSwitchIn/onSwitchOut/onUpdateResource/onUpdateResourceList/onFocus/onBlur/undo/redo 调用；`render()` 返回**渲染该面板 `id` 文本**的稳定组件（用 `createElement` 构造，如 `() => createElement('div', null, this.id)`）；`id` 可指定）。
    - 资源后端用 05.3-05 的真实 `ResourceSystem` + 一个内存 `IResourceInjection` 替身。
    - 覆盖基础闭环：注册（未初始化）不调 initialize；`initialize()` 补调；`switchTo(b)` 触发 a.onSwitchOut 与 b.onSwitchIn、currentPanel 变为 b；`render()` 返回一个函数。
    - **真实挂载渲染（W1，必须）**：用 `@testing-library/react` 的 `render` / `screen` / `act`，`render(createElement(panelSystem.render()))` 挂载渲染根；先 `switchTo(a)`（用 `await act(async () => ...)` 包裹）断言画面出现 a 的文本；再 `switchTo(b)` 断言画面出现 b 的文本，证明 `render()` 随 `currentPanel` 重渲染（D-12）。
