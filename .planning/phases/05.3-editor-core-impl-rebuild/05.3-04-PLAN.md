  <action>
    新建 `src/undo/undoSystem.ts`，实现 `IUndoSystem`（全部成员，含 05.3-02 新增的 `dispose(): void`，否则 typecheck 不过）：
    - 模块内非导出接口 `UndoEntry`（单行 `//` 注释说明它是“可撤回对象 + 撤回上下文”的一条记录）。
    - 字段：`maxUndoStep = 0`（实现类可变字段以满足接口 readonly；由 `initialize` 注入，D-13）、`private readonly undoStack: UndoEntry[] = []`、`private readonly redoStack: UndoEntry[] = []`。状态必须是实例字段，不得模块级容器（否则 module-state 门禁判红）。
    - `initialize(injection)`：`this.maxUndoStep = injection.maxUndoStep;`。
    - `addUndoContext(undo, context)`：push 到 undoStack；`maxUndoStep > 0` 且超长时 `shift()` 从栈底裁剪；并清空 redoStack。
    - `undo()`：弹 undoStack 栈顶；空则直接返回；`await entry.undo.undo(entry.context)`；把该条压入 redoStack。
    - `redo()`：反向（弹 redoStack，调 `entry.undo.redo(entry.context)`，压回 undoStack）。
    - `dispose()`：清空两栈。
    用相对导入 `import { IUndoContext, IUndoInjection, IUndoSystem, IUndoable } from './types';`；**不用**类型导入语法（用普通 import，类型再导出用 export type）。
    实现类**不重复**接口方法的 jsDoc（接口源头已写）；私有方法/内部接口用单行 `//` 或完整注释；不给构造器写注释；不写文件头注释。
    `src/undo/index.ts` 末尾**追加**一行 `export * from './undoSystem';`（不改已有行）。
    新建 `src/undo/__tests__/undoSystem.test.ts`：
    - 用 `import { describe, expect, test } from 'vitest';`。
    - 定义一个测试替身（记录调用次数与收到的 context 的 `IUndoable`）。
    - 覆盖：入栈后 `undo()` 以同一 context 调用了替身的 `undo`；`redo()` 以同一 context 调用其 `redo`。
    - 每个 `it`/`test` 前用单行 `//` 说明覆盖内容；不写文件头大段注释；首行必须是 import。
  </action>
