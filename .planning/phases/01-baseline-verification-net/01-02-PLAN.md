## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build/test output → committed `.planning/baseline/` | Generated data enters version control and becomes a long-lived comparison reference. |
| Editor surfaces → committed screenshots | Whatever the browser renders is published in the repository. |
| Local filesystem → `baseline.json` | Absolute paths or environment values could leak into a committed artifact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `.planning/baseline/screenshots/*.png` | high | mitigate | Capture only editor chrome driven by the public sample project through `ProjectSandbox`; explicitly exclude the runtime preview iframe, which executes project-authored code and can render arbitrary content. |
| T-02-02 | Information Disclosure | `.planning/baseline/BASELINE.md`, `baseline.json` | medium | mitigate | Keep the documents free of absolute filesystem paths, usernames, and any secret or environment value; record variable names only, never their values. |
| T-02-03 | Tampering | `scripts/baseline/collect.js` | medium | mitigate | The script reads runner-produced reports and the plugin's own artifact report instead of recomputing numbers, so a hand-edited baseline cannot diverge from a measurement without a diff; it adds no dependency and no network access. |
| T-02-04 | Repudiation | baseline claimed without a recorded tree identity | medium | mitigate | `baseline.json` records the git commit SHA, the submodule SHA, and the toolchain versions, so any later claim can be tied to an exact tree. |
| T-02-SC | Tampering | package installs (supply chain) | low | accept | This plan adds zero packages; `pnpm-lock.yaml` stays frozen. Playwright browsers are installed from the pinned `@playwright/test` release. |
