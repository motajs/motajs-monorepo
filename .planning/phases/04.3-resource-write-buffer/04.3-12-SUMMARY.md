## Decisions Made

- **改写而不是删除：** 三条旧用例描述的场景已被 D-26 / D-27 从结构上取消，但「重复打开只聚焦、草稿不丢、不静默覆盖」仍是应当守住的行为，因此改写成去重后的现实。
- **第二次打开只打已有标签：** 用 `ShellSystem.openPanelInTab(tabId, ..., path)` 命中「本次 tabId 就是登记者」那一支；不新建空白标签，避免空白标签先触发切出落盘。
- **用实例 id 作为「没有重建」的判据：** 去掉去重后，同一标签上的再次打开会「关闭旧实例 + 新建实例」，实例 id 必然变化；这让三条用例在去重回退时确实会红。
- **`devHostMap` 不改：** 地图保存走 `saveMapData` 能力直接写文件，不经过 5 秒缓冲，既有「保存后读盘」断言本来就成立且全绿。
