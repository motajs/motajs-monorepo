<objective>
收口 G2：让全量 / 生命周期写盘跳过被「外部已改」标记的待写条目，并让 `TablePanel.saveDocument` 在入口处挡住任何有 `pendingConflict` 的栏——安静 / 非安静一律停手，撤销 / 重做也跑不掉；切回面板时不重读磁盘，草稿不被外部内容换掉；两个冲突动作只结算真正有待写的路径。先写会失败的用例，再改实现。

Purpose: 冲突处置定稿要求「没表态就不写盘，冲突只由弹窗两个动作结算」。现在的实现只做到了「没有 5 秒自动落盘」，窗口失焦 / 切标签 / 关页仍会经 `WriteBuffer.flushAll` 写出，切走时表格的非安静分支也会 flush；更隐蔽的是撤销 / 重做走 `TablePanel.saveDocument` 的安静分支，`TablePanel.persist` 会把条目整条替换、把标记顺手清掉，5 秒后照样写盘。用户去外部编辑器核对改动、或按一下 Ctrl+Z，都会触发覆盖。本计划把这条契约变成一组会失败的行为断言（失焦 / 切标签往返 / `pagehide` / 撤销（含推进 5 000 毫秒） / 两条路径 / 未编辑的兄弟路径 / 自动保存 / 回声），再让它们变绿。

Output: `writeBuffer.ts` 的跳过与回声规则、`tablePanel.ts` 的入口守卫 / 刷新守卫 / 按实际待写结算，`types.ts` 的 JSDoc 同步，以及三份测试里新增的冲突生命周期用例；既有用例保持全绿。
</objective>
