<objective>
让素材管理器和地图编辑器不再每打开一个文件就多一个标签：同一种面板只保留一个标签，再次打开时沿用它；换内容前先把上一个目标的改动存好；如果那个面板正卡在「外部改了，听谁的」的弹窗上，就不换、不写盘，只把标签切到前台让用户先处理。表格保持一栏一条路径、每次新开标签的现状（D-31 / D-32 / D-33）。

Purpose: Gap B 的用户要求是「复用同一个面板」，不是「每次重建一个标签」。直接在资源管理器里新开标签会让用户手里堆一排素材 / 地图标签；而简单地在旧实例上换目标又会绕过既有的「切出落盘」生命周期，容易丢改动。本计划把复用做成外壳的一条规则：复用同一个标签，但先走完整的切出保存，再按新打开参数重建实例——用户看到的是同一个标签，内容已经换好，旧改动已经落盘。两个关键点必须由机制保证而不是靠断言措辞：①冲突判定要抢在「为打开而切走旧面板」之前（否则旧面板已经被自动存过一次）；②保存没成功时不能释放旧实例。

Output: `editor-core` 新增按类型的复用能力、冲突查询、未保存查询与暂存空白标签；素材 / 地图声明复用并实现两个查询；外壳、素材、地图三层守门用例；表格面板类型保持不变。
</objective>
