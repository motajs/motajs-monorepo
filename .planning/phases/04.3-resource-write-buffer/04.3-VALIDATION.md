## Sampling Rate

- **After every task commit:** 受影响单文件 `pnpm --filter <pkg> exec vitest run <file>` + 该包 `typecheck`
- **After every plan wave:** 三包全量 `test` + 三包 `typecheck` + 四条结构门禁
- **Before `/gsd-verify-work`:** 三包全绿 + 四条门禁全绿 + `pnpm lint` 0 error + `pnpm format:check` + 手工验收表（RESEARCH §Q9.5）完成
