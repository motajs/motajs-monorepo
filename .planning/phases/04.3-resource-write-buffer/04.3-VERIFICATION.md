# Phase 04.3: 资源写入缓冲与表格自动保存 — 验证报告（重验）

**Phase Goal:** 把「什么时候写盘」从各个面板 / 组件收回到资源层：新增按路径的写缓冲，写入只进缓冲 + 缓存，防抖 5 秒后 flush；切标签 / 关闭 / 页面失焦 / 释放时统一 flush。表格改为字段确认（blur / 回车）后写一次缓冲，不再要求手动保存才能落盘；同一张表允许在两栏同时打开，写入后 50ms 合并通知，另一栏立即更新，最后写盘者胜；有 pending 时右上角显示等待保存提示并在 `beforeunload` 弹浏览器原生确认；地图 / 素材保存时机不变，但写入同样走缓冲。

> **口径说明（D-28 / D-29）：** 上面 Goal 里「同一张表允许在两栏同时打开 / 另一栏立即更新 / 最后写盘者胜」已被 D-28 / D-29 取代。现在的合同是：**一条数据路径任何时刻最多只有一个编辑者**——跨标签只保留一个标签、同一表格面板内只允许一栏持有同一数据文件；「一栏数据 + 它的兄弟 schema 栏」仍是两条不同路径，允许并排联动。判据 3 按这个修订后的口径验收。
