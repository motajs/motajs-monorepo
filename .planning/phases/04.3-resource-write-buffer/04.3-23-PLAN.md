<objective>
把「表格面板自己换目标后，外壳不知道它现在显示哪个文件」这条缺口补上：给面板一个上报口，面板换目标后把当前显示的全部路径交给外壳；外壳按标签保存路径集合，资源管理器再打开同一文件时就能找到那个表格标签，而不是再开一个（D-30）。

Purpose: 04.3-21 只让「调用方把路径交给打开入口」的打开方式能被去重；表格面板在空栏选择器里换目标、关掉一栏、或从代码编辑器写回后换目标时，外壳的登记不会跟着变，于是同一个文件会出现在第二个标签里，直接违反 D-28「一条路径任何时刻最多只有一个编辑者」。本计划把登记的所有权从「调用方猜」改成「面板主动说」。

Output: `editor-core` 的面板上下文新增上报口与集合登记；`TablePanel` 在换目标 / 关栏后上报；`editor-core` 与 `editor-impl` 两侧守门用例；不新增公开外壳成员、不改打开参数形状、不加依赖。
</objective>
