## Decisions Made

- **全量写盘只留一个入口。** 切出、保存并关闭、`pagehide`、`blur` 四处都调 `ShellSystem.flushPendingContent`，不在各处自己 `try/catch`，失败口径因此只有一条 `resource.flushFailed`。
- **「不保存关闭」刻意不写盘。** 面板的丢弃钩子已经把该路径待写丢掉，外壳这时再写盘等于把「丢弃」变成一次写盘；测试用「推进 5 000 毫秒磁盘仍是旧值 + 待写列表为空」同时钉住这两点。
- **`ShellSystem.dispose` 不额外写盘。** 计划允许两种落点，选了「由 `ResourceSystem.dispose` 写盘」：面板释放时的最后一次写入仍进缓冲，`EditorCore.dispose` 的顺序（shell → resource → undo）保证它必被写出，`shellFlush.test.ts` 第 5 条钉住。
- **`beforeunload` 的诚实限制写进代码。** 处理函数只阻止卸载并「发起」写盘，不等待、不同步写、不循环；注释里写明浏览器不等异步写盘，因此这条路径不承诺「保证不丢」。
- **三个处理器三个字段。** 按 `INTERFACE-NAME.md` 的 `beforeUnloadHandler` / `pageHideHandler` / `windowBlurHandler` 一一落地，字段声明为「可能为空」以便 `dispose` 注销。

- **Files modified:** `packages/libs/editor-core/src/shell/shellSystem.ts`
- **Verification:** `shellPageLifecycle.test.ts` 5/5 绿（`pagehide` 与 `blur` 各一条用例）

**2. 页面处理器是「可空字段 + initialize 里赋值」，不是声明即赋值的箭头函数常量。**
- **Found during:** Task 3
- **Issue:** 计划同时要求「私有箭头函数字段」与「声明为可能为空的字段以便注销」；声明即赋值的字段无法在 `dispose` 里清空引用，也没法和 `ResourceSystem.unwatch` 的形态对称。
- **Fix:** 三个字段声明为 `((…) => void) | null`，`initialize` 里先注销旧值再赋新值，`dispose` 里注销后置空。注销用的是同一个函数引用。
- **Files modified:** `packages/libs/editor-core/src/shell/shellSystem.ts`
- **Verification:** `shellPageLifecycle.test.ts` 第 5 条（释放后 `pagehide` 不写盘）绿
- **Committed in:** `baccd9f`

**3. 两个测试文件都不渲染 React 组件。**
- **Found during:** Task 1
- **Issue:** 计划建议照抄 `shellAutosave.test.ts` 的 `render` + `act` 装配写法；但本计划要断言的只是「磁盘内容 / 待写列表 / 事件是否被阻止」，不需要组件挂载时序（既有 `shellCloseChoice.test.ts` 的「释放外壳」用例同样不渲染）。
- **Fix:** 两个文件只 `createElement` 造面板的渲染组件、不调 `render` / `act` / `cleanup`，用例更短且不会引入 React 调度噪声；页面事件全部 `window.dispatchEvent`。
- **Files modified:** `shellFlush.test.ts`、`shellPageLifecycle.test.ts`

**4. `beforeunload` 用例只断言 `defaultPrevented`，不断言 `returnValue` 的值。**
- **Found during:** Task 1

- **Fix:** 只钉「有待写 → 被阻止 / 无待写 → 不阻止」，代码里 `preventDefault` 与 `returnValue = ''` 都写（T-04.3-04 与 Pitfall 6 的要求），真实弹框留人工验收（coverage 的 D5）。
- **Files modified:** `shellPageLifecycle.test.ts`
- **Verification:** 用例 1 / 2 绿
- **Committed in:** `7e6a3ef`
